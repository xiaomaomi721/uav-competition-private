# 1. 给新协作者的一页摘要

## 1.1 项目从哪里来

**[F]** 项目起源于一个八类无人机低空航拍语义分割比赛。源域具有像素级标签，后期工作允许使用无标签目标域图像进行训练期适配，评价指标为八类等权 mIoU。项目由早期 SegFormer 基线逐渐转向目标域自训练、软蒸馏、异构教师和参数空间稳定化。

## 1.2 为什么不能直接写成“冠军方案论文”

**[F]** 项目确实积累了大量训练、对照、失败分析和线上结果，但最高分 H75 的核心是同配方轨迹参数平均；BlindRecall、ACDD 和 HPRD 使用的类别阈值、软 KL、异构教师、prototype、query region、LoRA 等组件也都有明确文献近邻。

**[L]** 因此，比赛冠军、模型汤或现有模块组合本身不能直接作为论文创新。论文需要从比赛过程中发现的现象出发，重新提出可测量、可证伪、可在公开数据集验证的问题。

## 1.3 当前最可靠的项目观察

**[F; E1-E3]** BlindRecall 的 matched TREAT 相对 CONTROL 提高 `+0.595100pp`，说明加入目标域类别感知软监督具有明确的配对正信号。

**[F; E1]** 完全移除 source 监督的 Arm A 不如保留轻量 source anchor 的 Arm B，差值为 `+0.088066pp`；但纯 source continuation 的 CONTROL 又明显低于共同起点 A05。

**[F; E1]** 将 Arm B 的目标软监督替换成 hard pseudo 后下降 `1.113170pp`，说明扩充目标域训练信号不能简单等价为硬化教师预测。

**[F; E1, E8]** HPRD-Lite 使用异构 query region、source-GT prototype 资格确认和受限 LoRA，线上相对 ACDD 仅提高 `+0.019285pp`；其 source holdout 区域精度很高，但目标域 region 支持和训练曝光非常低。

## 1.4 当前候选科研问题

**[H]** 我们怀疑，目标域自训练中的一部分困难类别，不只是“置信度低”或“样本少”，而是在经过 top-1 决策、置信门、区域资格门和损失权重后，实际获得的正监督质量或梯度贡献长期接近零。本文暂将该现象称为：

> **目标类别监督支持不足**  
> 工作术语：**Target-Class Supervision Starvation, TCSS**

这个术语目前只是工作名称，不是已经确认的新概念。

## 1.5 当前最可能保留的独立研究残量

**[H]** 与普通类别阈值、低置信像素利用和 prototype 去噪相比，较有希望的研究残量是：

1. 显式测量每个目标类别实际获得的正监督质量或梯度支持；
2. 只在检测到 support deficit 时触发干预，而不是全局放宽阈值；
3. 在类别级估计精度或风险约束下扩展支持；
4. 利用尽量独立的异构 region/prototype 证据，将有限的 non-top1 概率质量转化为正监督。

候选方法工作名为：

> **Precision-Constrained Class Support Expansion，精度约束的类别支持扩展**

## 1.6 目前还差什么

**[L]** 当前只有比赛 pilot evidence，尚无公开数据上的问题诊断、最近邻方法完整复现、多随机种子和统计显著性证据，因此还不能冻结论文题目和贡献。

**[T]** 下一阶段应优先完成：正式文献查重、公开数据协议、无干预 support 测量、最简单强基线以及 precision-matched / support-matched 因果对照，而不是继续优化比赛分数。

# 2. 任务背景及比赛证据的使用边界

## 2.1 论文需要知道的任务信息

**[F; E1]** 原任务是无人机航拍语义分割，包含 Background、Building、Road、Water、Barren、Vegetation、Agricultural、Vehicle 八类。项目后期主要面对带有域偏移的无标签目标图像，并在训练期使用教师预测进行目标域适配。

**[F; E1]** 历史主模型为 SegFormer-B3；后期核心训练信号包括 source GT、目标教师软分布、hard pseudo、异构 Mask2Former region 和 source-GT prototypes。最终比赛部署受单 checkpoint 约束，但这一约束不是论文科学问题本身。

## 2.2 比赛结果可以用于什么

比赛材料可以用于：

- **[F]** 说明问题来自真实应用，而不是凭空构造；
- **[F]** 给出若干 matched control/treatment 和强负结果；
- **[F]** 展示项目已经完成的机制探索和工程工作量；
- **[H]** 生成待在公共基准验证的研究假设。

## 2.3 比赛结果不能用于什么

**[L] 总分限制**：平台主要返回整体 mIoU，缺少目标域逐类 IoU、伪标签 precision/recall、支持量和错误结构，无法直接判断某个模块为什么涨分。

**[L] 排行榜适应**：历史上多次根据线上分数调整方案，后续方法已经受到隐藏测试集低带宽反馈影响，存在 selection bias 和 leaderboard overfitting。

**[L] 统计限制**：多数关键分数为单次 online 点，没有三个独立随机种子、置信区间和独立目标测试集。

**[L] 工件限制**：部分后期结果有用户回报分数，但平台回执、完整代码或工件身份没有全部闭合，应归为 `SCORED_IDENTITY_PARTIAL`，不能描述成完全可复现实验。

因此论文证据应分层：

```text
公开基准、固定协议、多seed结果     → 论文主要科学结论
原比赛结果                         → pilot / retrospective case study
历史排行榜探索                     → 动机与工作量，不承担统计结论
```

# 3. 候选问题：目标类别实际得到了多少监督？

## 3.1 为什么普通“类别不平衡”描述不够

已有研究已经大量讨论 rare class、class imbalance、class-wise threshold 和伪标签偏置。如果本文只说“困难类别伪标签较少，所以降低阈值”，创新性很弱。

我们需要区分四个不同层次：

1. **真实存在量**：目标图像中某类别实际有多少像素；
2. **预测量**：教师有多少像素将该类别预测为 top-1；
3. **接受量**：经过阈值和区域门后，有多少像素或 region 被用于训练；
4. **有效支持量**：考虑 soft mass、损失权重和梯度之后，该类别实际获得了多少正更新。

**[H]** 一个类别可以真实存在，也可以在 teacher 的 top-2/top-k 中持续出现，但由于始终不是 top-1 或无法通过严格 gate，最后获得的有效正支持仍接近零。

## 3.2 暂定测量指标

后续不应立即把所有指标压成一个自定义分数，而应先分别记录：

### 接受的正质量


a) hard support：被接受且 hard label 为类别 `c` 的像素或 region 数；  
b) soft positive mass：

\[
M_c=\sum_i w_i q_i(c)
\]

其中 `q_i(c)` 是 accepted target 对类别 `c` 分配的软概率，`w_i` 是可靠性或区域权重。

### 曝光频率

- 含类别 `c` 有效监督的图像比例；
- 含类别 `c` 有效监督的 batch/step 比例；
- 连续多少训练步该类没有正监督。

### 监督质量

- accepted pseudo-label precision；
- coverage / recall；
- promoted non-top1 precision；
- false-support injection；
- teacher 间错误相关性。

### 梯度代理

\[
G_c=\sum_i\left\|\nabla_\theta \ell_i^{(c)}\right\|
\]

可先记录关键层的 per-class loss/gradient norm，再决定是否需要更复杂的梯度方向稳定性指标。

**[L]** 在无标签目标域训练时无法知道真实 precision。训练阶段只能使用 calibrated proxy、跨视图一致性、prototype margin 或异构教师一致性；真实 target precision 只能在隔离的评估标签上离线分析，不能参与适配或模型选择。

## 3.3 可证伪假设

### H1：类别支持不足可重复存在

**[H]** 在若干域偏移任务中，部分低 IoU 类别会长期表现出明显偏低的 accepted positive mass 和 non-empty step ratio。

**反证条件**：如果低 IoU 类别并无稳定 support deficit，或 support 指标与类别性能没有可重复关系，则不能用“监督支持不足”解释失败。

### H2：类别阈值放宽不足以解决问题

**[H]** 如果类别从不成为主教师 top-1，仅降低 top-1 confidence threshold 不能恢复其正支持；异构证据支持的 non-top1 promotion 应有额外价值。

**反证条件**：如果 class-wise threshold/quota 或现有 FPL/soft-label 基线已经在相同风险下达到同等支持和性能，候选方法没有独立贡献。

### H3：支持扩展存在精度—覆盖前沿

**[H]** 极严格 gate 能获得高 precision，但可能因 exposure 过低而无效；在风险下降可控的条件下增加支持，应能提高支持不足类别的 IoU。

**反证条件**：如果 support 增加后类别 IoU 没有稳定提高，或改进完全来自 precision 提高而与 support 无关，则“支持扩展”不是主要机制。

### H4：轻量稳定锚能控制扩展风险

**[H]** 适量 anchor 可能减少 target self-training 漂移，但过强 source supervision 会妨碍目标域适配。

**反证条件**：如果公开基准上 source 权重变化与 target drift/source tax 没有稳定关系，则 Arm A/B 的比赛现象不能推广。

## 4.2 HPRD 暴露出的关键矛盾

**[F; E1, E8]** HPRD-Lite v1 使用冠军初始化、Mask2Former SIZE768 query region、source-GT prototype 资格确认和 Stage3 rank-4 LoRA，训练后 merge 回普通单 checkpoint。

**[F; E1]** 已记录的诊断为：

- R1099 region precision 约 `99.30%`；
- 目标域 `125/1300` 张图出现合格 region；
- region coverage 约 `1.59%`；
- 1000 个训练步中只有 `103` 步出现 non-empty region。

**[H]** 这些数据提出了“高质量证据供应不足”的合理假设，但不能证明 support 是唯一瓶颈。还需要在有隔离 target GT 的公开数据上主动改变 support，并控制 precision 后做因果实验。

# 5. 文献覆盖与创新边界

## 5.1 已有研究已覆盖的主要部分

当前初步查新表明，以下内容已有直接近邻：

| 方向 | 代表工作 | 与本项目的重合 |

## 5.2 当前候选独立残量

**[H]** 只有下面四点同时成立，才可能形成区别于现有工作的完整研究闭环：

1. **Measure**：测量每个类别实际获得的正监督质量和梯度支持，而不只统计预测频率；
2. **Detect**：只有检测到 support deficit 才触发干预；
3. **Constrain**：在类别级 estimated precision/risk 约束与新增 support budget 下扩展；
4. **Promote**：用尽量独立的异构证据，将有限 non-top1 类别质量转化为正监督。

# 6. 候选方法框架：Measure–Detect–Propose–Promote–Constrain–Anchor

这部分只描述研究结构，不冻结最终公式。

## 6.1 Measure：测量类别实际支持

对每个类别维护：accepted positive mass、non-empty ratio、支持来源、estimated risk、loss/gradient contribution，以及随训练时间的变化。

## 6.2 Detect：识别支持缺口

只在类别长期支持不足时触发。不能因为 source 中类别较多就假设 target 中也必须同样多；检测应结合：

- 目标 support 的时间趋势；
- 多视图稳定性；
- base teacher 与异构 teacher 的系统性分歧；
- prototype/region 是否反复提供一致候选；
- 是否存在大量稳定 top-2/top-k 质量但几乎无 top-1 接受量。

## 6.3 Propose：生成新的类别候选

候选证据可以来自：

- 异构 Mask2Former/query region；
- source-GT prototype 相似度和 margin；
- 强弱增强或多视图一致性；
- 区域内部语义一致性。

一个模型提出候选，另一种不同归纳偏置的证据负责验证，避免同一 teacher 循环自证。

## 6.4 Promote：有限提升 non-top1 正质量

当主 teacher 没有把类别 `c` 预测为 top-1，但异构证据稳定支持 `c` 时，可以向该类分配有限 soft positive mass。不能直接将所有 top-2 转成 hard label。

## 6.5 Constrain：控制错误支持

训练阶段无法得到 target 真 precision，因此“precision-constrained”必须诚实写成 estimated precision/risk constraint。候选约束包括：

- 每类最低估计精度；
- 每类新增 coverage/support budget；
- 最大 estimated false-positive budget；
- 对非缺失类别允许的最大退化；
- 支持扩展的逐步 curriculum 和回退条件。

## 6.6 Anchor：防止目标适配漂移

可使用轻量 source regularization、保守 teacher anchor 或冻结参数子空间。anchor 的角色是风险控制，不是核心创新。LoRA 可以作为限制漂移和降低成本的实现选择，但不能作为主要贡献。

# 7. 数据问题与建议实验协议

## 7.1 为什么原比赛数据不能作为唯一主实验

**[L]** 比赛 test2 缺少公开 GT，训练时又使用了确切目标测试图，因此属于 transductive adaptation。再叠加多次排行榜反馈，无法形成严格独立的 final test。

所以原比赛的合理定位是：

- 问题发现数据；
- 历史 pilot；
- 最后可选的真实场景 case study；
- 不能作为唯一的主要科学证据。

## 7.2 最低公共数据方案

### LoveDA 双向迁移

**[H] 初步推荐**：以 LoveDA Urban→Rural 和 Rural→Urban 作为第一公开基准。它与当前航拍场景、Building/Road/Water/Barren/Forest/Agriculture 等类别结构较接近，也具有明确域偏移。

**[T]** 下载和实验前核验官方版本、真实文件计数、split、ignore 语义与许可；生成固定 manifest 和哈希记录，不照抄二手文章中的样本统计。

### ISPRS Potsdam↔Vaihingen

**[H] 推荐外部验证**：增加 Potsdam→Vaihingen 和反向迁移，用于检验跨城市、分辨率和成像条件变化。必须在论文中固定 5/6 类口径、clutter 是否 ignore、使用哪些波段、patch 与 tile 划分方式。

如果时间有限，先把 LoveDA 双向、强基线和三个 seed 做完整，再增加 ISPRS；不要同时铺开多个不完整数据集。

## 7.3 主实验使用 inductive UDA

建议主协议：

```text
source train：图像 + 标签
target adapt：图像，无标签
target final：训练、阈值、BN统计、模型选择均不可见；只做最终评价
```

原比赛式 transductive UDA 可以单独成表，但不能与 inductive 主结果混合平均。

## 7.4 目标标签隔离

**[T] 数据协议交付物**：

1. 固定 source/target-adapt/target-final manifest；
2. 按城市、tile、区域或序列划分，禁止先随机裁 patch 再拆分；
3. target-adapt loader 不配置标签目录，并断言 batch 不含 label；
4. 记录所有访问文件并检查 source/target 身份交集；
5. 方法、超参数、训练步数和 checkpoint 选择规则冻结后，才允许一次性评价 target-final；
6. 如果 final label 解封后修改方法，该结果必须标记为 post-hoc，不能继续作为独立 final test。

## 7.5 必须报告的指标

- 整体 mIoU 和所有 per-class IoU；
- domain/tile macro mIoU 与 worst-domain mIoU；
- class-wise hard support 和 soft positive mass；
- non-empty image/step ratio；
- accepted pseudo-label precision、recall、coverage；
- promoted non-top1 support 及其 precision；
- precision–support 曲线；
- source retention 和 negative-transfer rate；
- 训练成本、可训练参数和推理开销；
- 至少三个完整随机种子的原始值、均值和标准差。

如果相对强基线的改进与 seed 方差接近，应增加 seed 或降低结论强度，不能只展示最佳运行。

# 8. 最小实验矩阵与停止条件

## 8.1 第一阶段：只测量，不改变训练

| 实验 | 目的 |
|---|---|
| Source-only | 建立无 target adaptation 基线 |
| 标准 UDA/self-training | 测量每类 support、precision、coverage 和 non-empty ratio |
| 多 seed 重复 | 判断 support deficit 是否稳定存在 |

**停止条件**：如果在公开任务上没有稳定、可重复的 class-wise support deficit，则不进入复杂扩展方法，重新评估选题。

## 8.2 第二阶段：排除简单解释

| 对照 | 回答的问题 |
|---|---|
| Global threshold | 普通全局选择表现如何 |
| Class-wise threshold / quota | 是否只需类别阈值或配额 |
| Full-distribution soft KL | 是否只需对全部像素做软蒸馏 |
| Top-k / fuzzy-positive baseline | 是否已有 non-top1 方法即可解决 |
| Random equal-support control | 是否只是“更多梯度”而非正确类别支持 |

**停止条件**：如果简单 class-wise threshold、FPL 类基线或全分布 soft KL 在 matched risk/support 下等效解决问题，当前方法残量不足。

## 8.3 第三阶段：最小候选方法

按照单变量顺序：

1. support-deficit detector；
2. detector + 单一异构证据；
3. 加 estimated precision/risk constraint；
4. region only；
5. prototype only；
6. region + prototype；
7. soft promotion vs hard promotion；
8. anchor on/off；
9. matched-support 与 matched-precision 比较。

需要证明的不是“最终 mIoU 上升”这一件事，而是至少满足：

- 支持不足类别的有效 support 上升；
- 在相同 support 下 precision 更高，或在相同 precision 下 support 更高；
- 对应类别 IoU 多 seed 一致改善；
- 非缺失类别没有被明显牺牲；
- 结果跨至少两个迁移方向存在。

# 9. 暂定论文故事线

如果上述假设得到公开数据支持，论文可以按以下逻辑组织：

## Introduction

传统 UDA 伪标签研究多关注整体可靠性和类别平衡，但某些类别可能在多重选择门后几乎得不到实际正监督；仅降低阈值无法恢复从不成为 top-1 的类别。

## Diagnosis

区分真实存在、预测、接受和实际梯度支持，报告 class-wise support starvation、precision–support 前沿以及与类别性能的关系。

## Method

提出 deficit-triggered、risk-constrained 的 non-top1 support expansion，使用异构 region/prototype 证据和轻量 anchor 控制错误与漂移。

## Experiments

以 LoveDA 双向为主，ISPRS 跨城市为外部验证；与 CBST/DARS/CPSL、FPL/soft-label、ProDA/query-region 等最近邻思想做匹配对照；比赛放在 case study 或附录。

## 暂定贡献表达

下面只能作为 `[H]` 草案，不能原样写入投稿稿件：

1. 从“预测频率”进一步区分并操作化目标类别的 realized positive supervision；
2. 提出只对 support-deficit 类别触发的风险约束支持扩展；
3. 利用异构证据验证有限 non-top1 正支持，并通过 matched-support / matched-precision 实验证明其作用；
4. 在多个遥感域偏移方向验证类别性能、precision–support 和稳定性。

# 10. 协作者可立即接手的任务

## T1：最近邻文献矩阵

**产物**：不少于 15 篇的结构化矩阵，重点覆盖 CBST、DARS、CPSL、DAFormer、U²PL、FPL、Enhanced Soft Label、When Confidence Fails、ProDA、UniDAformer 和异构教师工作。

**验收**：逐篇回答是否测量 realized support、是否 deficit-triggered、是否有 risk constraint、是否扩展 non-top1 正支持、证据是否独立。

## T2：术语和假设审查

**产物**：一页“问题定义—替代解释—反证条件”表。

**验收**：能够明确区分 class imbalance、低置信、低 coverage、support starvation 和 gradient starvation；不得只换术语描述已有问题。

## T3：公开数据协议

**产物**：LoveDA 双向 manifest、标签隔离规则、类别映射、ignore 处理、三个 seeds、模型选择和最终评价协议；之后补 ISPRS。

**验收**：训练代码无法访问 target-final 标签；split 可复现；所有调参空间在 final evaluation 前冻结。

## T4：无干预诊断 pilot

**产物**：标准 baseline 在两个迁移方向上的 per-class IoU、hard/soft support、non-empty ratio、precision、coverage 和关键层 gradient proxy。

**验收**：判断 support deficit 是否跨 seed 稳定存在；若不存在，停止方法实现。

## T5：最小方法和匹配对照

**产物**：global threshold、class-wise threshold、top-k/FPL 类基线、单一异构证据和 risk-constrained expansion 的 matched-support / matched-precision 比较。

**验收**：不能仅以最终 mIoU 作为机制证据；需报告完整 precision–support 关系。

## T6：最终选题冻结

**前置条件**：完成 T1–T5 后再确定题目、方法名和贡献。

**停止条件**：最近邻文献已覆盖完整闭环，或实验增益不超过 seed 方差，或 support 变化不能解释类别改善。

给后续协作者的最重要信息不是“我们已经有一个新方法”，而是：

1. **[F]** 项目已经用 matched controls 和强负结果证明，目标软监督、anchor 强度和 hard/soft 形式确实会改变目标域结果；

# 14. 术语表

- **Blind class**：项目内部对目标域显著低召回类别的称呼，不应直接作为通用学术术语。
- **Support**：某类实际获得的正监督；需要区分 hard count、soft mass、曝光频率和梯度贡献。
- **Coverage**：通过选择规则的像素或区域占候选/全目标数据的比例；必须说明分母。
- **Conditional precision**：被接受或被 promotion 的监督中，真实属于目标类别的比例；训练时只能估计，评估时可用隔离 GT 计算。
- **non-top1 promotion**：在主教师未把类别选为 top-1 时，依据独立证据向该类分配有限正监督质量。
- **Source tax**：项目内部对 source continuation 妨碍目标域适配的现象概括；是否普适仍需公共数据验证。
- **Anchor**：限制 target adaptation 漂移的保守约束，可来自 source、冻结教师或参数子空间。
- **Inductive UDA**：最终目标测试图像在训练和适配阶段不可见。
- **Transductive UDA**：训练或适配阶段可访问确切的无标签最终测试图像；必须与 inductive 结果分开报告。
