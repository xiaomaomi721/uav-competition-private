# 冲击 72：复合小策略与异构教师路线研究（2026-09-30）

## 0. 当前锚点与边界

- 当前冠军：`REVERSE_ARMB = 71.045315`。
- 距 72：`+0.954685pp`。
- Arm B：A05 初始化 / A05 D4 教师 / blind classes={Water,Barren,Agricultural} / soft KL / source_coeff=0.1 / target_coeff=1.0 / 2000 steps。
- 每天最多人工提交 2 次；禁止自动提交。
- 最终推理必须为单 checkpoint；训练期允许多教师、蒸馏和官方 test 图伪标签；禁止外部训练图像和推理期多模型融合。

项目内已证：

1. TREAT−CONTROL = +0.5951pp，盲类召回软 KL 有真实因果收益；
2. source-only continuation 相对 A05 = −0.5030pp，source CE 存在明显“source 税”；
3. 纯 target Arm A 比轻 source anchor Arm B 低 0.088066pp，说明完全无锚会漂移/过拟合；
4. test1 扩展+5000步比 Arm B 低 0.028780pp；hard pseudo 比 Arm B 低 1.113170pp；继续同源迭代已接近局部饱和。

因此路线必须分两层：

- **阶段 A：把两个同属“目标域可靠度控制”的小策略合成一个方法，只用 1 个线上槽。**
- **阶段 B：引入当前 A05/Arm B 不具备的异构语义或区域表示，用另 1 个槽验证真正的新信息方向。**

不得把阶段 A 与阶段 B 在第一次线上验证时直接混在一起，否则无法知道异构信息是否有效，也会放大历史上多方法负交互风险。

## 1. 文献核实结果与项目映射

### 1.1 低置信伪标签不能只靠固定阈值

ICCV 2025 **When Confidence Fails / CSL** 指出固定置信度阈值受过度自信影响，会把有用低置信像素丢掉；其方法以样本特定决策边界替代统一阈值，并随机遮蔽可靠像素，让模型从邻近不可靠区域的上下文学习。

来源：
- https://openaccess.thecvf.com/content/ICCV2025/html/Liu_When_Confidence_Fails_Revisiting_Pseudo-Label_Selection_in_Semi-supervised_Semantic_Segmentation_ICCV_2025_paper.html

CVPR 2022 **U2PL** 的互补观点是：不可靠像素未必有可信正类，但仍可作为若干类别的负样本，不必完全丢弃。

来源：
- https://openaccess.thecvf.com/content/CVPR2022/html/Wang_Semi-Supervised_Semantic_Segmentation_Using_Unreliable_Pseudo-Labels_CVPR_2022_paper.html

**项目映射：** Arm B 的固定 `0.98/0.50` mask 已证明方向正确，但不是可靠度建模的终点。第一步不应直接完整复刻 CSL/U2PL，而应先利用已经存在的 D4 多视图信息，对盲类低置信区域做连续可靠度加权，同时给其余目标像素很弱的防漂移约束。

### 1.2 source anchor 与 target anti-drift

DAFormer 的训练策略包含 teacher-student self-training、rare-class sampling、ImageNet feature-distance regularization 和 warmup，目的之一是稳定适配并缓解常见类偏置；其论文增益来自标准 UDA 基准，不能外推到本比赛。

来源：
- https://openaccess.thecvf.com/content/CVPR2022/html/Hoyer_DAFormer_Improving_Network_Architectures_and_Training_Strategies_for_Domain-Adaptive_Semantic_CVPR_2022_paper.html

CVPR 2024 **Stable Neighbor Denoising** 将目标样本分为稳定/不稳定，用相关稳定邻居通过双层学习指导不稳定样本，并以 object paste 补偿弱类。其核心证据支持“防漂移应来自稳定目标证据，而不一定要来自 source CE”。

来源：
- https://openaccess.thecvf.com/content/CVPR2024/html/Zhao_Stable_Neighbor_Denoising_for_Source-free_Domain_Adaptive_Segmentation_CVPR_2024_paper.html

**项目映射：** Arm B 的 source=0.1 是已证有效护栏，但护栏携带 source 域偏。可尝试把它替换为全目标域、弱权重的 teacher consistency anchor。

### 1.3 SAM 只能提供区域时，不会自动提供正确语义

WACV 2024 **Segment Anything, From Space?** 在多种遥感任务上发现 SAM 表现依任务和分辨率显著变化；小目标、尺度变化、俯视域差以及道路等细长/类级连续目标是明显困难。SAM mask 不能直接当遥感真值。

来源：
- https://openaccess.thecvf.com/content/WACV2024/html/Ren_Segment_Anything_From_Space_WACV_2024_paper.html

CVPR 2024 **GoodSAM** 的关键范式是：SAM 提供空间区域，但没有语义；另一个 semantic teacher assistant 提供类别预测，二者融合后再蒸馏给紧凑学生，部署时使用学生。

来源：
- https://openaccess.thecvf.com/content/CVPR2024/html/Zhang_GoodSAM_Bridging_Domain_and_Capacity_Gaps_via_Segment_Anything_Model_CVPR_2024_paper.html

T-IV 2024 **SAM4UDASS** 同样采用 semantic-guided mask labeling，把 UDA 语义伪标签分配给 SAM masks，并做融合以减少 SAM 实例粒度与语义标签粒度不匹配；其动机包括改善 majority-class bias 以及 rare/small classes。

来源：
- https://github.com/ywher/SAM4UDASS

**项目映射：** 只用 Arm B 给 SAM mask 赋类，可改善区域同质性和边界，但仍不能召回 Arm B 完全没认出的类别。它是“结构异构”，不一定是“语义新信息”。冲 72 的主候选需要再加入独立的类别证据。

### 1.4 基础模型特征 + 类别原型 + SAM 区域，是更完整的异构路线

IEEE TIP 2025 **Learning From Vision Foundation Models for Cross-Domain Remote Sensing Image Segmentation (LFMDA)** 包含：

- Prototypical Contrastive Knowledge Distillation，用于域不变且类别可分的特征；
- Local Region Homogenization，使用 SAM 生成/扩充区域伪标签。

来源：
- https://pubmed.ncbi.nlm.nih.gov/40668721/

CVPR 2022 **CIRKD** 则通过 pixel-to-pixel 与 pixel-to-region 关系蒸馏、像素/区域 memory queues，把跨图像结构关系传给学生；这些组件仅用于训练，推理使用学生网络。

来源：
- https://openaccess.thecvf.com/content/CVPR2022/html/Yang_Cross-Image_Relational_Knowledge_Distillation_for_Semantic_Segmentation_CVPR_2022_paper.html

2025 **RS-MTDF** 在遥感半监督分割中使用冻结 DINOv2 与 CLIP 作为互补教师，进行特征级蒸馏并融合进学生解码器，在 Potsdam、LoveDA、DeepGlobe 上研究；摘要页未明确给出部署移除教师的全部实现细节，需核代码后才能确认比赛落地。

来源：
- https://arxiv.org/abs/2506.08772

CVPR 2025 **SegEarth-OV** 说明 CLIP 类开放词表特征可用于遥感语义图，但需要处理 patch token 全局偏置并恢复空间细节；它是训练自由开放词表推理方法，本身不能直接作为比赛提交推理链，只适合作为离线教师信号来源。

来源：
- https://openaccess.thecvf.com/content/CVPR2025/html/Li_SegEarth-OV_Towards_Training-Free_Open-Vocabulary_Segmentation_for_Remote_Sensing_Images_CVPR_2025_paper.html

**项目映射：** 最有针对性的异构主线不是“把 SAM mask 当标签”，而是：

1. 用冻结基础模型的 dense feature 和官方 source GT 建立类别原型；
2. 用这些原型给 target 产生独立类别证据；
3. 用 SAM/SAM3 masks 聚合为区域级证据；
4. 只在 Arm B 低可靠且异构证据高可靠时 rescue；
5. 最终蒸馏回单个 SegFormer-B3。

## 2. 阶段 A：一个槽的复合小策略

### 2.1 方法命名

**RWTA：Reliability-Weighted Target Anchor（可靠度加权目标域锚）**。

它不是把两个互不相关的 trick 硬叠，而是把“D4 可靠度选择”和“mask 外防漂移”统一成一张连续像素权重图。

### 2.2 保留不变

- student init = A05；
- teacher = A05 D4 TTA8；
- test2 1300；
- trainable = stage2 + stage3 + decode head；
- optimizer/LR/2000 steps/seed/replay/strong_photo 与 Arm B 相同；
- Bstar、打包和推理协议完全不变；
- 最终单 checkpoint。

### 2.3 唯一方法变化

当前 Arm B：

```text
M_high  = conf >= 0.98
M_blind = predicted_class in {Water,Barren,Agricultural} AND conf >= 0.50
M       = M_high OR M_blind
L       = 0.1*L_source + 1.0*KL[M]
```

RWTA：

```text
source_coeff = 0

D4 teacher views -> p_v, v=1..8
p_bar = frozen A05 D4 mean teacher distribution

stable_i = function(vote_agreement_i, JS(p_v || p_bar)_i)

pixel weight w_i:
  conf >= 0.98:
      w_i = 1.0
  blind class AND 0.50 <= conf < 0.98:
      w_i = mu + (1-mu)*stable_i
  all remaining target pixels:
      w_i = mu

L_RWTA = sum_i w_i * KL(p_bar_i || p_student_i) / sum_i w_i
```

设计理由：

- 保留已经证明有效的高置信分支，不用 D4 gate 删除它；
- 只对最有噪声风险的“盲类低置信 rescue”按 D4 稳定性连续加权，不做新的硬删阈值；
- mask 外仍以极弱 KL 固定在 A05 目标域函数附近，替代有域偏的 source CE；
- 三段权重属于一个统一的 reliability weighting 方法，可用一个线上包裁决。

### 2.4 mu 的冻结方式

禁止线上扫 `mu`。先在固定 target replay 的 100–200 个 batch 上测：

```text
G_main = ||grad(stage2+3, weighted selected KL)||
G_rest = ||grad(stage2+3, complement KL)||
```

一次性令：

```text
mu * G_rest / G_main ≈ 0.10～0.15
```

并预注册 clamp 范围，例如 `[0.02, 0.15]`。这是根据梯度预算选择稳定器强度，不是用 leaderboard 调参。

### 2.5 离线可归因性

虽然线上只交 full RWTA，一个训练运行仍必须同时记录：

- high-confidence、blind-rescue、complement 三段覆盖率；
- 每段未加权 KL、加权 loss、stage2/3 梯度范数；
- blind rescue 的 D4 vote/JS 分布；
- candidate vs Arm B 的 flip，按三段分解；
- source canonical guard（只防崩，不排序）。

另外可从同一 full checkpoint 构造：

```text
d_RWTA = theta_RWTA - theta_A05
```

并在不训练的情况下做 layer-wise/scale behavior probe；这些 probe 不自动获得线上槽。

### 2.6 预注册线上判据

相对 Arm B 71.045315：

- `>= +0.15pp`：成为新基线，机制强；
- `+0.05 ~ +0.149pp`：有效小轴，保留用于参数合成；
- `-0.05 ~ +0.049pp`：无实质价值，关闭；
- `< -0.05pp`：target-only weak anchor 不足，保留 Arm B。

**预期增益没有论文或项目直接保证。** 规划估计为 `0 ~ +0.20pp`，也可能为负。

## 3. 阶段 B：异构新信息主线

### 3.1 方法命名

**HPRT：Heterogeneous Prototype-Region Teacher（异构原型—区域教师）**。

第一版不做全特征强制对齐，也不把 SAM mask 当真值；先构造可审计的离线异构 teacher，再蒸馏到单 B3。

### 3.2 两类异构证据

#### 语义证据：基础模型类别原型

候选 encoder：

1. SAM3 vision encoder dense features；
2. DINOv2 dense features；
3. 若许可、权重和空间分辨率可控，再考虑 CLIP/SegEarth 风格特征。

仅使用官方 source 图像和 GT：

```text
对每类 c：从 source GT 区域采集 frozen VFM feature
建立 K 个 prototype_{c,k}
```

K>1 用来覆盖同一类别的多域/多纹理模式；聚类只使用官方数据。

目标图像上：

```text
p_proto(c|pixel) = softmax(max_k cosine(feature, prototype_{c,k}) / T)
```

这提供独立于 A05/Arm B classifier 的类别证据。

#### 空间证据：SAM/SAM3 区域

在官方 target 图像上生成 masks。对每个 mask 聚合：

- prototype class distribution；
- Arm B class distribution；
- D4 稳定性；
- region purity/margin。

SAM 只负责区域支持，不单独决定语义。

### 3.3 Rescue 规则

从 Arm B checkpoint 开始，而不是从 A05 重走同源适配。

```text
若 Arm B 可靠：
    teacher = Arm B soft distribution

若 Arm B 低可靠，且某个异构 region：
    - source holdout 上该类别 teacher precision 已通过资格门
    - target D4 下 region/class 稳定
    - prototype margin 足够
    - SAM mask 区域纯度足够
则：
    teacher = convex combination(Arm B, prototype-region distribution)

其余：
    teacher = Arm B weak anchor
```

训练损失：

```text
L = L_rescue_soft_KL + lambda_anchor * L_ArmB_anchor
```

禁止第一版直接用 hard pseudo。

### 3.4 教师资格测试（不消耗提交）

自动/开放词表 teacher 在 source 上必须先过资格门。必须使用修正后的 canonical GT 映射，禁止旧 `gt.max()>7` 逻辑。

建议：

- H300：只用于 prompt/温度/阈值冻结；
- R1099：完全冻结验证；
- 按图 bootstrap，而非按像素假装独立样本；
- 对每类测：precision、recall、IoU、Arm B error correction、Arm B correct corruption、region D4 stability；
- 只有 `corrected > corrupted` 且置信下界为正的类别开放 rescue；
- 对道路等 SAM 已知困难的细长连续类别默认不开放，除非官方 source 验证强证据推翻。

目标域无 GT，只允许使用：

- D4 稳定性；
- 与 Arm B 高置信种子的区域一致性；
- 类别份额和连通区域 sanity；
- 这些都不得称准确率。

### 3.5 教师优先顺序

先在 source qualification 上做 bake-off，不占线上槽：

1. **SAM3 concept masks**：若文本/样例概念能在 source 上对某些类取得高 precision，可直接提供新类别语义；
2. **DINOv2/SAM3 feature prototypes + SAM masks**：若 concept masks 不稳定，这是首选；
3. **纯 SAM semantic-guided refinement**：只提供结构，不提供新语义，作为低风险备份；
4. **全 feature KD/CIRKD**：若 prototype-region teacher 没有可靠离散 rescue，但 feature relation 显示明显可分性，再做第二代。

项目历史 Exp31 的 DINOv2 蒸馏只有小收益，说明“source 上全局 feature KD”不是大杠杆；本路线只有在变成“目标域 + source-GT prototypes + region rescue”后才算新实验，不能把旧 Exp31 当作成功保证。

### 3.6 预注册线上判据

相对 Arm B：

- `>= +0.20pp`：异构信息主线成立；
- `+0.05 ~ +0.199pp`：有异构小轴，进入参数合成，不立即继续堆教师；
- `-0.05 ~ +0.049pp`：异构 teacher 没提供部署价值；
- `< -0.05pp`：qualification 未迁移，关闭当前 teacher/gate。

论文只能证明机制在其他数据集可行，**不能支持本比赛 +0.3/+0.5 的数字承诺**。

## 4. 每日 2 槽策略

### 第一个有正式候选的提交日

| 槽 | 候选 | 科学问题 |
|---|---|---|
| 1 | RWTA full composite | 能否用目标域弱 anchor 替代 source 税，并用 D4 稳定性降低盲类 rescue 噪声？ |
| 2 | HPRT v1 | foundation prototype + SAM region 是否提供 Arm B 没有的新类别/区域证据？ |

两包都直接与冻结 Arm B 比，不重复提交 Arm B；前提是完全复用 byte-exact 推理/打包路径。

### 次日决策树

#### 两者都正

- 槽1：参数空间合成：`ArmB + alpha*d_RWTA + beta*d_HPRT` 的一个预注册低维候选；
- 槽2：保留给合成的单一对照（例如最佳单轴的 layer-wise 版本），不做大网格。

不得先把两个 loss 合进一条训练轨迹；历史负交互风险高。

#### 仅 RWTA 正

- 新基线 = RWTA；
- 下一槽继续异构 teacher 的第二种信号（concept vs prototype-region），不扫 RWTA 的 mu。

#### 仅 HPRT 正

- 新基线 = HPRT 或保留为异构轴；
- 下一槽测 HPRT 与 Arm B 的参数中点/分层轴，不继续同源 selector 扫描。

#### 两者都负

- Arm B 保持冠军；
- 关闭同源小改；
- 重新审计异构 teacher qualification，只有换到真正不同的 teacher 信号后才再提交。

## 5. 哪些可以合并，哪些必须独立

### 第一包可合并

- D4 稳定度；
- blind low-confidence 连续权重；
- mask 外 weak target anchor；
- source CE 移除。

原因：它们共同定义一张 target reliability weight map，是一个统一方法。

### 第一轮绝对不与 RWTA 合并

- SAM/SAM3 proposal；
- DINO/CLIP/SAM3 feature prototype；
- prototype contrastive loss；
- CIRKD relation loss；
- 新 decoder/adapter。

原因：这些改变知识来源或表示空间。若直接合并，线上一个分数无法判断新信息是否有效，也容易发生负交互。

### 暂不进入首轮

- 完整 CSL 的 learnable convex selector + reliable-pixel random masking；
- U2PL negative queues；
- stable-neighbor bilevel learning；
- DACS ClassMix；
- 多基础模型同时全量 feature fusion。

它们有论文机制依据，但相对本项目首轮实现变量太多，应在 RWTA/HPRT 判决后再决定。

## 6. 风险排序

| 路线 | 新信息强度 | 工程成本 | 线上成功把握 | 合规风险 | 备注 |
|---|---:|---:|---:|---:|---|
| RWTA | 低 | 低-中 | 中 | 低 | 主要解决 source anchor 与可靠度，不足以单独保证 72 |
| SAM-only refinement | 中（结构） | 中 | 中低 | 低-中 | 不能自动补语义盲区 |
| VFM prototype + SAM region | 高 | 高 | 未知但最值得 | 中 | 最符合“新语义+新区域表示”目标 |
| 全 feature KD | 中 | 高 | 中低 | 低-中 | 历史 DINO KD 仅小分，跨架构错配风险 |
| CLIP/open-vocab 直接伪标签 | 高 | 中-高 | 低-未知 | 中 | 类名歧义、空间分辨率和遥感域偏明显 |
| 多方法同轨联合训练 | 不确定 | 很高 | 低 | 中 | 历史负交互，不推荐首轮 |

合规上还必须补：模型汤许可的一手答复截图；任何新的 SAM3/CLIP/DINO 权重需记录许可证、公开学术权重来源、SHA，并确保训练时只读取官方图像。

## 7. 最终判断

1. **可以合并小策略**，但应合并成 RWTA 这一张统一可靠度权重图，而不是把多个论文模块堆进一个训练脚本。
2. RWTA 只占 1 个线上槽；另一个槽必须留给 HPRT 异构新信息候选。
3. SAM mask 本身不是足够的新语义。最有依据的主路线是：**基础模型 dense feature → 官方 source GT 类别原型 → target 独立类别证据 → SAM/SAM3 区域聚合 → 只在 Arm B 低可靠区 rescue → 蒸馏回单一 B3。**
4. 71.045→72 仍没有任何文献或项目证据可保证。更现实的成功结构是：RWTA 提供小轴，HPRT 提供较大新轴，最后用单-checkpoint 参数空间合成收口。
5. 在异构 teacher qualification 完成前，不应消耗第二个槽；每天两个名额是上限，不是必须用满的配额。
