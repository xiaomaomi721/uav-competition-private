# MixUp / CutMix 数据增广研究结论（低空航拍语义分割专项）

> 来源：深度调研（2026-09-01）
> 用途：决定"老师数据增广方向"里 MixUp/CutMix 是否值得做、怎么做
> 关键结论：**MixUp 完全不对抗"场景位置依赖"根因（对症），是 CopyPaste 之外的真新方向；但收益预期低（校准量级），别指望突破。**

---

## 一、一页结论

| 问题 | 结论 |
|---|---|
| MixUp | 整图像素线性混合，无空间位移 → **完全不对抗位置依赖（对症）** |
| CutMix | 整块区域连背景带目标一起搬 → 弱对抗，比 CopyPaste 轻一个数量级 |
| ClassMix/HalfMix | = CopyPaste 高精度变体，**直接踩已证伪的雷，不推荐** |
| 收益预期 | **[推断] 独立增益≈校准量级（0.1~0.3），不会突破；主要价值=校准正交补充** |

**对我们假设的验证**：CopyPaste 失败根因 = 单目标从原场景剥离随机投放（车离开道路）。MixUp 整图一起混，没有任何目标被单独搬走 → **位置依赖零破坏，完全对症**。CutMix 连背景带目标一起搬 → 弱对抗。

## 二、机制（实证）

- **MixUp**：`x̃=λ·x_i+(1−λ)·x_j`，λ~Beta(α,α)，原文 α∈[0.1,0.4] 默认 0.2；分割标签=两支 CE `λ·CE(pred,y_A)+(1−λ)·CE(pred,y_B)`，λ 全图标量
- **CutMix**：随机矩形 patch 覆盖，λ=patch面积/图面积，label 按 patch 空间混合；中心点采样后反推框边长
- **实现位置**：必须写在 loss 层（需要双 label+λ 驱动梯度）；mmseg 无内置 batch MixUp/CutMix，需自己写（几十行，低成本）

## 三、关键发现

1. **[实证] MixUp 改善校准**（Thulasidasan 2019）：显著降低过置信，接近温度缩放效果。**与我们"模型自信地错+校准双维收敛"实证是同一类药**——MixUp 是校准的"模型侧"补充，与已有"决策侧"校准正交。
2. **[实证] CutMix 面积label credit 对小目标有偏**：patch 面积≠目标语义占比。车辆全图仅 0.91%，随机 CutMix patch 里大概率没车辆，label 却按面积加权重 → 对少数类无帮助。**随机 CutMix 对车辆不平衡几乎无用**。
3. **[实证] mmseg 无内置 batch MixUp/CutMix**——需自己写。
4. **[推断] 完全监督分割里 MixUp 作为普通增广的收益证据少且弱**——主流分割基线增广栈通常没有 MixUp。诚实：我们的用法文献未充分验证。

## 四、风险

- MixUp 制造真实分布不存在的"中间颜色"——但我们低饱和，产物大概率仍在合理域，风险比色彩抖动低；**必须小 α 温和混合**
- λ 过强混合会平均掉边界/小目标细节 → 分割里 λ 分布整体偏小
- 与 label smoothing/先验偏移交互：MixUp 软标签≈label smoothing，与校准/prior-shift 作用环节不同（损失构造 vs 输出调整）理论可叠加，**但总软化强度克制**
- **同域验证集会骗人**——必须走"训练→提交→看线上分"闭环，别用本地分枪毙/背书

## 五、落地建议（按用户"先研究再实现"纪律，三个配置候审）

### 建议 A（主推）：温和整图 MixUp
- `λ~Beta(0.1,0.1)`（比原文更小）；应用概率 0.5；每 batch 随机配两张图；只对有效像素算两支 CE（ignore 掩掉）
- 理由：小 α 不污染"灰色团靠形状"纹理信号；软标签压过置信（对症自信地错）；与校准/prior-shift 正交；不制造空间伪影

### 建议 B（次选）：小面积 CutMix
- `λ~Beta(1.0,1.0)` 但 **patch 面积 ≤ 全图 25~30%**；应用概率 0.3~0.5
- 理由：patch 边界保留真实高分辨率纹理 → 给"细窄道路/形状几何"提供锐利边缘监督（对症被 32× 抹掉的细窄目标）
- 风险：patch 内可能无车辆/荒地（面积 credit 错配）→ 对少数类无增益

### 建议 C（观察项，先不做）：类别感知 CutMix
- 只在参考图含车辆/荒地时触发，patch 对准少数类 bbox
- 但"车辆只在道路"硬场景依赖下仍有 CopyPaste 式风险 + 超参变多 → **优先级最低，先跑 A/B 看线上**

## 六、与已有方法的组合纪律
- 不混 TTA/Lovász/EMA（已判死）；可放心与校准/prior-shift/植被 bias 叠加（不同环节）
- **务必线上闭环**：每个配置 1 次提交裁决，负收益即放
