# 新论文调研：与"盲类召回测试域自训练"正交/强化的方法（2026-09-27）

> 背景：用户要求"研究新论文找新方法，72 是下一步目标不是一步到位"。本文档诚实记录两篇高相关新论文的机制与适用性判断。

## 结论摘要

两条真正相关的线，都不是假大空：

| 论文 | 机制 | 与当前方案关系 | 何时做 |
|---|---|---|---|
| **CSL** (When Confidence Fails, ICCV 2025, arXiv:2509.16704) | 伪标签选择建模为置信度分布空间的凸优化，样本特定决策边界 + 可靠像素随机 mask 逼学低置信区上下文 | 强化 TREAT 的盲类召回（当前 TREAT 是它的弱版本） | TREAT 线上结果若证明盲类召回方向成立，则升级 |
| **DA-Cal** (TIP 2026, arXiv:2602.20860) | Meta Temperature Network 生成像素级校准温度，双层优化绑定软伪标签与 UDA 监督，domain-mixing 防过拟合，推理零开销 | 校准从"8维常数 Bstar"升到"像素级元温度"，与 TREAT 正交 | 独立可行，成本中等 |

## CSL 细节（When Confidence Fails）

- 痛点：① 网络过度自信，正确/错误预测在高置信区重叠，固定阈值分不开，放大认知偏差；② 直接丢低置信像素破坏空间语义连续性。
- 方法：伪标签选择 = 置信度分布特征空间里的凸优化 → 样本特定决策边界；再随机 mask 可靠像素，逼网络从低可靠区域学上下文。
- 与我们的对应：盲类（Barren 0.29% / Agricultural / Water）正是"正确但低置信"像素，被 0.98 阈值当不可靠删掉。当前 TREAT 用"盲类单独降阈值 + 软 KL"，是 CSL 的弱版。

## DA-Cal 细节

- 关键洞察：跨域下软伪标签替换硬伪标签反而掉分，根因是校准差（置信度与准确率错位），完美校准的软标签理论等价硬标签。
- 方法：Meta Temperature Network 出像素级校准参数；双层优化建立软伪标签与 UDA 监督关系；domain-mixing 防过拟合。
- 意义：我们现在用固定 8 维 Bstar（+1.9 分，项目最大单项）；DA-Cal 是这条线的高分辨率版本，明确"嵌入自训练框架、推理零开销"。

## 项目内适用性判断

1. CSL 的"低置信区上下文学习 + 样本特定边界"与当前盲类召回**同向强化**，不是替代。先等 TREAT 线上结果确认方向，再升级。
2. DA-Cal 是**独立正交**的校准提升线，但需新增训练模块（Meta Temperature Network + 双层优化），实现成本中等，且项目纪律"训练期方法不可叠加"（CWFA+no-decay 互相摧毁的历史教训）意味着它必须单独成臂、不能直接叠进当前 TREAT。
3. 两者都不应该"学了不用"：CSL 对应我们已实锤的盲类丢分结构，DA-Cal 对应已实锤的"校准是最大单项(+1.9)"。这是"学了用得上"的候选，而非假大空。

## 未证部分（诚实标注）

- 两篇论文都在 Pascal/Cityscapes/COCO 上验证，**没有航拍 8 类、目标域无 GT、源域 5597 张**这种设定的直接证据。增益量级在本赛题未验证。
- CSL/DA-Cal 的增益是"弱 base 上 +X"，迁移到 70.775 强 base 会衰减（项目历史规律：增益衰减 30~50%）。
