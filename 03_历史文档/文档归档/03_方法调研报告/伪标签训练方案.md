# 伪标签训练方案任务单（P3）

## 一、为什么做

核心问题：训练域 ≠ 测试域（本地↔线上负相关，Spearman=0.4）。

伪标签是唯一能**把测试域数据直接送进训练**的手段——用已有模型对 500 张测试图生成伪标签，按置信度过滤后与 6996 张真标签混合训练，模型直接"见过"测试域。

已授权前提：
- 可以使用提供的测试集做 TTA 和伪标签（用户明确授权）
- 不限提交次数（可反复验证）

## 二、生成器模型选择（关键决策）

用**线上最强的模型**生成伪标签（伪标签质量直接决定上限）。决策规则：

| Exp17(CWFA) 结果 | 用哪个生成伪标签 |
|---|---|
| 线上大涨 | Exp17（CWFA 特征级域鲁棒，伪标签质量最好） |
| 线上平平 | Exp14（当前线上最高 66.44，最稳） |
| Exp18(B3) 线上涨 | 评估 B3 与 B2 谁线上高用谁 |

生成时叠加 TTA（多尺度+翻转概率平均），提升伪标签精度。

## 三、伪标签生成参数

- 脚本：`scripts/generate_pseudo_labels.py`（已写好）
- 置信度阈值：默认 0.90，先跑一次看 overall_confident_ratio，再定 0.85 / 0.90 / 0.95
- TTA：scales (0.5, 0.75, 1.0, 1.25) + hflip
- 输出：`<output>/pseudo/images/*.png` + `pseudo/masks/*.png`
- mask 空间：train-ID 0-7 + 255 ignore（低置信像素置 ignore，不参与训练）

## 四、训练集成方式（需改 dataset 支持）

当前 `dataset.py` 硬编码从 `train/images` + `train/masks` 读官方 mask 并做 `official_to_train` 映射。伪标签 mask 已经是 train-ID 空间，需加一条路径：

1. 新增 split 文件 `splits/train_pseudo.txt`，列出 6996 真标签 + 500 伪标签 stem；
2. dataset 增加 `pseudo` 子集：伪标签样本直接读 `pseudo/masks/*.png` 作为 train-ID，跳过 `official_to_train`；
3. 采样比例：伪标签占每个 batch 约 10-20%（500/6996 ≈ 7%，可适当上调采样权重，避免被真标签淹没）。

## 五、实验设计（单变量，线上验收）

- 基线：Exp14（B2+1024+CE+rare_crop）
- 变量：伪标签（阈值 T）+ 混合采样比例
- 训练：56000 步，与 Exp14 完全同配置，仅数据变了
- 验收：线上分，与 Exp14 的 66.44 对比

## 六、风险与边界

1. **伪标签质量风险**：模型在测试域本身有误差，错误伪标签会强化错误。→ 用高阈值（0.90+）只信高置信像素。
2. **label 空间**：伪标签 mask 是 train-ID，不能二次映射。集成时必须在 dataset 层区分真/伪样本。
3. **合规**：伪标签来自官方测试集，不引入外部数据，符合规则。
4. **提交**：伪标签训练后的模型仍是单模型，正常提交。

## 七、依赖与触发条件

- 依赖：Exp17 线上结果（决定生成器模型）
- 触发：主线 P1/P2 若线上提升不足，或直接作为并行备选上
- 前置：需先完成 dataset 的 pseudo 子集改造（中成本，约半天）
