# MaxEnt + 区域对比损失（补 MaxEnt 未覆盖的区域级吞并）

> 2026-09-05。用户批准方向：不套旧框架(校准/加权CE)，补 MaxEnt 真正缺失的边缘。
> 触发：混淆分析证明 MaxEnt 解决分布对齐(输出端)但留下"农田/建筑→背景"区域级吞并(像素端)。

## 一、诊断链（为什么是这个问题）
1. 训练域≠测试域 → MaxEnt(CE−λH)让输出分布对齐测试(预测vs测试真偏差0.009) ✅已解决
2. 但 MaxEnt 留下残余错误: **农田−1.29M / 建筑→背景−0.7M** = 区域级吞并
3. 诊断早证: 混淆是区域级非边界级, 错误66%在区域内部, 灰色团RGB距离仅3-15
4. SegFormer解码只用stage4(1/32)+1×1上采样 = **缺区域级聚合** → 单像素"深绿"难辨农田vs背景

## 二、方案：双目标 = MaxEnt(输出端) + 区域对比(特征端)
```
total_loss = [CE − λH(pred)]  ← MaxEnt 保留, 管分布对齐
           + α · L_region       ← 新增, 管区域判别
```
L_region 设计（用真值 mask 在特征图上分区域）：
- 对特征图 F(B,C,H,W)，用真值 mask(下采样到F尺寸) 得每像素区域归属
- 每个语义区域(或每类)算**区域中心特征** c_k
- **拉近**: 区域内像素特征 ↔ c_k（一致性）
- **拉远**: 不同类区域中心之间（可分性）
- 用 cosine 或简单 InfoNCE

## 三、为什么对症且符合规律
| 已验证规律 | 本方案符合 |
|---|---|
| 有效方法=不扭曲监督的表示增强(CWFA/MixStyle/蒸馏) | 区域对比=特征端表示约束, 不碰CE |
| 不同机制层可叠(蒸馏+MixStyle可叠) | MaxEnt输出端 vs 区域对比特征端, 层不同 |
| CWFA(按类特征聚合)正收益 | 区域对比是其"显式一致性"版本, 更对症吞并 |
| 加权CE/Focal(扭曲损失)全负 | 本方案不动CE |

## 四、风险
1. 区域对比用真值 → 监督式, 可能和CE冲突(需小α)
2. 少数类区域小(车辆) → 对比信号弱, 需类平衡
3. 计算开销: 特征图上分区域+算中心, 需smoke测显存
4. 可能踩"训练期技巧全负"雷(但它是表示级非损失级)

## 五、实施步骤（先smoke后全量）
1. 在 losses.py 加 RegionContrastLoss (用stage3/4特征+真值)
2. 配置: loss=ce_maxent_region, 参数 λ(H)+α(region)
3. 40步smoke看loss/mIoU/显存
4. 若OK: 全量56000步(5597旧切分! 不是6796), 出standard+校准看线上
5. 对照: exp49(MaxEnt,67.77) 作基线, 看叠加region能否破
