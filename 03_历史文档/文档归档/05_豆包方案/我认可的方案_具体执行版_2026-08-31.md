## 一、我的核心判断（三句话）

1. **真正的分数瓶颈是"灰色团四类视觉不可分"**（背景/建筑/道路/车辆 RGB 全在 117~129 灰阶，建筑vs车辆 RGB 距离仅 3），只能靠形状几何+空间上下文+纹理区分，颜色完全没用。
2. **提大分的全是测试时先验（+2.0），训练期只贡献小分（+0.63），但测试时先验已榨干到 69.28。** 要突破只能靠训练期补"形状/纹理表示能力"，而不是继续调校准。
3. **训练期方法中，最对症灰色团形状区分的是"边界/形状辅助监督"**——5 个独立工作一致验证，SaCBL 摘要逐字命中"缓解类间高相似对边缘预测的影响"，且落地成本最低（只加辅助损失，不重构架构）。

## 二、我推荐的方案（主线 + 副线 + 零成本）

### 主线（第一优先，最可能突破 69.28）

**边界/形状辅助监督（基于 B3+CWFA 主模型加辅助边界分支）**

这是我最看好的方向，原因：
- 直接对症核心难点（灰色团靠形状区分，颜色分不开）
- 5 个独立工作（SaCBL/BaAFN、ABSM/BGSC-Net、BFEM/MSCSCNet、BS/MCCANet、SPENet）一致报告有效
- 落地成本最低：只加一个辅助边界分支 + 生成 pseudo-boundary，不改动 SegFormer 主体，不破坏预训练权重
- 与 CWFA 机制不同类（CWFA=特征扰动正则，边界监督=辅助损失），理论上可叠加

**具体设计：**

| 组件 | 设计 | 参数 |
|---|---|---|
| 基础模型 | SegFormer-B3 + CWFA（ε=4） | 保持当前最强训练配置不变 |
| pseudo-boundary 生成 | 欧氏距离变换（distance_transform_edt），不是 Sobel、不是形态学 | radius=5（先试 5，再扫 3/7） |
| 边界辅助分支 | 解码头加一个 1×1 卷积，输出 1 通道边界图 | 从解码头融合后的特征接出 |
| 边界损失 | BCE（边界像素 vs 非边界像素） | λ_boundary=0.2（先试 0.2，再扫 0.1/0.3/0.4/0.5） |
| ignore 处理 | ignore 区域（id=0/255）的边界必须 mask 掉，不参与边界损失 | 强制 |
| 总损失 | CE_loss + λ_boundary × boundary_loss | — |

**pseudo-boundary 生成代码（核心，distance_transform 软边界）：**
```python
from scipy.ndimage import distance_transform_edt
import numpy as np

def gen_soft_boundary(mask, radius=5, ignore_index=255):
    """
    mask: (H,W) 单通道标注，像素值=类别ID
    返回: (H,W) 二值边界图，1=边界，0=非边界
    """
    H, W = mask.shape
    boundary = np.zeros((H, W), dtype=np.uint8)
    # 对每个类别单独算边界（类间边界）
    for cls_id in np.unique(mask):
        if cls_id == ignore_index or cls_id == 0:  # skip ignore
            continue
        cls_mask = (mask == cls_id).astype(np.uint8)
        # 距离变换：前景内部距离+背景内部距离
        dist = distance_transform_edt(cls_mask) + distance_transform_edt(1 - cls_mask)
        # 距离小于 radius 的像素 = 边界附近
        cls_boundary = (dist > 0) & (dist <= radius)
        boundary = np.maximum(boundary, cls_boundary.astype(np.uint8))
    # ignore 区域置 0（不参与边界损失）
    boundary[mask == ignore_index] = 0
    boundary[mask == 0] = 0  # id=0 也是忽略类
    return boundary
```

**关键注意（避免重蹈 Lovász 覆辙）：**
- ⚠️ Lovász -0.415 的根因是"直接优化分割边界的 IoU，而边界本身无像素级真值"。我们的方案不同：用独立的边界预测分支 + BCE 辅助损失，引导模型学形状特征，不是直接优化分割边界的 IoU。
- ⚠️ pseudo-boundary 有噪声，所以 λ_boundary 必须小（从 0.2 开始，不要一上来就 0.5+）。
- ⚠️ ignore 区域的边界必须 mask 掉，否则模型会拟合标注噪声。
- ⚠️ 车辆边界像素极少，边界损失可能对车辆有害——如果线上车辆 IoU 明显下降，考虑只对多数类（背景/建筑/道路/农田/植被）算边界损失，车辆不参与。

**执行步骤：**
1. **smoke 测试**（必做）：用 100~200 step 跑一下，确认：① loss 正常下降 ② 主任务 mIoU 不崩 ③ 边界分支有梯度回传 ④ 显存够。smoke 通过再正式训练。
2. **正式训练**：56000 步，保存 best mIoU checkpoint。
3. **标准版提交**：无 TTA、无校准，看线上分。**成功判据：标准版 > 67.37**（B3+CWFA 基线）。
4. **如果标准版 > 67.37**：套旋转 TTA 8 视图 + 六维校准（背景−0.2/荒地3.6/水体0.70/车辆−0.50/植被0.40），看是否 > 69.28。
5. **参数扫描**：如果正收益，扫 λ_boundary（0.1/0.3/0.4/0.5）和 radius（3/7），找最优组合。
6. **止损条件**：如果标准版 ≤ 67.37，或 smoke 阶段主任务 mIoU 崩，或车辆 IoU 暴跌且无法通过只对多数类算边界来修复 → 放弃此方向，转副线。

### 副线 1（第二优先，与主线并行跑）

**DINOv2 特征蒸馏（外部知识注入，补纹理表示）**

这是唯一"外部知识注入"路线，对症灰色团纹理表示。但 DINOv2 不熟航拍细粒度，所以用 cosine 只对齐方向、不对齐幅值。

**具体设计：**

| 组件 | 设计 | 参数 |
|---|---|---|
| 学生 | SegFormer-B3 stage3 特征（最深语义层，32×32） | 不逐 stage 蒸馏（DINOv2 只有单尺度输出） |
| 教师 | DINOv2-large patch 特征（去 CLS，1024 维，37×37） | 教师输入 resize 到 518×518（DINOv2 原生），学生保持 1024×1024 |
| 投影层 | Conv1×1：512→1024 | 学生特征投影到教师维度 |
| 教师特征上采样 | 37×37 → 32×32（bilinear） | — |
| 蒸馏损失 | cosine 距离（1-cos_sim），只对齐方向 | λ_distill=0.3（先试 0.3，再扫 0.1/0.5/1.0/2.0） |
| 总损失 | CE_loss + λ_distill × cosine_loss | — |
| 基础模型 | SegFormer-B3 纯 CE（**不加 CWFA**，先单测蒸馏） | — |

**关键设计理由：**
- 只蒸馏 stage3（最深语义层）：灰色团区分需要高层语义上下文，浅层（stage0/1）是低层纹理，蒸馏价值低且易过约束。
- 用 cosine 不用 MSE：DINOv2 不熟航拍细粒度，MSE 会强迫学生模仿教师不擅长的航拍幅值；cosine 只对齐语义方向，更宽松。
- 不加 CWFA：蒸馏和 CWFA 都是训练期方法，需先单测蒸馏正收益，再考虑叠加（机制不同类，理论上可叠，但必须先单测）。

**执行步骤：**
1. smoke 测试：确认蒸馏损失可算、梯度可回传、显存够（教师+学生同卡）。
2. 正式训练 56000 步。
3. 标准版提交。**成功判据：标准版 > 67.37**。
4. 如果正收益：扫 λ_distill（0.1/0.5/1.0/2.0），套校准+TTA。
5. 止损：标准版 ≤ 67.37 → 放弃 DINOv2，考虑换 SAM3 教师（更强、更贴分割任务，但前置障碍多：Python 3.12 环境、HF gated access）。

### 副线 2（第三优先，与主线并行跑）

**MixStyle（CWFA 的严格强化版）**

CWFA 只用了 channel 均值扰动（ε=4），是最弱变体。MixStyle 是均值+方差混合，是它的严格强化。14000 步减步数扫描显示 α 越小越好（α=0.05 标准 66.244 > α=0.2 标准 65.841）。

**具体设计：**

| 组件 | 设计 | 参数 |
|---|---|---|
| 基础模型 | SegFormer-B3 纯 CE（**不加 CWFA**，MixStyle 和 CWFA 是同类域泛化正则，不可叠加） | — |
| MixStyle 挂载点 | decode_head.register_forward_pre_hook，在 decode_head 前扰动 hidden_states[-1] | — |
| α（混合强度） | 0.05（先试最小的，扫描显示越小越好） | 再扫 0.02/0.1/0.2 |
| 概率 p | 0.5（训练时以概率 p 触发 MixStyle） | — |
| 总损失 | CE_loss（MixStyle 是特征扰动，不加额外损失） | — |

**关键注意：**
- MixStyle 和 CWFA 是同类（域泛化正则），**不可叠加**（同类正则叠加=过正则=欠拟合，三合一已证）。永远只从 CWFA/MixStyle/no-decay 里选一个。
- 如果 MixStyle 标准版 > 67.37（CWFA 基线），则替换 CWFA 作为主正则，套校准+TTA。

**执行步骤：**
1. 正式训练 56000 步（代码已就绪，smoke 已过）。
2. 标准版提交。**成功判据：标准版 > 67.37**。
3. 如果正收益：扫 α（0.02/0.1/0.2），套校准+TTA。
4. 止损：标准版 ≤ 67.37 → 放弃，继续用 CWFA。

### 零成本并行（不占 GPU，随时可做）

**1. 补扫校准残余维度**

当前六维校准已扫：背景−0.2、荒地3.6、水体0.70、车辆−0.50、植被0.40、农田压2.40。

**未扫到底的维度：**
- 道路：只扫了 0.15/0.25（全负），**负方向没试**。扫道路 bias = −0.1/−0.2/−0.3/−0.5。
- 建筑：只扫了 0.05/0.12（无效果），**正负方向都没扫透**。扫建筑 bias = −0.1/−0.2/0.3/0.5。

这是零风险、纯测试时操作，历史背书强（背景/荒地/水体/车辆/植被全扫出了正收益）。成本极低，在等待训练结果时并行做。

**2. 准备复赛换分布后的重新校准流程**

当前 69.28 是初赛 500 张分布下的最优。复赛测试集2（1300 张）分布不同，半决赛 3594 张分布又不同。每次换分布，校准空间都会重新打开（确定性 +1~2 分机会）。

**换分布后的标准流程（机械执行）：**
1. 用当前最强模型在新测试集上推理，生成标准版预测（无 TTA、无校准）。
2. 统计新测试集的预测类别分布，与训练集/初赛分布对比，识别偏移最大的类别。
3. 从背景/荒地两个大杠杆类开始，逐类扫描 bias（每类 5~7 个点）。
4. 验证旋转 TTA 8 视图在新分布上是否仍正收益（可能收益不同）。
5. 锁定新分布下的最强组合。

## 三、方法集成（条件触发，不是现在做）

**只有当两个单方法都线上正收益（标准版 > 67.37），且机制不同类，才启动集成。**

| 集成组合 | 机制是否同类 | 触发条件 | 预期 |
|---|---|---|---|
| 边界监督 + 蒸馏 | 不同类（辅助损失 + 外部知识） | 边界监督正 且 蒸馏正 | ★★★ 最可能突破 |
| 蒸馏 + MixStyle | 不同类（外部知识 + 域泛化正则） | 蒸馏正 且 MixStyle 正 | ★★★ 代码共存已验证 |
| 边界监督 + MixStyle | 不同类（辅助损失 + 域泛化正则） | 边界监督正 且 MixStyle 正 | ★★☆ |
| 边界监督 + 蒸馏 + MixStyle | 三者不同类 | 三个都正 | ★★☆ 风险高，可能过正则 |

**绝对禁止的集成：**
- ❌ CWFA + MixStyle（同类域泛化正则，叠加=过正则）
- ❌ CWFA + no-decay（已证三合一崩，66.196）
- ❌ MixStyle + no-decay（同理）
- ❌ 任何两个同类正则叠加

## 五、明确不做的方向（已证负或非瓶颈，不要投入）

| 方向 | 原因 | 线上证据 |
|---|---|---|
| Lovász loss | 边界无真值，拟合标注噪声 | −0.415 |
| EMA | 权重平滑，内部技巧 | −0.445 |
| 伪标签/自训练 | 确认偏差，把模型错误固化 | −0.136 |
| 高分辨率推理（1.5×/2.0×） | 分布外输入，中小目标被误判成背景 | −4.2~−8.0 |
| 多尺度 TTA | 改分辨率=分布外 | 全负 |
| 全局色彩增广/DomainAug/LightBlur | 训练/测试颜色几乎一样，无空间 | 全失败 |
| B4+CWFA / B4+no-decay | 方法不跨模型迁移，B4 对训练期正则全面过敏 | −0.95 / −0.37 |
| B5+LoRA | 阉割大模型容量（只训 4.66% 参数） | −2.72（灾难） |
| CWFA+no-decay 三合一 | 同类正则叠加=过正则=欠拟合 | 66.196（比基线还低 0.54） |
| 细窄道路方向 | 像素占比仅 0.013%，对 mIoU 影响 <0.01 分，SegFormer 32× 下采样结构性不可解 | 四条独立证据证死 |
| prior-shift 系数重扫 | 被按类校准碾压（68.572 vs 69.279） | 已到顶 |
