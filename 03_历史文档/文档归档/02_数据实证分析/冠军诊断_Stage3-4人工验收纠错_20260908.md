## 三、Stage 3 Road结论需修正（已确认）
原"Road主要是Very Wide问题"不准确。正确二分：
- **模型能力层**：Thin/Medium Road recall明显低于Very Wide → **中细道路是模型结构性短板**（能力弱点）
- **排行榜像素层**：VeryWide占Road像素比例极高，故虽recall高仍贡献大量FN像素
- **能力弱点 ≠ mIoU错误贡献最大来源，两概念必须分开**
- 修正产物：`road_width_bucket_metrics.csv` 数据正确，报告措辞已改。

## 七、Test scene shift 无法解释81→69大幅下降（已确认，删除原强结论）
原"Test domain组成精确解释了线上掉分"**删除**。用val各cluster真实性能反事实重加权，仅scene cluster比例变化只能解释~1 mIoU point。实际差11.8 points(local81.10 vs online69.28)。
**正确结论**：scene composition shift只解释少部分；**剩余主要问题更可能来自 class-conditional / semantic shift**——整体像训练过的农业/城郊场景，但同类在Test的纹理/状态/上下文/判别边界变了。

## 八、Test 非 Global Visual OOD（已确认）
OOD P95仅6/500、P99 0/500，RGB/HSV视觉统计偏移不大。不能称"test是全新视觉世界"。
**正确结论**：test global appearance多数近train，但**像素级类别条件发生更细粒度变化** → 支持 class-conditional domain shift。

## 九、Label Policy 差异证据不足（已确认）
Stage3 hard case肉眼可疑 → "possible source/label-policy inconsistency"保留；但Stage4未发现强烈集中在单一cluster。
**降级为 P2/P3待观察因素**，不得直接写"官方标签错误"。

## 十、八维校准技术解释（正式）
8维校准 = `z'_c(x)=z_c(x)+b_c`, b∈R^8，**additive logit bias**。不增加视觉特征、不重新学习地物。可修复：class prior mismatch / global decision bias / 部分target calibration shift。**不能解决**：Barren具体区域为何与Train不同、Agri为何被Bg吞、像素特征为何不可分。

## 十一、Agri与Barren必须区别解释（已确认）
- **Agricultural**：scene shift(农田域test占比↑)可解释部分正向校准需求
- **Barren**：scene proxy显示荒地先验未明显增加，仍需强正向correction → **不能用class prior shift解释**，更强支持 target-domain conditional recognition failure（模型到test对荒地特征变不敏感）

## 十二、Stage 1–4 最终病因优先级（正式采纳）
```
P0  Barren ↔ Background 区域语义可分性
P0  Class-conditional domain shift
P1  Agricultural 跨场景/跨上下文稳定性
P1  Background 类内部高度多模态
P2  Road 中细结构/多尺度能力
P2-P3 Potential source/label-policy difference
P3  Vehicle residual small-object/boundary error
P3  General boundary refinement
```

## 十三、后续冠军方案原则（正式采纳）
- 冠军方案**非不可拆分整体**；每模块须分别判断：收益大小/稳定性/跨域一致性/是否重复优化同机制/是否依赖当前500 Test/计算成本/复赛迁移风险
- "正收益"≠应永久保留；接近噪声、仅单域有效、不可叠加的模块应重设计或删除
- **8维校准：收益大但稳定性风险最大**。未来目标 = robust model / target adaptation先解决类别判别，把logit calibration降级为小幅残差修正，而非让固定8维bias承担主要涨分
