## 五、⚠️ RTX 3060Ti 可行性警告（必须转告队友）

服务器上 exp47 的训练配置（来自 `run_manifest.json`，实测值）：

| 参数 | 值 |
|---|---|
| crop_size | **1024** |
| batch_size | **2** |
| gradient_accumulation_steps | **2**（有效 batch 4） |
| max_steps | 56000（实跑 56000，best 也是 56000） |
| 平均每步 | 2.31 s |
| 混合精度 | 开 |
| PYTORCH_CUDA_ALLOC_CONF | `expandable_segments:True` |
| 训练集 / 验证集 | 5597 / 1399 |

训练机是 4090（24 GB）。**3060Ti 只有 8 GB。**

**1024² + batch 2 + 8 GB 显存大概率 OOM。** 队友上手第一步不是改代码，是：
1. 先把 `batch_size` 降到 1，`gradient_accumulation_steps` 提到 4（保持有效 batch 4）；
2. 若仍 OOM，把 `crop_size` 降到 768 或 512；
3. 用 `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True` 起；
4. 先跑 `launch_exp47_smoke.sh` 那种小规模冒烟，**别直接上 56000 步**。

另外 56000 步 × 2.31 s ≈ **36 小时**（4090）。3060Ti 慢 3–5 倍，**同等步数要 5–7 天**。
队友需要先确认这个时间预算是否可接受，再动手。

## 六、训练启动命令（权威来源，照抄）

```bash

export PYTHONDONTWRITEBYTECODE=1 PYTHONPATH="$ROOT"

python scripts/train_once_no_oom_retry.py \
  --config configs/stage47/wave1_exp47_semeda.yaml \
  --dataset-root '/home/jhy/datasets/2026-低空图像语义分割赛道-训练集' \
  --output-dir stage47_runs/stage47_w1_exp47_b3_semeda_formal_seed42 \
  --device cuda:0
```

注意几个**离线环境变量**（`HF_HUB_OFFLINE=1` 等），队友按需调整。
`UAVSEG_MODEL_SOURCE` 指向本地的 segformer-b3 权重目录，**迁移后必须改成本地路径**。
