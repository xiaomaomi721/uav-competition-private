# 悲观下的后备道路（外部事实挖尽清单）

> 用途：如果 5 条训练期线（蒸馏/MixStyle/CopyPaste/B4低lr/B5+LoRA）线上全负，立刻切换到本清单，不浪费半天纠结。
> 核心判断：本赛题分数由"测试时先验（外部事实）"主导，训练期技巧大多拖后腿。外部事实这条稳定涨分的路，我们**没挖到底**。
> 更新：2026-08-29

---

## 一、残酷事实（先承认，悲观有数据支撑）

40+ 次提交，只有两类稳定涨分：
- **外部事实（测试时先验）**：prior-shift +0.34、按类校准 +1.9、旋转TTA +0.21 —— **占最强 69.276 的绝大部分**
- **训练期正收益**：仅 CWFA +0.63、no-decay +0.67 两个，其余全负或微正

**结论**：分数主要由"测试分布先验"决定，而非"模型内部学得更准"。真难点=灰色团 RGB 距离 3~15 分不开，是"标注含糊+类别视觉不可分"，训练期技巧难解。**这不是失败，是赛题真相。**

## 二、第一层（最稳，历史背书）：挖尽校准先验

### 2.1 校准 bias 的真实覆盖（精确核对，2026-08-29）

| 类别 | 扫描状态 | 当前值 | 缺口 |
|---|---|---|---|
| 背景 | ✅ 扫到底 | −0.200 | 无 |
| 荒地 | ✅ 扫到底 | 3.60 | 无 |
| 水体 | ✅ 扫到底 | 0.70 | 无 |
| 农田 | ✅ 扫到底 | 压 2.40 | 无 |
| 车辆 | ✅ 扫到底 | −0.50 | 无 |
| **道路** | ⚠️ 只扫 2 点(0.15/0.25 全负) | 0 | **未扫到底，负方向没试** |
| **建筑** | ⚠️ 只扫 2 点(0.05/0.12 无效果) | 0 | **未扫到底** |
| **植被** | ❌ **完全没扫** | 0.1932(V1e残留) | **最大遗漏** |

**关键遗漏 = 植被**：植被是绿色团里和农田"孪生"的那个（RGB 距离仅 16）。我们调了农田(压2.40)但**从没单独调过植被**。农田/植被是最典型的混淆对，只调一个、不调另一个，很可能没到位。这是**零风险、纯测试时、历史背书的可挖空间**。

**待做**：对 B3+CWFA 主模型，扫植被 bias（正负两方向）+ 道路负方向 + 建筑正负方向。

### 2.2 半决赛 1794 张分布 vs 初赛 500 张（更大的外部事实，被忽略）

| 阶段 | 测试集 | 张数 | 计分 |
|---|---|---|---|
| 初赛 | 测试集1 | 500 | 进复赛，不计总分 |
| 复赛 | 测试集2 | 1300 | 不计决赛总分 |
| **半决赛** | **测试集3=1+2+3** | **1794** | **计入决赛总分** |

**致命问题**：我们现在的 69.276 校准，是拿**初赛 500 张**的线上分精调的。但**最终决赛计分是 1794 张的混合分布**。官方原话"测试集某类占比可能远高于训练"——这个**分布转移本身**就是可挖的先验，而我们还没针对最终 1794 张分布重新校准过。

**待确认**（关键，先问清楚）：
- 我们提交后看到的线上分，对应的是哪个测试集？（初赛 500 / 复赛 1300 / 半决赛 1794？）
- 如果决赛用 1794，那 prior-shift 系数、校准 bias 都要按新分布重调。

**✅ 已确认（2026-08-29 用户）：目前是初赛（500 张）。**

**含义修正（重要）**：
- 现在的 69.276 = **初赛 500 张分布下的最优**，但决赛（半决赛）计分 = **1794 张混合分布**，分布不同。
- **"校准到顶"只是初赛到顶，不是决赛到顶**。决赛换分布后，校准 bias + prior 系数大概率要重调——这是**决赛阶段的确定性增量**，不是赌博。
- 初赛阶段能做的增量 = 在 69.276 框架下逼近初赛上限（补扫植被/道路/建筑 bias 仍有效）；决赛阶段再针对 1794 分布重校准。

### 2.3 prior-shift 系数针对最终分布重扫
- 现在 prior×3.0 是初赛 500 张分布下的顶点。
- 若决赛分布不同，prior 系数也要重扫（3.0 附近，成本低）。

## 三、第二层（重审误判）：失败方法细拆参数

TTA 的教训：曾记"全负"，实为"翻转 TTA +0.275，多尺度 TTA 才负"——**判死可能是用法/参数错，不是方法错**。以下失败值得细拆重试：

| 方法 | 原判决 | 重试角度 | 成本 |
|---|---|---|---|
| 伪标签 | −0.136 | 阈值/置信度过滤没调？ | 低（纯测试/数据） |
| EMA | −0.445 | decay 0.999 太钝？试 0.99/0.995 | 低 |
| Lovász | −0.415 | lovasz_weight 太大？类选择太激进？ | 低 |
| 多尺度上下文融合 FPN/ASPP | 从未试 | 官方点名，针对"形状/纹理判据" | 中（需写代码） |

**注意**：这些是"重审"，不是"盲目重试"。逐个用"参数/复杂度/用法"三问，只挑有依据的重试。

## 四、第三层（官方点名但没做）：合规的大方向

1. **SAM3 蒸馏**：官方指定资源(facebookresearch/sam3)，比 DINOv2 更强、更贴分割任务。DINOv2(Exp31) 若负，换 SAM3 是唯一"外部知识"路线的升级。（已调研：需独立 conda Python3.12 + HF gated access，见 [[SAM3蒸馏调研]]）
2. **多尺度上下文融合 FPN/ASPP**：官方解题思路点名，显式加强"形状/纹理/上下文"建模——这正是灰色团区分的唯一判据（见 [[赛题难点与图像质量复盘]] 用户肉眼观察）。我们记录过但一直没做。

## 五、一个比"不涨分"更严重的风险（务必记住）

**半决赛后官方复现，复现失败 = 取消成绩。** 所以：
- 守住一个"能复现的 69.276"，比"不可复现的 70"更安全。
- 任何新方法上线前，先确认它能被官方复现（权重公开、训练只用官方数据、无外部图片）。

## 六、决策树（5 条线全负后的动作顺序）

```
5 条线线上分回来 → 若全负（或无一 >67.37）：

1. 立即做 2.1：补扫植被/道路/建筑 校准 bias（零风险，纯测试时，历史背书）
2. 同时确认 2.2：决赛用哪个测试集？分布变了没？prior/校准要不要重调？
3. 若 2 有空间 → 针对最终 1794 张分布重新校准 + prior 重扫
4. 若仍不够 → 第二层重审（伪标签/EMA 参数细拆）
5. 最后 → 第三层（SAM3 蒸馏 / FPN/ASPP）

原则：先挖尽"外部事实"（第一层，零风险），再碰"训练期方法"（第二三层，高风险）。
```
