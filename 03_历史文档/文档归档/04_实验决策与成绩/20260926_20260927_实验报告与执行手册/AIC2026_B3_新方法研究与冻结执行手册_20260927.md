## 2. 研究结论：为什么唯一选择 MIC

### 2.1 可核查的外部证据

MIC 的核心不是普通 teacher-student，而是：

1. EMA teacher 在**完整、干净的 target 图像**上生成伪标签；
2. student 只看到强增强并大面积 block-masked 的 target 图像；
3. student 仍被要求恢复完整语义；
4. 伪标签质量以高置信像素比例加权；
5. 最终推理使用单独 student，不加载 teacher。

MIC 论文在 GTA→Cityscapes 的公开实验中，把 MIC 加到 Transformer DAFormer/HRDA 后分别报告约 `+2.3`、`+2.1 mIoU`；默认配置为：

```text
mask_ratio=0.7
mask_block_size=64
mask_lambda=1
EMA alpha=0.999
pseudo threshold=0.968
```

论文消融中 masking 是核心增量；mask ratio `0.5–0.7` 较稳，默认 `0.7`。这些是**外部机制证据，不是本项目收益保证**。本项目 A05 已较强且已含 EMA/target adaptation，实际收益可能远小于论文、为零或为负。

权威来源：

- MIC 论文：[CVPR 2023 paper](https://openaccess.thecvf.com/content/CVPR2023/html/Hoyer_MIC_Masked_Image_Consistency_for_Context-Enhanced_Domain_Adaptation_CVPR_2023_paper.html)
- MIC 官方配置：[gtaHR2csHR_mic_hrda.py](https://github.com/lhoyer/MIC/blob/master/seg/configs/mic/gtaHR2csHR_mic_hrda.py)
- MIC masking 实现：[masking_consistency_module.py](https://github.com/lhoyer/MIC/blob/master/seg/mmseg/models/uda/masking_consistency_module.py)
- MIC teacher 实现：[teacher_module.py](https://github.com/lhoyer/MIC/blob/master/seg/mmseg/models/uda/teacher_module.py)
- 官方 student 推理路径：[tools/test.py](https://github.com/lhoyer/MIC/blob/master/seg/tools/test.py)

说明：先前自动 deep-research 工作流的网页正文抽取阶段失败，得到 `0 verified claims`，所以不能把那次 workflow 称为成功研究。本文件中的外部结论来自后续对论文页、官方配置与官方代码入口的直接核对。

### 2.2 为什么不选其他候选

| 候选 | 结论 | 原因 |
|---|---|---|
| residual D1 | 不选 | A05 已吸收 D1 且比完整 D1 高 `+0.038877pp`；是饱和问题，不是新杠杆 |
| DACS/ClassMix | 不选 | 真正新残量只剩 source-target ClassMix；EMA/pseudo/增强高度重合；本项目已有“ClassMix/HalfMix 类似 CopyPaste、破坏航拍位置关系”的负面先验 |
| DAFormer RCS | 不选 | rare-class-aware crop 已存在，不能称新方法 |
| DAFormer feature distance | 不选 | loss 新，但本项目诊断没有 feature collapse；动机弱 |
| HRDA | 不选 | 架构新，但双分辨率实现/显存/验证复杂；项目 scale 轴有强负面历史，首轮风险过高 |
| ProDA | 不选 | 多阶段 prototype 链过长；已有诊断没有支持 prototype collapse 是瓶颈 |
| Mean Teacher | 不选 | ATDA 已含 EMA target consistency；重复度最高 |
| M2F | 不选 | 项目已经完整跑过，线上 ZERO 最高约 68.4133，明显低于 A05；不是未尝试新方法 |
| **MIC masking** | **选定** | block masking 是 A05 祖先中没有的核心机制；论文与官方代码成熟；不改 backbone/head；GPU2 单卡实现面可控 |

DACS 原论文可核查来源：[WACV 2021 paper](https://openaccess.thecvf.com/content/WACV2021/html/Tranheden_DACS_Domain_Adaptation_via_Cross-Domain_Mixed_Sampling_WACV_2021_paper.html)。原始 DACS 是单网络产生 target pseudo，不应把后来 DAFormer 的 EMA teacher 混称为原始 DACS。

DAFormer 机制来源：[CVPR 2022 paper](https://openaccess.thecvf.com/content/CVPR2022/html/Hoyer_DAFormer_Improving_Network_Architectures_and_Training_Strategies_for_Domain-Adaptive_Semantic_CVPR_2022_paper.html)。它的 RCS、feature distance、warmup、EMA 与 decoder 是一组 bundle，不能把整套论文增益归给其中一个组件。

### 2.3 收益判断边界

本方法具有争取 `≥+0.20pp` 的合理机制空间，但不得承诺结果。支持它的不是 source holdout，而是：

- block masking 确实是 A05 中未出现的训练约束；
- 它要求上下文恢复，适合航拍纹理/区域语义；
- 官方方法在强 Transformer UDA baseline 上仍有增量；
- 不需要换 backbone/head，减少架构迁移风险。

主要风险：

- A05 已含 ATDA EMA consistency，MIC 的独立残量可能不足；
- 70% masking 可能损伤无人机小目标 Vehicle；
- Bstar 参与 pseudo label 后可能放大 Barren；
- test2 无 GT，任何 confidence/entropy/share 都不能证明准确率；
- source mIoU 与 test2 排名已被历史反例证明不可靠。

## 3. 冻结实验：仅两个正式 RUN_ID

```text
A05_MICMASK_CONTROL_S20260927_L8000
A05_MICMASK_TREAT_S20260927_L8000
```

共同初始化、数据流、teacher、优化器、步数、replay、checkpoint 和评估完全相同。唯一方法差异是同一个预生成 block mask 是否真正作用到 student 输入：

```text
CONTROL: apply_mic_mask = false
TREAT:   apply_mic_mask = true
```

两臂都必须完整执行 target loader、clean EMA forward、strong photo、block-mask 生成、pseudo/quality weight、student forward 和 target CE，且 target loss 权重都固定为 `1.0`。CONTROL 的 student 看未遮挡的 strong target；TREAT 的 student 看对应的 masked strong target。这样 `TREAT-CONTROL` 才隔离 MIC masking 本身，而不是把“新增全部 target supervision”误算成 masking。不得通过分支跳过任一共同路径。结构化配置 diff 的 allowlist 只能含 `run_id/role/output_dir/apply_mic_mask`。

### 3.1 为什么 formal 是 8000 steps

历史 D1 的 2000 steps 只约 1.54 个 target 遍历，适合验证强 hard-pseudo 的短剂量，但 MIC 依赖遮挡覆盖的多样性。这里固定：

```text
attempted loop steps = 8000
primary endpoint = loop 8000 student
```

这约对应每张 target 平均被不同 mask 看见约 6.15 次，仍是 bounded fine-tune，不是 40k 论文训练重做。2k/4k 只保存用于恢复证据和轨迹审计，禁止事后选择或提交。

## 4. 冻结训练 recipe

### 4.1 共同模型与 scope

student 和 EMA teacher 均从 A05 strict-load，初始逐 tensor 相同。

训练参数：

```text
segformer.stages.2.*
segformer.stages.3.*
decode_head.*
```

模块模式：

```text
student.eval()
stages.2.train()
stages.3.train()
decode_head 参数有梯度但 module 保持 eval
EMA teacher 始终 eval / requires_grad=False / no_grad forward
```

其余所有 parameters 和 buffers 冻结，每步和 checkpoint 做 equality/hash 审计。

### 4.2 source 分支

冻结复用 D1 source recipe：

```text
5597 real-GT
crop_size=1024
batch=1
rare crop probability=0.5
priority IDs=(7,4,6)
max_offset_fraction=0.25
ignore_index=255
```

source logits bilinear upsample 到 GT 尺寸，`align_corners=False`：

```text
L_source = CE(source_logits_up, source_gt, ignore_index=255)
```

source 分支不得加 Bstar。

### 4.3 target clean teacher 分支

每个 loop 取一张 1024×1024 target，保持 clean normalized tensor `x_t`。

```python
with torch.no_grad(), autocast:
    z_teacher = ema(pixel_values=x_t).logits
p_teacher = softmax(z_teacher.float() + Bstar, dim=1)
conf, y_teacher = p_teacher.max(dim=1)
q = mean(conf >= 0.968)
```

合同：

- teacher 输出保持 native `256×256`；
- Bstar 仅在 teacher target logits 上加一次；
- 不使用 theta261/theta278/D1 静态 cache；
- 不做训练期 D4/TTA；
- `q` 是一张图的高置信像素比例，是 loss scalar weight；
- 不把低置信 pixel 从 loss 中删除。

### 4.4 target student mask 分支

固定共同预处理与唯一差异：

```text
clean target
→ strong_photo（复用 D1 的 brightness/contrast/saturation/gamma/noise/25% avg blur）
→ 生成同一个 block mask
→ CONTROL: student 输入保持未遮挡 strong target
→ TREAT:   student 输入应用该 block mask
→ student forward
```

mask 固定参数：

```text
type=block
input block size=64×64 pixels
1024 input → 16×16 block grid
每个 block 独立 Bernoulli(masked)=0.70
同一 mask 广播到 RGB 三通道
masked fill=0 in ImageNet-normalized space
```

若一次随机结果为全 mask 或全 unmask，使用同一专用 RNG 重采样，直到两种 block 都存在；记录重采样次数。不得改 mask ratio，不扫 block size。

student：

```python
x_strong = strong_photo(x_t)              # 两臂 replay 完全相同
mask = make_block_mask(mask_rng)           # 两臂生成完全相同
x_student = x_strong if role == "CONTROL" else apply_mask(x_strong, mask)
z_student = student(pixel_values=x_student).logits.float() + Bstar
ce_map = CE(z_student, y_teacher, reduction="none")
L_target_raw = mean(ce_map)                 # 全部 native-grid pixels
L_target = q * L_target_raw
L_total = L_source + 1.0 * L_target
```

Bstar 在 student target logits 上加一次。两臂 target loss 权重完全相同且无 ramp；`TREAT-CONTROL` 的唯一方法变量是 student 输入是否遮挡。CONTROL 不是 source-only continuation，而是未遮挡的 EMA pseudo-label consistency 对照。

不加入 D1 hard agreement、static caches、D4、ClassMix、CutMix、feature distance、prototype、entropy、KL、soft teacher、MixStyle、AdaIN、CWFA 或新 class weights。

### 4.5 EMA

使用 MIC 官方 warm-start EMA：

```text
alpha_max=0.999
alpha_u=min(1 - 1/(u+1), 0.999)
```

`u` 为 successful optimizer update index；初始 teacher 直接复制 A05。EMA 仅在 AMP 确认真正完成 optimizer step 后更新：

- parameters 按 EMA；
- floating buffers 按 EMA；
- integer buffers直接复制；
- AMP skip 时 EMA 不动。

两臂都维护 EMA。最终 primary checkpoint 是 **student loop8000**；EMA 仅作训练 teacher 和审计，不参与最终推理。

### 4.6 optimizer / AMP

```text
optimizer=AdamW
stage2/3 LR=1e-5
head LR=5e-7
weight_decay=0.01
LR factor=max(0, 1-(loop-1)/10000)
AMP=on
seed=20260927
batch=source1 + target1
```

记录 attempted loops、successful optimizer updates、AMP skip loops。skip 仍算 attempted loop，不补步。

为降低峰值显存，可以在同一次 optimizer step 内：

1. `scale(L_source).backward()`；
2. target forward 后 `scale(L_target).backward()`；
3. 只执行一次 optimizer step。

但两臂实现必须相同，日志仍记录精确总 loss。不得错误地在两个 branch 之间 optimizer step。
