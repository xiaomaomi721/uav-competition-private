## 问题2：all_symlink语义必须分层

当前`PSEUDO_PAYLOAD_MANIFEST.json`扫描的是resolved payload目录：

```text
/home/jhy/pseudo_labels_v2_multi/masks_official/test1_1..500.png
```

这些确实是regular files，所以对它们写`all_symlink=false`是正确的。

但是实际训练数据入口：

```text
/home/jhy/datasets/pseudo_train_6796/train/masks/7000..7499.png
```

当前仍全部是symlink，并解析到上述regular payload文件。

因此manifest和报告应改成两个明确字段：

```json
{
  "training_mask_entries": {
    "root": "/home/jhy/datasets/pseudo_train_6796/train/masks",
    "id_range": "7000..7499",
    "count": 500,
    "all_are_symlinks": true
  },
  "resolved_payload_files": {
    "root": "/home/jhy/pseudo_labels_v2_multi/masks_official",
    "count": 500,
    "all_are_regular_files": true,
    "all_are_symlinks": false
  }
}
```

每个entry同时记录：

```text
training mask symlink path
symlink target
resolved payload path
resolved payload SHA/size/mode/shape/labels
```

不能再概括成“实际是regular files，非symlink”，因为这会错误描述训练入口。正确说法：

> 训练mask条目是500个symlink；它们当前解析到round-2目录中的500个regular PNG payload。此manifest冻结当前/B4-era解析结果，仍不能证明历史B3读取相同payload。
