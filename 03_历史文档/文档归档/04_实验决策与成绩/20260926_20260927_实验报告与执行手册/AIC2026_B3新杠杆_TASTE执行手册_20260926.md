# 1. 为什么本轮做这个，而不是继续小调

## 1.1 当前事实

- A05_WEIGHT：70.775011，checkpoint SHA256：

  ```text
  023b65800d434069f0fb0ad881083fd439b89011f731feebc88d6e9217727134
  ```

- A05 是单 merged checkpoint，推理加载一个 checkpoint，按现行项目规则合规。
- A05 相对 D1_2k 的收益仅 `+0.038877pp`，属于高价值精修，但不是新杠杆。
- D1 相对 parent 约 `+0.149pp`，说明 test2 目标域信息确实可能有效。
- D1 Barren 消融在 matched source 上 `+0.2541pp`，线上融合包却显著下降到 `70.506962`；因此 source 逐类提升不能当作 test2 排名器。
- 旧 alpha evaluator 曾错误处理 ignore=255；旧 Vehicle 诊断也被这一类映射问题污染。必须先统一 evaluator。

## 1.2 已有 domain-shift 证据及其边界

`无人机/审计记录/cpu_tasks/ROUND2_SHIFT_REPORT.md` 已证明 test2 存在真实但中等的 shift：

- source→test2 image-space MMD² 约 `0.00740 ± 0.00222`；source internal 约 `−0.00016 ± 0.00056`；
- stage2/stage3 deep Fréchet 的 source→test2 距离显著大于 source internal；
- confidence、entropy、D4 disagreement 同方向变化。

但这只能证明“有 shift”，**不能证明 shift 正好由 TAST-E 操作的低频颜色/照明成分承载**。因此本轮必须先做 operator-specific eligibility，而不是看到 domain shift 就直接训练。

## 1.3 TAST-E 的正交性

D1 的主要参数运动在 B3 stage2/3；本轮只训练 A05 的 stage0/1，攻击外观/纹理适配问题，理论上与 D1 的语义适配更正交。最终仍是一个 B3 checkpoint，不需要推理期双模型融合。

## 4.2 正确混淆矩阵

内部训练标签必须明确是 `0..7 + ignore=255`。核心逻辑：

```python
valid = gt != 255
if not valid.any():
    return
if gt[valid].min() < 0 or gt[valid].max() > 7:
    raise ValueError("GT outside train IDs 0..7 after explicit mapping")
if pred.min() < 0 or pred.max() > 7:
    raise ValueError("prediction outside 0..7")
cm += np.bincount(
    gt[valid].astype(np.int64) * 8 + pred[valid].astype(np.int64),
    minlength=64,
).reshape(8, 8)
```

如果输入是官方 mask，先由项目的 `official_to_train` 显式映射，再进入上面逻辑。绝不通过 `if gt.max()>7: gt=gt-1` 猜测编码。

## 4.3 单元测试必须覆盖

1. GT 含 255 时，所有合法类别保持原值，Vehicle 不被 ignore 污染。
2. 官方标签 0 明确映射成 ignore，1–8 映射到 0–7。

# 6. Phase C：CPU-only TAST-E eligibility

## 6.1 冻结算法

### 6.1.1 Fourier 操作

对 RGB float32 `[0,1]` 图像逐通道：

```python
fft = np.fft.fft2(image, axes=(-2, -1))
amp = np.abs(fft)
phase = np.angle(fft)
amp = np.fft.fftshift(amp, axes=(-2, -1))
```

在中心窗口中做：

```text
A_mix = (1-rho) * A_source + rho * A_donor
beta = 0.01
rho ∈ Uniform(0.25, 0.50) after frozen warmup rule
```

窗口大小必须在代码中明确：由 `beta * min(H,W)` 取整的 half-width/side-length 规则只能有一种，并写进 config 与报告。恢复 source phase，inverse shift/FFT，取 real component。训练前先保存 pre-clamp range，再 clamp `[0,1]`，用于统计 clipping。

### 6.1.2 采样

- 固定 seed42。
- source-source bootstrap：建议 100 次、每侧 size-matched 500 或预注册规模；两个 source subset 必须互斥。
- source-test2：固定 source subset 与 test2 full 或固定 test2 subsets；报告 full 和 size-matched 两种时必须预先声明 primary。
- transformed-source：content 与 donor 索引在 diagnostic config 中冻结；不得看结果后重抽“更好看的”配对。

## 6.2 统计族

至少输出：

1. **Low-frequency spectrum**：若干预注册 radial bands 的 log-amplitude mean/std，以及 standardized distance。
2. **Color**：RGB/Lab mean/std、固定 bins histogram 距离。
3. **Illumination/texture**：luminance mean/std/percentiles、contrast、gradient/高低频能量比。

不得只使用通用 MMD 重复证明“有 shift”；primary 指标必须与 TAST 算子直接相关。

## 6.3 安全检查

- pre-clamp 低于0/高于1的像素比例；总 clipping 必须 ≤0.5%。
- finite 检查。
- source 与 transformed source 的边缘/phase structure 指标。
- 固定 32 对 image/content/donor/transformed visual grid，供人工查看；人工查看只能检查错位/伪影，不能改 PASS 数字阈值。

## 6.4 冻结 PASS 条件

全部满足：

1. 至少两个统计族中，source→test2 超过 source-source bootstrap 95th percentile。
2. 重采样方向稳定；不是坏图、尺寸或归一化错误。
3. TAST 使至少一个 primary target distance 相对未变换 source 降低 ≥20%。
4. 其他 primary target distance 没有 >10% 系统性恶化。
5. clipping ≤0.5%，无 NaN/Inf，结构检查通过。

输出：

```json
{
  "status": "PASS_OR_METHOD_PRECONDITION_NOT_MET",
  "gpu_training_authorized_by_diagnostic": false,
  "note": "PASS only makes the method eligible; user approval and contracts are still required"
}
```

即使 PASS，也不得由脚本自动启动 GPU。

# 12. 结果决策树

## 情形 A：treatment < A05 +0.05pp

- 当前 TAST-E recipe 无实质收益。
- 不扫 beta/rho/LR，不用更多提交槽救结果。
- 不能写“所有 style transfer 无效”。
- 等 B4 结果；B3 下一大分支再从已验证 D1 机制或公平 M2F 预算中选，不在本轮自行增加 run。

## 情形 B：treatment +0.05～+0.199pp

- 弱正，但未达到新杠杆目标。
- 完整保存因果对照；不立即扫参。
- 若 treatment-control 也为正，记为可能的 target appearance signal；等待 B4 后统一决定组合。

## 情形 C：treatment ≥ A05 +0.20pp，但 treatment-control <+0.20pp

- 找到 B3 新冠军杠杆，但未证明主要来自 test2 donor。
- 若 control 同样强，优先解释为通用 Fourier/双视图继续训练机制。
- 下一步应做 seed43 的同一成对确认，而不是修改 recipe。

## 情形 D：两个 delta 均 ≥+0.20pp

- target donor 外观信息形成强因果杠杆。
- 锁定 treatment checkpoint 为候选新 parent。
- 允许预注册一次 seed43 成对复现；仍不得自动启动。

## 情形 E：≥+0.40pp

- 视为大杠杆；优先冻结全部证据并升级项目 handover。
- 后续再研究与 D1 或 B4 的组合，但本轮执行 AI 不得自行加跑。
