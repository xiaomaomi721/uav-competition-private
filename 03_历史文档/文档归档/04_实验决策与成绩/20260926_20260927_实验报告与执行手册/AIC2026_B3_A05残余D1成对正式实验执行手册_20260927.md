# 2. 冻结的科学问题

## 2.1 主问题

```text

启用original D1 target hard CE是否比其权重为0更好？
```

## 2.2 为什么必须有CONTROL

只比较TREAT与静态A05，会混合：

- 2000步source continuation；
- fresh optimizer/weight decay；
- 随机增强；
- target hard supervision。

只有：

```text
TREAT - CONTROL
```

才能估计target hard loss的增量价值。

## 2.3 预注册强度

```text
Delta_target    = online(TREAT) - online(CONTROL)
Delta_treat_A05 = online(TREAT) - 70.775011
Delta_ctrl_A05  = online(CONTROL) - 70.775011
```

- `<+0.05pp`：无实质target增益。
- `+0.05～+0.199pp`：小的残余增益，不是新杠杆。
- `≥+0.20pp`：强信号。
- 只有`Delta_target`与`Delta_treat_A05`都`≥+0.20pp`，才称residual D1为强新杠杆。

# 8. 每loop准确训练语义

## 8.1 Source

```text
1024 crop
rare crop p=.5
priority=(7,4,6)
max_offset_fraction=.25
source batch=1
```

```python
source_logits = model(source).logits
source_logits = interpolate(
    source_logits.float(),
    size=source_gt.shape[-2:],
    mode="bilinear",
    align_corners=False,
)
source_ce = cross_entropy(source_logits, source_gt, ignore_index=255)
```

## 8.2 Target student

按照replay应用D4和strong_photo：

```text
brightness factor Uniform(.85,1.15)
contrast factor   Uniform(.85,1.15)
saturation factor Uniform(.88,1.12)
gamma             Uniform(.9,1.1)
noise sigma       Uniform(0,.015)
avg blur 3x3 probability .25
```

但formal不得现场重新抽随机数，应消费replay中冻结值/seed。

student logits inverse D4后加Bstar一次。

## 8.3 Teacher target

从raw cache加载并转换FP32；两套分别加Bstar一次：

```python
p278 = softmax(z278_plus_bstar, dim=class)
conf278, y278 = p278.max(class)
y261 = z261_plus_bstar.argmax(class)
mask = (y261 == y278) & (conf278 >= 0.98)
```

```python
per_pixel = cross_entropy(student_plus_bstar, y278, reduction="none")
hard_ce = per_pixel[mask].mean() if mask.any() else finite_zero
```

## 8.4 唯一分叉

```python
ramp = min(1.0, loop / 500)
coefficient = 0.0 if role == "control" else 0.5 * ramp
loss = source_ce + coefficient * hard_ce
```

CONTROL必须实际计算hard_ce，不能以role跳过target路径。建议在graph中保留`0.0 * hard_ce`，并通过receipt证明其weighted contribution精确为0。

## 8.5 AMP和step

```text
attempted loop总数固定2000
AMP overflow时记录skip
skip不做optimizer update
skip仍消耗本loop replay record
不补额外loop
```

因此报告必须分别写：

```text
attempted_loops=2000
successful_optimizer_updates=<actual>
amp_skip_loops=[...]
```

## 12.3 固定决策树

### A. TREAT > CONTROL 且 TREAT > A05

residual D1 target loss有独立、可部署价值，TREAT成为新冠军。

- 两个delta均≥+0.20：强新杠杆。
- 否则：modest residual gain，不扫参数。

### B. TREAT > CONTROL，但 TREAT ≤ A05

target loss有正因果效应，但没有部署收益；保留A05，关闭本recipe。

### C. TREAT ≤ CONTROL，CONTROL > A05

不支持residual D1；CONTROL可能是source-continuation候选，但不得归功于target supervision。

### D. 两者都≤A05

保留A05，关闭本recipe。

### E. 同分

target effect=0，关闭本recipe。

无论哪种情况，不自动增加第三臂、seed、lambda、confidence、duration、teacher或alpha sweep。
