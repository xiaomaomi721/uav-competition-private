## 4. 新head的准确命名与必要机制

第一候选：MiT-B3 encoder + 简化Mask2Former-style segmentation head。

必须包括：
1. Mask queries；
2. Class+mask prediction（含no-object）；
3. Masked cross-attention / query refinement；
4. Set prediction、matching与相应mask/class损失；
5. 正确的semantic mask合成与8类输出。

若pixel decoder简化，不能称完整官方Mask2Former复现。若同时更改decoder、匹配和损失，结果只归因于整个head方案，不能单独宣称query机制带来收益。

## 5. 预注册验收指标

### 固定的测量协议

- 相同1399张验证split、相同GT映射与Ignore处理。
- 使用确定性单视图zero-bias验证；无随机几何、无TTA、无后处理、CWFA推理关闭。
- 形态使用CPU审计v2相同定义：8连通；有效GT相邻异类两侧像素作为种子，欧氏3px/5px带；Ignore接口不作为边界。
- 主目标用5px，3px作为敏感性检查；所有有向类对、所有连通域纳入，无最小面积截断或top-N过滤。
- 报告全体结果，不能事后挑某几张可视化替代总体。
- 结构初版线上先测zero，不把独立calibration收益算成结构收益。

### 指标与解释

| 维度 | 预注册规则 |
|---|---|
| 整体验证mIoU | 报告相对匹配B3基线的pp变化；下降时不能称无代价提升。工程准备阶段尚未设置额外硬停机数字，不能事后把“明显”解释成预设统计阈值。 |
| Barren | 重点观察IoU、Barren→Background与Background→Barren的FP/FN及内部大块错误，期望方向为IoU上升、目标错误下降。 |
| Agricultural | 同样记录Agricultural↔Background两向错误，禁止只汇总两向后掩盖一向恶化。 |
| Vehicle | 相对匹配基线IoU下降超过0.3pp触发警戒；不是自动断言显著性，也不靠总体mIoU好看而忽略警戒。 |
| 内部≥4096大块 | 对上述每个有向类对同时记录绝对错误像素、除以该GT类像素的归一化错误率、除以该类对全部错误的份额。下降方向预注册，不把无最小效应约定的微小下降说成“清晰改善”。 |
| 成本 | 显存峰值、单步耗时、总优化步/处理样本、参数量、预测耗时如实记录；未经GPU实测不承诺适配24GB或训练时长。 |

分母解释：对c→d类对，A_cd为GT边界5px外、按该精确类对分割的≥4096连通域总面积。
- 主报告A_cd（绝对面积）；
- A_cd / GT(c)（固定验证集上的归一化错误量）；
- A_cd / 全部c→d错误（组成比例）。

比例单独下降不算目标改善：它可能只是其他错误增加。类对反方向使用自己的GT类分母；农业/裸土总体FP+FN另行记录，不能混淆这些分母。

### 匹配基线的限制

历史Stage23 B的mIoU=81.09861029%，Barren=61.12649064%，Agricultural=80.12744122%，Vehicle=81.53704438%，来源见CPU审计receipt。这些是参考锚点，不自动等于新head实验的匹配训练对照。

新head的encoder初始化、head随机初始化、训练预算、优化器、增强与数据采样必须在实现计划中写清。若新head从已训练B3 encoder起步，而MLP基线保留成熟head，则两者训练起点不对称；如果无法增加匹配控制，必须标记该限制，不宣称严格的head因果消融。

## 6. 工程截止与成绩止损

- 2026-09-17前形成可评分版本为工程目标；不是耗时承诺。
- 初版线上zero≥68.30：积极继续投入信号，而非证明已达突破路径。

## 7. Teacher入池规则

至少需要一项正向证据：
- 在带GT的验证图上，现有模型错误处，新模型确实更正确（同时记录反向损失）；
- Barren/Agricultural目标错误明显改善，且没有用大范围其他错误换取；
- 受控蒸馏后最终单模型student实际收益。

入池前仍需考虑验证/测试域不一致；满足上述之一只是候选资格，不自动证明对test1或完整复赛有效。

## 8. 三条线不互相替代

- KD：现有教师信号能否转移到单个student。
- 新head：区域级分割机制能否减少大块内部误分类。
- calibration：每个模型在明确搜索预算下的偏置响应与分数改善；不把test1结果无条件外推。

形态证据支持研究区域级方法，但不证明错误来自head、分歧来自不同basin、teacher一定互补，或70必须依赖新架构。
