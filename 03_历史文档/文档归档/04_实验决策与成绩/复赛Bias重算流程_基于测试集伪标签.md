# 复赛 Bias 重算流程（基于测试集伪标签实证）

> 用途：复赛数据换分布后，快速重算校准 bias。校准是唯一稳定大分来源（+1.9），本流程是复赛的核心弹药。
> 日期：2026-09-02
> 依据：诊断 #5b（测试集伪标签，置信度 0.94）+ 校准八维封顶判决（69.281290）

---

## 一、为什么校准是唯一稳定大分

- 当前锁定 69.281290 = B3+CWFA + 旋转TTA8 + 八维校准
- 校准贡献：背景−0.2/荒地3.6/水体0.70/植被0.40/农田3.32/车辆−0.50 等，合计 **+1.9 分**
- 诊断 #5b 证明机制根源：**测试集背景比训练集多 4.75%、植被少 4.71%** → 校准"背景−0.2"压背景、让灰色团吐分，正好对齐测试先验
- 训练期方法天花板低（CWFA+0.63/no-decay+0.67），**测试时先验才是大分**

## 二、复赛重算流程（5 步，半天内完成）

### 第 0 步：准备
- 复赛数据到达后，确认测试集路径 `$DATASET/images`
- 确认主模型：B3+CWFA best_miou.pt（`stage23_runs/.../best_miou.pt`）——除非复赛我们换了更强的模型

### 第 1 步：测试集伪标签类别占比（用分析脚本）
```bash
# 服务器上跑（CPU 后台，500 张约 30-40min）
/home/jhy/diag/analyze_test_prior_pseudo.py
# 输出：/home/jhy/diag5b_test_pseudo_prior.json
# 关键字段：test_frac / delta_test_minus_train / conf_mean
```
**这一步给出复赛测试集的真实类别先验**，是 bias 调整的直接依据。

### 第 2 步：用伪标签占比确定 bias 调整方向
| 类 | 初赛 Δ(测试−训练) | bias 方向 |
|---|---|---|
| 背景 | +4.75% | **继续压低**（当前 −0.20，可试 −0.25/−0.30） |
| 植被 | −4.71% | **可能上调**（当前 +0.40，可试 +0.50/+0.60） |
| 农田 | +1.39% | 微调（当前 3.3215，可试 3.5） |
| 水体 | +0.95% | 微调（当前 0.70） |
| 荒地 | −0.91% | 微调（当前 3.60） |
| 道路 | −0.64% | 微调（当前 0.0709） |
| 建筑 | −0.67% | 微调（当前 −0.0384） |
| 车辆 | −0.15% | 微调（当前 −0.50） |

**注意**：这是"起始方向"，**必须按第 3 步逐个重扫**，不能直接套（类间耦合，单维最优≠组合最优）。

### 第 3 步：bias 逐维重扫（用校准扫描脚本）
```bash
# 服务器上，GPU0 轻任务串行（复用 run_calib_road_build_scan.sh 模式）
# 每次只改一个维度，其余用锁定值
run_bias() {
    local tag=$1; shift
    local out="/home/jhy/calib_${tag}"
    local zip="/home/jhy/calib_${tag}.zip"
    $PY "$SCRIPTS/rot_tta.py" \
        --experiment-dir "$EXP_DIR" --checkpoint "$CKPT" \
        --dataset-root "$DATASET" --output-dir "$out" \
        --device cuda:0 --prior-shift --prior-bias "$@"
    $PY "$SCRIPTS/check_submission.py" \
        --test-images "$DATASET/images" --predictions "$out/predictions" \
        --output-dir "$out/check_out"
    $PY "$SCRIPTS/package_submission.py" \
        --test-images "$DATASET/images" --predictions "$out/predictions" \
        --check-json "$out/check_out/submission_check.json" --zip-path "$zip"
}
# 8 维各扫 3-4 个值，锁定向量顺序：背景/建筑/道路/水体/荒地/植被/农田/车辆
run_bias "bg_m25" -0.2500 -0.0384 0.0709 0.7000 3.6000 0.4000 3.3215 -0.5000
run_bias "veg_p5" -0.2000 -0.0384 0.0709 0.7000 3.6000 0.5000 3.3215 -0.5000
# ... 逐个类扫
```
**每次提交看线上分**（本地分不可信，判据=线上标准版）。校准空间由 logits 系统性偏置决定，复赛换分布后模型 logits 分布会变，bias 必须重扫。

### 第 4 步：多维多维组合微调
- 单维最优不等于组合最优（历史规律：类间耦合，车辆−0.40 单维更优但组合 water0.70 下 −0.50 更好）
- 找到 2-3 个单维顶点后，两两组合试一轮
- 组合涨幅 <0.01 即到顶，停止

### 第 5 步：锁定 + 记录
- 记录复赛锁定 bias 到成绩表
- 若复赛还换了模型（如用上了 Exp46/47 或新模型），**bias 必须按该模型重新扫，禁止复用 B3+CWFA 的参数**（历史教训：校准不跨模型迁移）

## 四、关键纪律

1. **校准 bias 绝不跨模型复用**（B4+no-decay 崩到 7.93 的教训）
2. **本地分不可信**，判据=线上标准版
3. **伪标签先验只给方向**，最终以逐个线上提交为准
4. **校准空间由 logits 偏置决定**，不是标准版高就校准空间大
