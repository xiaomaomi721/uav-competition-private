### 判据

- **s62 单轴**：基准为 `s62_ref_champion`（对应 28 = 0.686610）。任何单轴 > +0.05pp 才视为信号；若全轴全负，**s62 专属校准线立即终止**。
- **Paramwise01**：二维评价 —— zero-bias 对比 s62 的 0.680973；champion 对比 s62 的 0.686610。

### 第二批（GPU 主线）

**Stage23 + s62 双教师 soft-KD，student 从 s62 初始化。**

第一版严格克制：
- 真实 5597 张：hard CE
- test1 500 张：soft KD，`L = L_CE(real) + λ·w(x)·T²·KL(q_teacher ‖ p_student)`
- `w(x)` 用 teacher confidence / agreement 降权
- **不叠 RareExposure / SEMEDA / MixUp / MaxEnt**
- **教师用 zero-bias logits**

### 需要新增的代码（不是配置）

1. 教师概率缓存（Stage23 + s62 对 test1 的完整 softmax，**zero-bias**）
2. 无标签 test 数据加载器
3. soft-target KL 损失
4. 加权 / 掩码
5. real / test 批次混合策略

> ⚠️ **陷阱警告**：现有 `distill.py` 是 **DINOv2 特征余弦蒸馏**。
> 若只改 config 会得到一个「看起来像 KD、实际跑的是 DINO 特征蒸馏」的错误实验。
