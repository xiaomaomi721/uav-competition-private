# B4/B5 参数机制 + epoch/loss 关系 + 三大难点应对（深度分析）

> 用途：吃透 B4 参数机制、epoch/loss 关系、赛题三大难点如何针对 B4 应对。
> 更新：2026-08-29

---

## 一、B4 的完整参数机制（config 硬数据）

### SegFormer B3/B4/B5 的唯一区别 = depths（层数）
```
B3: hidden_sizes=[64,128,320,512] depths=[3,4,18,3]  → 47.2M
B4: hidden_sizes=[64,128,320,512] depths=[3,8,27,3]  → 64.0M
B5: hidden_sizes=[64,128,320,512] depths=[3,6,40,3]  → 84.6M
```
其余全部相同：decoder_hidden_size=768、num_attention_heads=[1,2,5,8]、sr_ratios=[8,4,2,1]、mlp_ratios=[4,4,4,4]、drop_path_rate=0.1。

### 参数怎么影响训练（机制级）
1. **depths 增加 → 层数变多 → 模型容量/表达力↑**，但**梯度路径变长 → 更容易梯度不稳定 + 过拟合**。
2. **B4 在 stage2(4→8)、stage3(18→27) 加层** → 中层语义更强，但**中层是"纹理/中尺度特征"所在**，加层后对训练集的纹理细节记得更死 → 过拟合训练域的纹理 → 换测试域就崩。
3. **decoder_hidden_size=768 不变** → 解码头容量没变，encoder 变深了但 decoder 没跟着长 → 信息瓶颈。

### 关键：drop_path_rate=0.1 没针对大模型调
drop_path（Stochastic Depth）是正则化，B3/B4/B5 都用 0.1。但**越大的模型越需要更大的 drop_path 来抗过拟合**（论文常识：ViT-Large 用 0.2~0.3，ViT-Huge 更高）。我们 B4 还用 0.1，正则不足。

## 二、epoch/loss 关系（回答"1 epoch=40 步是否适用 B4"）

### 事实
- 训练集 5597 张，batch_size=2，grad_accum=2 → effective_batch=4。
- max_steps=56000 → **40.02 个 epoch**（对 B3/B4/B5 都一样，因为数据量/batch 相同）。

### mIoU 曲线（前/中/后）
| 模型 | step1400(ep1) | step19600(ep14) | step37800(ep27) | step56000(ep40) | best@ |
|---|---|---|---|---|---|
| B3 | 0.6911 | 0.7768 | 0.7987 | 0.8091 | 47600(ep34) |
| B4 | 0.6912 | 0.7893 | 0.8054 | 0.8170 | 53200(ep38) |
| B5 | 0.7041 | 0.7846 | 0.8050 | 0.8165 | 53200(ep38) |

### 关键洞察
1. **B4/B5 在本地验证集上确实学得更好**（0.8170 vs B3 0.8091），best 出现得更晚（ep38 vs ep34）——**本地分越高、越晚饱和 = 越在"死记"训练域**。
2. **但线上 B4(66.95) 反而 < B3+CWFA(67.37)** → 本地曲线和线上方向相反，正是"过拟合训练域、泛化崩"的铁证。
3. **40 epoch 对 B4/B5 太多**：大模型应该更早停（early stop），因为它们在 ep38 才 best，说明一路在过拟合，没有"平台期"。

## 三、赛题三大难点，B4 如何应对（针对设计）

### 难点① 域差异 DomainGap
- B4 现状：过拟合训练域，域泛化差（CWFA 还 −0.95）。
- **应对**：不是再加扰动正则，而是 ①降学习率（6e-5→2e-5）让预训练权重少被破坏 ②加大 drop_path（0.1→0.2）抗过拟合 ③label smoothing 防止过自信。

### 难点② 类别/先验不平衡（车辆0.91%、荒地2.51%）
- 老师提示"数据增广"：少数类 Copy-Paste（已做 Exp33，对症）。
- 老师提示"长尾分布"：这是 class imbalance 的学术说法。**对 B4 的意义**：大模型更容易在长尾少数类上过拟合（记死少数样本），所以 B4 更需要少数类增广 + 降学习率。

### 难点③ 极端尺度差异（细窄道路、小目标车辆）
- B4 中层加深（stage2 8层/stage3 27层）→ 对**中尺度纹理**强，但**细窄目标在 32× 下采样已经丢失**（前面诊断：细路像素占0.013%不是瓶颈）。
- **对 B4 的应对**：多尺度上下文融合（FPN/ASPP）让 decoder 显式融合多尺度，弥补"细目标丢失"。

## 四、综合结论：B4 的正确打法（重新排序）

之前我们一直"往 B4 叠方法"（CWFA/校准），方向错了。正确顺序：

1. **先把参数调对**（最优先，零风险）：
   - 学习率 6e-5 → **2e-5**（大模型微调铁律）
   - drop_path 0.1 → **0.2**（大模型需更强正则）
   - 可选 label smoothing（防过自信）
2. **再谈方法**：
   - LoRA 参数高效（降低过拟合，B5 已写代码）
   - 蒸馏（外部表示纠偏，已写代码）
   - 少数类 Copy-Paste（补长尾，已写代码）
3. **针对三大难点的 B4 专项**：
   - 域差异 → 降学习率 + drop_path + label smoothing
   - 不平衡 → Copy-Paste + 长尾感知
   - 尺度 → 多尺度上下文融合（FPN/ASPP，未做，候选）
