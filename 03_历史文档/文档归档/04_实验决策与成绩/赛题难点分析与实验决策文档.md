## 一、项目目标与规则（一句话）

在 2026AIC 无人机低空航拍图像语义分割赛道中，用官方数据 + 公开学术预训练权重，单模型（不做 ensemble）最大化测试集 mIoU。8 个评测类 + 忽略类，评测指标是 **每类平权的 mIoU（各类权重 1/8，不是像素加权）**。

**硬约束**：只能用官方数据；预训练权重须学术公开；禁止商业闭源 API、外部数据、多模型 ensemble；提交 PNG 须同名、1024×1024、单通道非调色板、官方 ID 0-8。

---

## 二、官方赛题明确强调的三大难点

1. **多源域差异（domain gap）**
2. **类别/先验不平衡（class/prior imbalance）**
3. **极端目标尺度差异（extreme target-scale differences）**

这三条必须逐一对数据验真，不能凭感觉。

## 三、数据实证结果（全部实测，非推测）

### 3.1 数据规模与结构
- 训练集：6996 张 1024×1024 图 + mask（尺寸统一）
- 测试集（当前）：500 张 `test1_*`
- 官方示例：11 张；标签：0=Ignore + 8 类

### 3.2 难点① 类别占比不平衡 —— 已解决
训练集 6996 张类别像素占比（实测）：

| 类 | 占比 |
|---|---|
| 植被 | 28.78% |
| 背景 | 28.01% |
| 建筑 | 18.28% |
| 道路 | 8.92% |
| 农田 | 7.10% |
| 水体 | 6.29% |
| 荒地 | 1.83% |
| 车辆 | 0.78% |

车辆 vs 植被差 **37 倍**，荒地差 16 倍。
**解法**：prior-shift（乘官方测试先验）已 +0.342，这是对难点①的正确解。

### 3.3 难点② 域差异 —— 真相是"自信地错"，不是颜色差异
- 颜色层面训练/测试几乎一样：亮度差 3.4，饱和度差 1.5。
- 训练集内部分块亮度均匀（35 块无拼接跃变），高度同质。
- 模型在测试集 softmax 置信度 0.932 vs 训练集 0.947，**只差 0.015**。

**结论**：模型不觉得测试集更难，它是"自信地错"。14 分本地↔线上鸿沟 = 标注含糊 + 类别先验错配，不是颜色域差异。

### 3.4 难点③ 尺度差异 —— 真实，但主受害者是"细窄道路"，不是"小目标"
连通域面积分析（32× 下采样后 <1px 被抹掉占比）：

| 类 | 被抹掉占比 |
|---|---|
| 背景 | 89.6% |
| **道路** | **79.9%** |
| 植被 | 61.2% |
| 车辆 | 37.1% |
| 荒地 | 34.3% |
| 建筑 | 34.5% |
| 农田 | 21.0% |
| 水体 | 16.8% |

**关键纠正**：尺度难点的最大受害者是**道路（细窄线性目标）**，不是我们早期以为的"小目标车辆"。车辆中位数 2756px（约 52×52）其实不算小。

> **⚠️ 重大二次纠正（2026-08-27，必须看）**："细窄道路是最大受害者"这个判断本身是**被"连通域数量"误导的**。真相：
> - 细路(<100px)在道路类里**数量占 79.9%**（连通域数），但**像素只占 0.013%**（3860 px / 2956万 px）。宽路(>10k)占道路**像素 98.6%**。
> - **mIoU 是像素级指标**，细路像素 0.013% × 道路类占 1/8 = 对最终分数影响 <0.01 分。**细路根本不是分数瓶颈。**
> - 四条独立证据证明细路在 SegFormer 下不可解：①训练域细路召回仅 15%（主 head）②放大后细路流失 84.6% ③线上单调恶化 −4~−8 ④stage0 浅层特征线性 probe 召回仅 3.8%（浅层无语义，深层才有的语义在 32× 下采样时已把细路抹掉 = 结构性死结）。
> - **教训：任何"占比"统计，先分清"数量占比"还是"像素占比"，两者指向相反的结论。** 细路方向彻底封存，不再投入。

### 3.5 发现3（增量）：类内形态偏移 —— 训练偏宽路/城市，测试偏细路/乡村
- 数据：细路连通域(<100px)占比 **训练 15.1% vs 测试 20.5%**；宽路(>10000px) **训练 65.8% vs 测试 51.3%**。
- 含义：测试集不止"类别比例"不同，**"类内形态"也不同**（同样是道路，测试集更细）。
- 来源：用户肉眼观察官方示例图（图2=细田埂、图3=林间小路被树冠覆盖），后经数据证实。

## 四、方法成败规律（线上实测，硬证据）

| 方法 | 攻击对象 | 线上结果 | 结论 |
|---|---|---|---|
| prior-shift | 测试分布（外部事实） | **+0.386（Exp18复验）** | ✅ 保留 |
| prior-shift 系数扫描 | 后处理力度 | **3.0×=67.393 顶点** | ✅ 最优系数 3.0 |
| **水平翻转 TTA** | 单模型翻转平均 | **+0.130（标准）/ +0.211（叠prior）** | ✅ 保留 |
| CWFA | 特征层域泛化 | **+0.632（B3上，Exp23）** | ✅ 保留（B2 时 +0.110，B3 放大6倍） |
| no-decay | 训练正则化 | **+0.673（B3，Exp25标准）** | ✅ 保留（破"训练期技巧全负"铁律） |
| B4 纯CE | 容量对照 | **66.951（<B3+CWFA 67.371）** | ⚠️ 待定（没加 CWFA，看 Exp29） |
| B5 纯CE | 容量对照 | **66.405（公平对比即败）** | ⚠️ 待定（疑 ade640 预训练，LoRA 是出路） |
| B3@1024 | 容量×分辨率协同 | **+0.296（翻案）** | ✅ 保留 |
| 伪标签 | 测试图灌训练 | **−0.136（Exp22判决）** | ❌ 放弃 |
| 测试时高分辨率推理 | 输入放大（分布外） | **−4.2~−8.0（方向3判决）** | ❌ 放弃 |
| 多尺度 TTA | 尺度鲁棒（改分辨率） | 全负 | ❌ 放弃（注意：仅限多尺度，hflip 是正的） |
| Lovász | 类别平衡（内部优化） | −0.415 | ❌ 放弃 |
| EMA | 权重平滑（内部技巧） | −0.445 | ❌ 放弃 |
| RareCrop/DomainAug/LightBlur | 输入增广 | 全失败 | ❌ 放弃 |

> **重要修正（2026-08-26）**：B3 不是"越大越差"。B3+768 曾 −0.73，但 B3+1024 标准 66.739 > B2+1024 66.443（+0.296）。结论：容量和分辨率协同，B3 需要原生 1024 整图才发挥优势。

> **伪标签判决（2026-08-27）**：Exp22（B2 伪标签）标准 66.307 vs Exp14（B2 基线）66.443 = **−0.136 有害**。伪标签虽名义"借用测试分布"，但标签是模型自己生成的，有确认偏差，把模型的错误倾向固化进训练数据；连 prior-shift 版一起拖累（Exp22 prior 66.504 < Exp14 prior 约 66.79）。**"贴测试分布"的正解只有 prior-shift（纯输出空间后处理，零自指），不含 self-training。**

> **高分辨率推理判决（2026-08-27，方向3）**：B3 测试时放大输入推理，1.5× 标准 62.507 / 2.0× 标准 58.699，vs 1.0× 标准 66.739，**分别 −4.23 / −8.04，随分辨率单调恶化**。

> **连通域分桶诊断（2026-08-27，逐像素对比 1.0× vs 2.0× 的 500 张预测，定位真凶）**：
> - **真凶不是"大目标"，是"中小目标"被系统性误判成背景**。按连通域面积分桶的"→背景流失率"：细路(<0.5k) 84.6%、中小农田 87.5%、中小水体 75.2%；而大目标(>10k) 反而最稳（道路 13.1%、水体 13.7%）。
> - 农田整体 46.5% 流向背景（最惨的类），但拆开是农田里的**中小连通域**在流失，不是大田。
> - **机制**：放大到 2048 是分布外输入，SegFormer 在 1024 训练时没见过的小尺度 patch 特征失准，导致中小目标（尤其细路）被大量判成背景。所谓"放大让细路看得更清楚"的直觉**完全失败**——恰恰相反。
> - **结论**：测试时改分辨率（放大/缩小）整体是死路，方向3 所有变体放弃。细路要救只能走**训练期结构层**（让模型训练时就学会处理细路），测试期改输入只会把它推进分布外。

### 核心规律（三连证据）
> **只有"用官方测试分布的外部事实"涨分；一切"训练期内部技巧"都拖后腿（Lovász −0.415、EMA −0.445）。**

### 本地分 vs 线上分（铁证）
- CWFA：本地↓ 线上↑（+0.110）
- Lovász：本地↑ 线上↓（−0.415）
- EMA：本地平 线上↓（−0.445）

**本地 mIoU 连方向都预测不准。** 根因：验证集是 stratified 从 6996 训练图切出的 1399 张，**与训练集同域**，无法代表真实测试集。→ 判断方法必须走"提交看线上分"闭环。

## 五、决策原则（必须遵守）

1. **先分析数据与赛题，再定方案** —— 用户明确要求，别盲跑方法。
2. **线上分才是唯一真相** —— 本地分只当初步筛子，不能当死刑判决。
3. **优先"外部事实"（官方测试分布），别让模型"内部优化噪声目标"**。
4. **输入空间增广 / 训练期内部技巧已证伪，别再去挖**。
5. **荒地（标注墙，RGB 召回仅 38.6%）不可修，放弃投入**。
