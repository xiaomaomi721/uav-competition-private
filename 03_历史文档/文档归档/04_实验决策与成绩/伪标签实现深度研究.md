# 伪标签实现深度研究（执行前必读）

> 2026-09-03。等 GPU 腾出前，把伪标签实现的坑研究透。核心原则：官方点名"无脑全用效果一般，必须置信度筛选"，但我们不能重蹈"以为加了筛选就够"的覆辙——逐像素过滤也有坑。

## 5 个实现审查点 + 决策

### ① TTA8 平均会让置信度系统性偏高 → 阈值不能照抄 0.9
- 问题：TTA8 视图平均 logits 会降方差 → softmax 置信度比单视图**偏高**（8 个一致视图平均≈更确信）。直接设 conf>0.9 会保留过多。
- 决策：**smoke 时先统计 keep 比例**。若 conf>0.9 保留 >70% 像素 → 阈值太松，提到 0.95；若 <30% → 太紧。以"keep 比例 + 逐类平衡"为准，不是拍 0.9。

### ② 逐像素 argmax 产生椒盐 ignore 洞 → 需区域级过滤（关键，官方没明说）
- 问题：conf 逐像素过滤，低置信像素挖成 255。车辆等小目标内部某像素置信低 → 被挖洞 → 训练 CE 对洞邻域敏感、且语义碎片化。
- 业界做法：**实例/连通域级过滤**（一个连通域平均 conf 达标才整块保留），比逐像素干净。
- **✅ 已解决（2026-09-03 v2）**：改为连通域级过滤。初版用"域均值≥阈值"有 bug——稀疏洞会把好块的均值拖低、整块误杀（实测：8px@0.93+1洞@0.3，均值0.86<0.9 整块被删）。**v2 改用"域内 ≥80% 像素 conf≥阈值才整块保留"**，对洞鲁棒。离线合成测试 PASS（含洞好块保留、低置信整块滤、单px高置信保留）。脚本已更新 `/home/jhy/gen_pseudo_labels.py`。

### ③ 伪标签会稀释真实分布 → 按类看保留率
- 问题：500 测试伪标签 + 5597 真实图，伪标签占 ~8%。若某类(如车辆)测试置信度普遍低 → 过滤后全 ignore → 该类"白加"，还稀释真实车辆样本。
- 决策：smoke 后看 `kept_pixel_per_class_official`，**逐类保留率**。若车辆保留率<20% → 该类单独降阈值或对该类不做伪标签（只吃真实）。

### ④ 阈值 0.9 未经验证 → 先用 smoke 定
- 决策：先 smoke(3张)→看 keep 比例 + 逐类 → 再定全量阈值。不预设。

### ⑤ 少数类(车辆)置信度天然低 → 伪标签可能帮不到车辆
- 问题：车辆 0.78% 像素、与背景孪生，模型对车辆像素置信度可能普遍 <0.9 → 过滤后车辆几乎全 ignore。
- 但反过来说：**低置信车辆像素若被高阈值过滤掉，就不算"教错"**——这反而是安全。要补车辆得靠真实数据(⑥)或约束 CopyPaste，不靠伪标签。
- 决策：接受"伪标签主要补背景/道路/农田等大类的测试域分布差"，车辆不指望它。这符合"伪标签补分布、真实数据补稀有类"的分工。

## 关键设计决定汇总
1. **伪标签 = 补"测试域分布"**（背景/农田等大类占比差），**不指望补稀有类**（车辆靠真实数据）
2. 第一版：逐像素 conf 过滤，阈值由 smoke 定，倾向 0.95
3. 训练时伪标签图与真实图**同 batch 混合**（不单独分段，避免两阶段复杂化）
4. **最终提交单模型**（合规红线）
5. 新模型必须重扫 8 bias

## 合规边界（官方原文确认）
- 允许：自训模型给官方测试图生成伪标签 + 加入训练；不属于外部数据集
- 禁止：推理阶段多模型集成/融合（我们单模型提交）
- 训练阶段可用任意多模型/蒸馏/伪标签
