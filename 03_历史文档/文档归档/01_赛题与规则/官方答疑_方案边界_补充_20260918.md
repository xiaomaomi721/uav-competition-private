## 三、这条确认实际覆盖了什么（范围界定）

本项目的**当前冠军 `237_S_semeda_M = 0.702574` 本身就是**：

```
θ = soupC + Σ_g α_g · (s55b − soupC)|_g  +  β · (Exp47 − soupC)|_stage2
soupC = (s58 + s64)/2
α = {stage0: +0.5, stage1: +0.5, stage2: +0.2, stage3: −0.1, head: 0.0}
β = +0.2188631149
```

**注意 `α_stage3 = −0.1` 是负系数** ⇒ 这是"带负系数的仿射组合"，比教科书式的
convex weight averaging 更进一步（task arithmetic 形式）。

**⇒ 本次确认必须覆盖到这一情形，否则当前冠军自身就在红线外。**
**在执行 Phase 0（`θ237 + λ·v`，系数 +1, +λ, −λ）之前，这一条应当被明确问过。**
