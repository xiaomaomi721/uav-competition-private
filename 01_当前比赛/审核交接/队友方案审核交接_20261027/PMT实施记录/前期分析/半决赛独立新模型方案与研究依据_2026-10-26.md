# 半决赛独立新模型方案与研究依据

日期：2026-10-26。目标：半决赛线上 mIoU 72。本文给出下一轮主要开发方向，不按剩余提交次数预排比赛计划。

## 决策

**建议把下一轮主要开发资源投入：DINOv3-L 通用图像预训练骨干冻结 + PMT 区域分割解码器，建立能够独立提交的八类模型。**

采用官方 PMT 的 ADE20K 解码器预训练权重初始化，更换分类输出为八类加 no-object；首先直接学习比赛源域真值。这个模型不是 H75 的附属教师，目标是作为最终单模型与 H75 竞争。是否进一步进行目标域训练，由它自己的逐类诊断决定。

这是本轮研究后选择的正式新模型路线，不是已经验证上涨的权重。当前没有其比赛数据训练结果，也没有半决赛线上成绩；不能称“已证明最可能达到72”。选择依据是：语义错分的项目证据、独立强表征的研究依据、完整公开实现，以及本轮单卡资源实测。

相比此前笼统的“冻结 DINO 加小头”，本次明确了可复用的区域解码器、已有分割初始化、源域错误结构、实际资源成本与验证流程。DINO 这个名称本身并不是本次的新发现，PMT 也不是我发明的方法；价值在于建立完整且可执行的独立模型路线。

## 1. 本轮实际完成的工作

1. 重新阅读历史 B4、MIC、失败归因、竞赛规则和队友 M2F 审计，区分实验配置、结果与未经证明的解释。
2. 核查 HRDA、MIC、ProtoSeg、Rein、PiPa++、标签统一、DINOv3、EoMT、PMT 的原始论文或作者代码；对 PMT 进一步阅读骨干封装、前向、解码器、训练配置和模型下载目录。
3. 新服务器只使用 CPU 读取已有 H75/M2F 缓存及1399张源域真值，新增区域内部/边界错误诊断和训练—验证重叠分组，耗时218.6秒。
4. 旧服务器 GPU0 进行了两项短时合成资源测试：官方 PMT 解码器；随机初始化的 ViT-L 规模冻结骨干加官方解码器。没有训练比赛权重，没有使用真实测试图训练，没有提交比赛。
5. 测试结束确认旧服务器GPU0回到18 MiB、0%，诊断进程已结束。依赖只装到独立审计目录，没有改队友环境。

核查时新服务器GPU1有队友尺度审计/其他进程活动，因此没有占用其GPU。本轮不会把“GPU当时空闲”当作下一次启动的授权状态，实际运行前仍需重新检查。

## 2. 赛题中的问题应怎样重新理解

### 2.1 不能把所有失败都归结为“同源闭环”

同源自训练并不在理论上被教师准确率封顶。未标注图像、不同视图、增强、正则化和真值监督可以改变学生的泛化行为，项目本身也有自训练成功记录。

真正可以确认的是：历史多个实验集中在保留现有输出、调节决策边界、续训和蒸馏；这些实验没有充分检验另一种表征是否能直接成为更强的最终模型。它是研究覆盖的缺口，不是已经证明的唯一根因。

### 2.2 新实测支持语义判别路线，但不证明边界没有价值

本次使用 H75 D4 原生256网格缓存，源域真值以步长4采样。以下先看零偏置，以减少把目标域校准当作源域表征能力的影响。距离按原生网格测量后换算为原图像素，是近似距离。

| 真值类别 | 错分像素中，距标注边界超过8原图像素 | 超过32原图像素 |
|---|---:|---:|
| Background | 53.56% | 30.48% |
| Barren | 66.81% | 34.12% |
| Agricultural | 72.41% | 48.53% |
| Vehicle | 21.52% | 4.05% |

大量荒地、农田错误位于区域内部，因此仅修边界、仅增大输出分辨率不构成完整答案。这支持优先研究更好的语义特征和区域分类。

限制：这是源域FN像素的空间分布，不包括该类全部FP结构；距离边界远也不能单独证明“缺乏全局上下文”或“骨干容量不足”。目标域无GT，不能把这些比例直接写成线上丢分占比。

边界仍然重要：在同一源域协议下，把边界邻域全部错误替换成GT的反事实上界，从80.18升到88.70；只修内部则到90.49。这两个上界不可实际取得、不可相加，也不是预期增益。它们说明两类错误都存在，而不是让我们忽略细节。

### 2.3 小类像素少，不能推出对mIoU贡献小

mIoU按类别平权。车辆IoU提高8个百分点，在其他类别不变时就是总mIoU提高1个百分点，与车辆占总像素比例没有直接等价关系。

旧材料中由车辆/细路面积占比直接估算“最多涨0.1分”的说法，不能作为路线封禁依据。本次源域反事实：修复所有涉及Vehicle的误分类，80.18可到82.68；这只是诊断上界，但足以说明“车辆小所以一定不值得做”不成立。

### 2.4 验证集的问题比“负相关”更具体

原1399张验证图中，762张直接与训练图共享已检测到的像素。把同一精确重叠连通分量内的间接关系也纳入，有794张与训练图处于同一分量，剩605张未检测到此关系。

这605张包含原验证集99.00%的荒地GT像素、98.44%的农田GT像素，却只包含9.51%的车辆GT像素。因此“重叠组与非重叠组总分不同”混入了很大的类别与场景组成差异，不能直接当作泄漏造成的分数差。

| 模型/设置 | 原1399张，原生256诊断mIoU | 未检测到训练连通关系的605张 |
|---|---:|---:|
| H75，零偏置，D4缓存 | 80.18 | 74.27 |
| H75，完整Bstar，D4缓存 | 77.29 | 70.64 |
| 既有M2F单视图缓存 | 79.20 | 73.56 |

H75与M2F视图协议不同，不能当作纯架构胜负。这里的新作用是形成更有针对性的语义压力测试集合，并提示逐类看结果。

605张也不是“已经证明独立的航线验证集”：当前只检测特定768步长的精确重叠；历史模型也反复用过源域验证集。不能把70.64与线上71.xx接近解释为新代理已有效。

## 3. 为什么选这套新模型

### 3.1 改变表征来源，并保留学习区域语义的能力

骨干选择官方 `facebook/dinov3-vitl16-pretrain-lvd1689m` 通用图像版。官方参数表约300M。本轮同规模结构实例化为303,129,600个参数。

DINOv3 提供强稠密特征的研究依据，但不保证本赛题上优于 MiT 或 Swin。本次选择通用图像版，主要因为官方 PMT 的语义解码器恰好与它配套，减少不必要的权重和接口错配；不依据“低空航拍等于卫星图”的假设。DINOv3论文中部分自然图像与卫星模型的比较使用不同模型规模，也不能据此声称Web-L必胜Sat-L。[DINOv3论文](https://arxiv.org/abs/2508.10104)、[官方模型](https://github.com/facebookresearch/dinov3)

PMT从冻结骨干的多层特征中学习区域掩膜和类别，能够作为完整的语义分割模型。选择已有ADE20K解码器初始化，是为了避免在本项目有限GT上从头训练全部分割模块。[PMT论文，CVPR2026 Workshop](https://arxiv.org/abs/2603.25398)、[官方代码](https://github.com/tue-mps/pmt)

冻结骨干只是减少遗忘预训练表征的途径，不保证不会过拟合；约5370万参数的解码器仍有明显学习容量。Rein关于保留强预训练特征的研究支持这一设计原则，不证明PMT在航拍域一定泛化更好。[Rein，CVPR2024](https://openaccess.thecvf.com/content/CVPR2024/html/Wei_Stronger_Fewer__Superior_Harnessing_Vision_Foundation_Models_for_Domain_CVPR_2024_paper.html)

### 3.2 它与队友M2F、以前DINO蒸馏的区别

| 已有路线 | 本方案的实质区别 |
|---|---|
| Swin-L/M2F常规续训或修改query反馈 | 改为DINOv3冻结稠密特征和配套区域解码器；不重复B1/P1-C |
| DINOv2特征蒸馏给B3 | DINO体系自身直接输出最终八类预测，不要求知识通过H75学生传递 |
| B3换B4后继承训练配方 | 利用不同预训练目标、冻结骨干和已有分割初始化；不是只增加MiT深度 |
| H75重叠概率蒸馏 | 不依赖只覆盖部分图像的真实重叠，也不依赖教师额外上下文能被学生继承 |

这些区别使历史失败不能直接否定新方案，但也不消除新方案失败的可能。

## 4. 工程实测与真实成本

旧服务器单张RTX4090、24GB。官方PMD六层、100个query、1024维、八类加no-object，BF16，batch1；包括AdamW状态。每种尺寸仅4次合成更新。

| 合成测试 | 峰值分配显存 | 热身后每次前后向及更新 |
|---|---:|---:|
| 解码器，512对应网格 | 2.78 GiB | 约0.054–0.073秒 |
| 解码器，768对应网格 | 5.84 GiB | 约0.091–0.094秒 |
| 解码器，1024对应网格 | 11.10 GiB | 约0.182秒 |
| 随机初始化冻结ViT-L规模骨干＋解码器，1024 | 12.74 GiB | 约0.224秒 |

最后一项的骨干约303.13M、解码器可训练参数53,696,521；原官方多层SyncBN还有少量参数，未计入此代理。

**这些结果只验证计算可行性。** 合成损失不是实际匹配/分割损失；没有数据读取、Hungarian匹配、真实预训练权重、完整训练框架和多GPU同步。运行环境也与官方固定依赖版本不同。因此不能从0.224秒直接承诺实际训练小时数，更不能宣称新模型已通过准确率验证。

原先“300M模型五天连探针都未必做完”的说法缺少依据；本轮已证明主要结构的1024计算可以在旧24GB单卡运行。完整训练仍需用真实权重和100次更新量出实际吞吐，再确定预算。

## 5. 下一轮正式执行规格

### 5.1 权重与数据

- 骨干：上述DINOv3-L通用图像版，全程冻结；运行时显式保持eval，不仅关闭梯度。
- 解码器：官方 `ade20k_semantic_pmt_large_512_dinov3`，重置分类层为9输出，其余可加载部分严格校验。
- 官方PMT模型目录明确说明：下载文件**只有解码器**，不含DINOv3骨干。不能把一个文件成功下载当作环境已就绪。
- 本轮没有下载或验证这两份预训练权重。取得骨干需要具备相应官方访问权限；使用前记录来源、许可证、SHA256和加载缺失键。
- 训练只用官方5597张训练图及其GT；1399张用于诊断。先不把验证GT并入训练。
- 模型最终包含冻结骨干和解码器的完整状态，作为一个分割网络推理，不在推理阶段融合H75或M2F输出。

### 5.2 第一个正式版本

以下是拟定起始配置，不是已经跑过的最优参数：

| 项目 | 起始规格与理由 |
|---|---|
| 输入 | 1024整图，保留原始目标尺度；不先把图统一压成512 |
| batch | microbatch1，累计4次；先单卡跑通。累计梯度不等价于扩大BN的实际batch |
| 更新模块 | 新分类头、PMT解码器与其多层特征投影/归一化；骨干不更新 |
| 优化器 | AdamW；预训练解码器LR起点2e-5，新分类头2e-4；真实100步检查梯度与损失后冻结配置 |
| 训练窗口 | 首个完整比较窗口8000次成功优化器更新；保存2000/4000/8000节点，观察是否仍在学习，不因新图片更多就机械延长 |
| warmup | 起点400次成功更新；不照搬ADE20K的6000步warmup |
| 损失 | 沿用PMT区域匹配、类别CE、mask BCE与Dice；官方ignore像素必须在匹配与mask损失中都正确处理 |
| 增强 | 先采用与航拍方向无关的D4几何增强；不同时叠加CWFA、困难类别对损失、ClassMix、FDA |
| 注意力mask | 采用官方退火机制，按本轮有效更新数重设结束时点；不能沿用超出8000步的原配置，否则推理关闭mask时可能出现训练/推理差异 |
| 日志 | 成功更新数、每类有效GT/损失、训练/验证曲线、峰值显存与实际吞吐；关闭外部在线日志上传 |

上表调整应以实际权重加载、loss行为和吞吐检查为依据，不能用目标测试预测占比反复调到符合预期。完整端到端训练代码还未适配，本文件是执行设计，不是声称已有可运行比赛训练器。

### 5.3 校准必须单独处理

PMT以query类别概率与掩膜概率汇总语义分数，数值定义与B3 raw logits不同。**禁止直接加H75的Bstar，禁止用H75预测面积冒充目标真实先验。**

首轮离线比较采用统一无额外偏置协议，并同时保留H75的正式协议作为实际系统参照。若新模型源域强、目标少数类明显不稳定，不能凭源域总分直接提交；先分析它自己的置信度、类间竞争和目标预测，决定是否做目标域自训练或单独校准。任何仅靠源域选出的偏置都不能宣称在线可靠。

这仍是新模型路线的关键风险，本轮没有解决目标域校准的可识别性问题。该问题不能被“论文更强”掩盖，也不应反过来成为永远不建立独立新模型的理由。

## 6. 怎样评价它，而不重演本地涨线上跌

训练完成后的比较必须包括：

1. 相同GT网格、相同输入尺寸、相同视图数、明确偏置设置下的逐类IoU、混淆与区域内部错误；不得混用本轮原生256和正式1024指标。
2. 原1399张与605张压力测试子集分别报告，额外按类别和已知重叠分量统计；两个集合均不是新的独立目标验证集。
3. 固定样本上的纠错/损伤图：荒地/农田改善不能主要依赖把大量背景改成前景，建筑/道路/车辆不能被整体牺牲。只看模型分歧或置信度不构成正确性证据。
4. 目标3594张只做无GT的覆盖、异常、输入扰动一致性和固定可视审计。这些指标排查明显失败，不用作目标准确率替代品。
5. 若进入上线候选，需有同一半决赛数据上的H75基线作比较。复赛71.3294不是半决赛的已知基线，不能由它计算“只差0.6706”。

若有独立的新源域候选，下一次线上反馈用于判断整个系统是否值得推进；不预先排14次提交、不承诺固定尝试次数。若连语义压力测试和完整系统检查都未通过，就没有理由占用提交机会。

## 7. 其它路线为什么没有排在它前面

| 路线 | 本轮研究后的判断 |
|---|---|
| 从当前官方图像重新做一轮自监督适配 | 有价值，但先做会同时改变表征和训练目标，未确认是否优于直接利用已有强表征。目标图像又有显著空间重复，不能视为3594个独立场景。先建立新模型，再决定是否需要适配骨干 |
| PiPa++像素/patch自监督 | 支持目标结构可以提供额外学习信号；论文同时含语义监督/伪标签，不是完全摆脱语义教师的方法。其60k步方案不能说成“加一项loss、20分钟可完成” |
| 多原型/背景子类分类器 | 是合理研究方向；但尚未证明当前特征空间内只有分类头欠拟合。视觉子类不必然对应跨域稳定语义，不能先改标签再找依据 |
| HRDA/全局局部双分辨率 | 对尺度差异有机制依据，保留；本项目语义内部错误较多，且队友已经在核查尺度。不要重复同一工作，也不能因旧高分辨率推理失败就否定其完整训练结构 |
| EoMT全量微调 | 是独立架构候选；PMT的冻结骨干形式更适合本轮保留预训练表征的假设。不能把EoMT骨干直接冻结后声称等价于PMT，作者消融显示两者有实质区别 |
| 真实重叠上下文蒸馏 | 局部证据有效，但当前验证覆盖的六类不含荒地/农田，且教师额外上下文不一定能传给单图学生。作为补充研究保留，不再列为首要突破方案 |
| 用C0替换旧M2F教师 | 已有小幅源域改进证据，可由队友延续；不应成为我方独立研究的全部内容 |
