# 半决赛数据诊断与下一方案：论文依据和可证伪指标

日期：2026-10-26（Asia/Shanghai）。本文为论文与既有项目材料的分析，不是新数据实测报告；没有连接服务器、使用 GPU、生成新预测、训练或提交比赛。

## 1. 先限定我们可以从数据知道什么

本项目需要解决的是：在新增目标域没有 GT、source1399 不能可靠排序线上方案的条件下，如何减少选错模型、校准方向和伪标签的风险。不存在一个无条件成立的无标签 mIoU 估计器；以下论文提供的是有假设的估计或诊断机制。

- **已有事实**：现有交接记录 H75 在旧 test2 为 71.329400；HPRD-Lite 从 C 初始化，旧 test2 为 71.177602；R1099 上接受区域 precision 约 99.30%，目标域仅125/1300图有接受区域、覆盖约1.59%，1000步只有103步非空。这些是既有材料中的记录，本轮未复测。
- **不可直接推出**：目标域区域也有99.30% precision；1.59%面积等于1.59%梯度；125图不足必然是唯一瓶颈；旧 test2 的 H75 分数会在新半决赛保持。
- **无标签能测**：预测分歧、类面积与软概率质量、视图稳定性、区域接纳与丢失、特征域可分性、校准估计的数值病态和敏感性。
- **只有 GT 才能直接测**：谁纠正了谁、每类 precision/recall/IoU、接受区域是否正确。在 source GT 上测到的互补性不能自动变成目标域的互补性证明。

必须区分数据条件：若只有 PNG，只能做硬预测行为分析；若保存了每类 raw logits/概率，才能分析置信度和软质量；若只保存聚合 dense M2F 概率而没有 query logits/masks，就不能逆推出 query 门控损失；若没有冻结骨干特征缓存，就不能零 GPU 验证 DINOv3 表征。

以下选5项直接影响决策的原论文/官方实现：2024–2025模型选择、伪标签选择和PEFT工作，以及必要的label-shift与region实现基础。不为了凑2026年份引入未经核验的新方法。

## 2. EnsV，NeurIPS 2024：先回测无标签选型器，而不是直接相信它

**论文**：[Towards Reliable Model Selection for Unsupervised Domain Adaptation: An Empirical Study and A Certified Baseline](https://proceedings.neurips.cc/paper_files/paper/2024/hash/f50cebc22663df45ce619645bfabb3b3-Abstract-Datasets_and_Benchmarks_Track.html)。

**官方代码**：[LHXXHB/EnsV — ensv.py](https://github.com/LHXXHB/EnsV/blob/main/ensv.py)。

**论文机制**：将现成候选的概率平均，得到一个参考预测；按单候选与该参考的相似程度选模型。其用途是降低选择很坏候选的风险，不是获得目标真值。官方代码实际计算候选argmax与平均概率argmax的一致率。

**我们可从现有缓存做的一个指标：历史线上回测的选择遗憾。** 在缓存身份一致、测试图清单一致的候选池里，计算每个候选的 EnsV 分数，并利用已知旧线上分数计算 `regret = 池中最高线上mIoU - 所选候选线上mIoU`。对候选池做留一方法家族回测，不只留一checkpoint；记录最差选择次数、排序关联和按图像bootstrap的稳定性。

**支持什么结果**：在预先固定的历史池中，较直接source mIoU、平均熵等基线更少选到明显失败候选；移除单个同源家族后结论仍较稳定。这样只支持将其作为候选筛坏的辅助信息。

**否决什么结果**：加入更多H75同系checkpoint就改变排名；对已知明显下降的候选给很高分；所有候选分数几乎相同。此时不要用它分配半决赛稀缺提交次数。

**适用边界**：论文中的概率平均/NLL论据不自动提供本项目单候选mIoU保证。H75、C、Arm B和重复轨迹并非独立证人；共识可能同错。整体像素一致率还会被Background等大面积类别主导。可另报按参考预测类分组的一致率，但这是我们的扩展诊断，不应冒称原版EnsV。只有PNG时，硬投票相似率也只是另一个指标，不能当作原版概率EnsV。

离线计算参考预测的用途是分析和选择，最终只提交被选中的单模型；不要把参考预测当作本项目已经获准的比赛输出。

## 3. BBSE，ICML 2018：先检验校准估计是否病态，不能把面积变化当目标先验

**论文**：[Detecting and Correcting for Label Shift with Black Box Predictors](https://proceedings.mlr.press/v80/lipton18a.html)。

**论文机制**：在label shift假设下，源目标的 `p(x|y)` 不变，只有 `p(y)` 变化；使用源域带标签数据估计混淆矩阵，再结合目标预测分布求目标类比例。估计需要可识别、数值稳定的混淆矩阵，并非看到颜色差或预测面积差即可使用。

**现有缓存的一项指标：目标先验估计的稳定性。** 在固定预测协议下，用source GT和预测构建 `C[i,j]=P(预测=i | GT=j)`，用新目标平均预测组成 `q`，检查约束拟合 `C*pi≈q`。报告矩阵条件数/最小奇异值、每类估计与图像级bootstrap区间，以及切换source场景子集或B3教师后估计的变化。不要将邻近百万像素当百万独立样本。

**支持什么结果**：先在有GT的source留出样本上构造可控类比例变化，能够恢复已知比例；在真实目标上估计非负、稳定、残差较小，且不同合理source子集/模型结论接近。此时可以保留“有限度测试校准”的候选资格，不能宣布已识别真实先验。

**否决什么结果**：病态矩阵；先验随少数图像/教师强烈跳变；无约束解大量负值；source内可控shift都恢复失败。此时不应据此自动重算Bstar。

**关键不可辨识性**：只有 `p_source(x,y)` 与 `p_target(x)`，通常不能唯一确定 `p_target(y|x)`。相同的目标图像边缘分布可以对应不同标签机制。域分类器AUC高，只说明在该特征上分布容易区分；可能是类别比例、相机、场景、尺度或其他因素。AUC低也不能排除与分类相关的条件变化。拟合残差小只是没有暴露矛盾，不能验证label-shift假设。

因此，域可分性分析应采用按图像/航线分组的交叉验证、类/场景匹配与标签打乱对照，定位差异来自何处；不能从“可分”一步跳到“做颜色对齐”，也不能从“均值相似”跳到“没有域偏移”。如果仅有预测向量缓存，测到的是输出分布可分性，不是原始图像/表征域可分性。

## 4. CSL，ICCV 2025：先测“置信度能否分对错”，再决定是否改门控

**论文**：[When Confidence Fails: Revisiting Pseudo-Label Selection in Semi-supervised Semantic Segmentation](https://openaccess.thecvf.com/content/ICCV2025/html/Liu_When_Confidence_Fails_Revisiting_Pseudo-Label_Selection_in_Semi-supervised_Semantic_Segmentation_ICCV_2025_paper.html)。

**官方代码**：[PanLiuCSU/CSL](https://github.com/PanLiuCSU/CSL)。

**论文机制**：最大概率不足以区分过度自信的正确/错误预测；同时考虑最大置信度及非最大概率分布的离散信息，设计样本级筛选，并通过可靠像素遮挡促进上下文利用。

**现有缓存的一项指标：逐类风险—覆盖曲线。** 在没有用于拟合门槛的source GT留出图上，对现有最大概率筛选与额外概率分布特征筛选进行比较；固定每类相同错误风险或相同precision，检查可接纳的独立图数/区域数与覆盖。附错误检出AUPRC、困难类precision、置信度最高区间的实际错误比例。采用图像级拆分和bootstrap，避免同一图的像素进入拟合与验证两端。

**支持什么结果**：在Background之外，额外特征能在相近风险下稳定保留更多真实正确区域，而且不是少数图像重复贡献。此时可研究更有区分力的门控，先保持当前训练配方不变。

**否决什么结果**：在同一数据上拟合后看似改进，图像级留出即消失；只增加Background；困难类precision先下滑；所有模型高置信错误与正确样本仍几乎不可分。此时不应以“放宽门槛”扩大监督。

**迁移边界**：CSL的半监督基准不等于本项目跨域条件；source上的风险可控不保证新目标也可控。新目标只可检查置信度特征是否超出校准范围、区域稳定性是否异常，不能填目标precision。B3概率与M2F语义混合分数必须按各自定义处理，不应把M2F分数随意再套B3的Bstar/softmax。

本文借鉴的是筛选诊断，不建议立即把CSL训练模块叠进H75。

## 5. Mask2Former，CVPR 2022：从query缓存测被硬化步骤丢掉了什么

**论文**：[Masked-attention Mask Transformer for Universal Image Segmentation](https://openaccess.thecvf.com/content/CVPR2022/html/Cheng_Masked-Attention_Mask_Transformer_for_Universal_Image_Segmentation_CVPR_2022_paper.html)。

**官方代码**：[semantic_inference](https://github.com/facebookresearch/Mask2Former/blob/main/mask2former/maskformer_model.py)。

**实现事实**：语义输出是query类别softmax（保留类别部分）与mask sigmoid的加权求和：`sum_q p(class|query_q)*mask_q(x)`。它没有要求每个query仅保留top1类别。这与将query先硬分成一类再筛区域是不同信息处理方式。

**现有缓存的一项指标：query硬化前后、相同逐类风险下的有效冲突覆盖。** 在保存了原query logits/masks的source留出集上，对当前HPRD候选、query硬top1候选和完整软支持候选，比较在H75错误处被正确覆盖的独立区域数，以及在H75正确处引入错误的区域数。若只有dense cache，这个query级指标暂时不可算，应报告字段缺失，而不是重建虚假的query。

定义可直接复用的source量：`corrective = #接受且H75错且M2F对`，`harmful = #接受且H75对且M2F错`；两者均按真实类别、模型冲突对、独立图数报告。不能只报告全局precision。目标域对应只能报告接受且冲突的数量，不能命名为corrective。

**支持什么结果**：被硬top1步骤排除的支持，在source上确实有多类、跨图的纠错价值；采用原质量要求仍能获得额外有效区域。这样支持优先修复“信息筛选损失”，而不是先换更大教师。

**否决什么结果**：增加区域主要是no-object query的微弱尾概率、Background或H75/M2F已经一致的像素；纠错少而伤害多；源域就无法达到现门控质量。此时不扩大soft支持训练。

风险控制：semantic score不是天然已校准的概率；除去no-object后无条件归一化会放大无效query；不同视图不能假定相同query编号对应相同区域，应先逆变换并匹配mask。区域重叠要去重，不能把多个query覆盖的同一块区域当多份独立证据。

## 6. Rein，CVPR 2024：大模型是否值得试，由表征增量决定

**论文**：[Stronger, Fewer & Superior: Harnessing Vision Foundation Models for Domain Generalized Semantic Segmentation](https://openaccess.thecvf.com/content/CVPR2024/html/Wei_Stronger_Fewer__Superior_Harnessing_Vision_Foundation_Models_for_Domain_CVPR_2024_paper.html)。

**官方代码**：[w1oves/Rein](https://github.com/w1oves/Rein)。

**论文机制**：冻结强预训练骨干，仅训练少量适配参数，在其领域泛化分割基准中优于全参数微调。它支持区分“总参数量”与“可训练参数量”，不能据此承诺某个大模型会超过本项目H75。

**现有缓存能先做的一项指标：source上的可用异构纠错量。** 使用现有H75/M2F预测，按上一节的corrective/harmful及类别/尺度/场景分层，判断现有异构表征是否已经提供但尚未用好。若有冻结特征缓存，还可做按图像留出的轻量线性/原型可分性分析；没有缓存则不能零GPU完成。

**支持优先使用现有教师**：M2F在H75错误处有稳定、跨图、非Background的可靠纠错量，但大部分在HPRD门控/采样中丢失。先修监督使用，比再下载/训练大教师更具体。

**支持新冻结骨干探针的条件**：现有M2F纠错量确实不足，错误集中于它和H75共同混淆的类别/场景；资源允许新增冻结特征。此时“值得做探针”不等于已经证明DINOv3有效。须新提取该骨干特征，再训练相同容量小头并测source逐类错误互补性；旧M2F缓存不能替代DINOv3证据。

**否决立刻全量换大模型**：仅因为新目标无标签图更多，而没有新增真实标注、可靠监督或冻结探针优势。伪标签不是同数量的独立真标签；更多图像改善覆盖，不自动提高标签质量。全量大模型可最后考虑，且应与PEFT按同协议比较。

大模型只在source更高总mIoU、却纠错集中于已有强类时，也不支持目标教师升级；冻结探针失败只否决该预训练权重/分辨率/头部组合，不能宣布所有大模型失败。

## 7. 这些论文如何收敛成一次可执行的诊断

本节是项目建议，不是上述论文的现成方法或成绩承诺。

| 次序 | 只读输入 | 输出指标/文件 | 由结果选择的方向 |
|---|---|---|---|
| 1 | 数据清单、GT、所有cache metadata | 身份、标签映射、分辨率、raw/prob/query字段、是否加Bstar、是否有新目标cache | 缺字段就报告不可算，先避免混协议 |
| 2 | 历史候选概率/旧线上账本 | EnsV历史选择遗憾、家族留出稳定性 | 决定它能否仅作候选筛坏辅助 |
| 3 | source预测+GT、新目标预测 | 校准矩阵病态、先验估计bootstrap/子集稳定性 | 决定是否保留有限校准实验资格 |
| 4 | source带GT概率与区域cache | 按类风险—覆盖、corrective/harmful、每层门控损失 | 区分“教师没知识”与“有知识但筛掉/没有训到” |
| 5 | 新目标现有cache | 类面积/soft mass、冲突分布、独立区域/图、超出校准范围情况 | 判断source门在目标上是否仅留下Background；不能得出目标precision |

若第4步显示可靠纠错已存在，下一臂优先改变监督分配而非质量门：保留全域H75 anchor流，另取已接受区域的类别/图像均衡流。须记录每类独立区域和累计曝光，控制重复样本及总梯度预算。按入选像素取mean的区域KL，不可用面积覆盖推导梯度；把103/1000非空变为每步非空而不调权重，累计区域更新机会约增9.7倍，应明确这是剂量变化。

若第4步显示教师缺乏独立纠错，单纯增加接受次数没有突破依据；才进入新冻结大模型/PEFT表征探针。若新数据特征可分但现有图像/结构诊断没定位到尺度，不要凭AUC直接上FDA或global/local；应结合source有GT的分层错误与目标尺度/场景分布，决定哪条机制值得检验。

所有“支持/否决”均针对该候选及其当前假设。source的正证据不能证明新目标上涨；target的无标签行为指标不能判定改动正确。旧线上记录用于回测，不能被包装为新半决赛结果。
