## 1. 公共背景、模型和评估口径

### 1.1 任务及类别

比赛图像 **1024×1024**；训练有标签数据 **5597 张**，本地源域验证 **1399 张**（`H300=300`、`R1099=1099`），`test2=1300` 张（无公开 GT）；指标为 8 类等权 mIoU。

| 赛题 ID | 中文类别 | 代码英文名 | 训练 ID |
|---:|---|---|---:|
| 0 | 忽略 | Ignore | 255 |
| 1 | 背景 | Background | 0 |
| 2 | 建筑 | Building | 1 |
| 3 | 道路 | Road | 2 |
| 4 | 水体 | Water | 3 |
| 5 | **荒地** | Barren | 4 |
| 6 | **森林** | Vegetation | 5 |
| 7 | 农田 | Agricultural | 6 |

`Ignore` 不参与 mIoU；`Background` 参与。提交预测需按比赛格式将内部 `0–7` 映射回 `1–8`，不能以训练标签原样提交。

### 1.2 ACDD → H75 的主线，不要和后面支线混淆

- 主线学生：`SegFormer-B3`，核心已有 `Arm B`；固定教师包含 Arm B 与独立 `Mask2Former + Swin-L` donor。
- ACDD 训练不是推理 ensemble：它在训练中使用教师软概率指导**单个** B3 学生；旧主线在 `G` 内使用 `0.75 p_ArmB + 0.25 p_Donor` 软教师，在其他位置以 Arm B 为锚；`M/G/W` 具有不同职责。
- `M` 是 Arm B 高置信选择，`G` 是定向双教师分歧/冲突区域，`W=M∪G` 是目标 KL 的采样集合；`G` 还影响软教师混合和非 G Anchor，**改动 G 并非只改一个二值权重**。
- 既有审计中，M 的主要选取口径：最大置信度 ≥0.98；或预测类在 `{3,4,6}`（内部 ID）时置信度 ≥0.50。不同缓存、下采样网格和有效像素分母会导致 G 覆盖率略有差异，不应直接混用不同诊断中的百分比。
- 冠军 H75 从 `C = ACDD_V1_ANCHOR` 与同配方轨迹 `R05/R06/R07` 离线参数平均得到：

  ```text
  H75 = (9*C + R05 + R06 + R07) / 12
  ```

  只平均允许的同构可训练部分（Stage2、Stage3、Decode Head）；其他冻结权重、buffer、metadata 保持 C 版本。**H75 是权重处理，不是新增网络模块，也没有 H75 自身的再训练轮次。**
- 原 `H75` 对应线上 **71.329400%**。后续每条支线必须回答“是否真正作用于 H75 学生”和“是否在该模型/协议下重新验证”，不能把 M2F 教师本地指标移植为 H75 提分。

### 1.3 对照规则

- 源域 FULL1399 只用于开发和健康诊断；已经多次用于调参与方案选择，**不能当作独立域泛化证据**。
- 同一模型内的 `best` 与 `final` 分开统计；`best@1500` 不可写为 `final@2000`。
- 不同推理尺度（M2F 640/768/896/1024）、D4-TTA、类别 logits 校准、不同保存节点均可显著影响结果；只有评估协议相同才能直接比 mIoU。
- 三种“提升”分开：**教师离线预测更准**、**训练后学生本地 mIoU 更高**、**线上 mIoU 更高**。前者不是后者的充分条件。

## 2. H75_HPRD_V1：在 H75 上做稀疏区域教师蒸馏

### 2.1 问题及设计起点

`HPRD-Lite v1` 先前是在 **ACDD Champion C** 初始化的 B3 上尝试高精度区域蒸馏，使用 `Mask2Former` 的真实 Query mask、source GT 原型辅助筛选少量可信区域，训练 `Stage3 rank-4 LoRA`，最终 LoRA 可合并为普通 B3 的单 checkpoint。旧版 `HPRD-Lite v1` **线上 71.177602%**，较旧冠军 C（71.158317%）仅 **+0.019285 pp**，较 H75（71.329400%）**−0.151798 pp**。

因此 `H75_HPRD_V1` 的假设是：**保留较强的 H75 初值，仅在少数 donor 真正可靠的区域学习与 H75 不同的补充信息，减少对冠军预测的破坏**。这是在原 H75 上进行新训练，而不是旧 HPRD-Lite 的结果换名。

### 2.2 核心机制与训练协议

| 环节 | 历史实施记录 |
|---|---|
| 学生初始权重 | **原始 H75**，不重训/覆盖 H75 |
| 固定锚定教师 | H75；用于限制非区域偏移 |
| 区域教师 | 原 `Mask2Former + Swin-L`，`SIZE768` query mask/类别信息 |
| 可信区域 | donor 的有效非 no-object Query、类别/置信、source-GT prototype 一致性、几何/面积/稳定性筛选；**不是把整张 test2 当真值** |
| 更新参数 | B3 **Stage3 rank=4、alpha=4 LoRA**；其余主干及教师保持原有冻结安排；部署前 merge |
| 主要目标项 | source CE、accepted-region teacher KL、non-region H75 Anchor；保持主线保护思想 |
| 训练预算 | **1000 attempted steps，实际 1000/1000 完成** |
| 工程原则 | 不重跑 C/H75 旧方案；只追加一次本支线训练；最终单 B3 checkpoint |

**需要队友从本实验配置核对的细节**：本 `H75_HPRD_V1` 是否沿用旧 HPRD-Lite 的全部区域阈值、`0.50/0.50` 区域目标混合，或改成 H75 与区域教师 `0.75/0.25`，历史方案描述出现不同口径；因此这里**不把混合系数写成已核实运行值**。旧 HPRD-Lite 的超参数和它的实跑结果不得无条件移植到 H75_HPRD_V1。

### 2.5 结果分析（事实 / 推断分开）

**已知事实**：Region KL 非空只在 10.3% 的训练步出现；总体采样区域均值仅约 1.71%；荒地 IoU 45.70%，依旧是薄弱类；没有该方案的线上闭环。

**合理推断但未经新消融证明**：严苛的 Query/原型/置信度联合门使区域教师很精确却太稀疏，大多数迭代主要是在做 source CE 与 H75 Anchor；因此 LoRA 注入的新增信息可能较弱。高 precision 与低 coverage 不是矛盾，也不保证目标域 mIoU 收益。

**交接结论**：应保留原 H75，不把 `H75_HPRD_V1` 覆盖为冠军；该实验的贡献是**验证了一条可运行的单学生局部蒸馏工程链**，尚未证明线上可增益。

## 3. CSL-PCOS：置信度可分性与伪标签选择（尚未正式训练）

### 3.1 提出动机与方法

原 ACDD 的 `M` 主要通过最大置信度阈值选像素，`G` 则专门选双教师在重要类别上的分歧。普通最大置信度可能高估“自信但错误”的像素，故尝试引入 `CSL-PCOS` 的**置信度分布形态**而非只看最大值。

- 历史讨论中 `CSL` 被解释为 *Confidence Separable Learning*；PCOS 面向每个像素的概率向量，联合考察 top1 最大置信度 `c` 与其他类别概率的离散程度。
- 其残差分散特征可记为 `v = −(1/7)·Σ_{k≠argmax}(p_k − (1−c)/7)^2`（8 类场景），即不是简单再次比较 top1；历史提案和审计包含利用 SVD 分簇、标准化两个坐标，生成平滑可靠性权重的机制。
- 审计摘录中的参考权重形式：`w = exp(−(zc² + zr²)/α)`，`α=8`；标准化坐标在特定分支上有置 1 规则。**这是阅读/诊断方案的候选机制，不代表已在 ACDD 训练 loss 中生效。**
- 对原 ACDD：在 `p_ArmB` 上研究是否能改善 `M` 的可靠性，在 Mask2Former donor 与混合 `pT` 上研究是否能筛去 `G` 的坏教师；**不能把 G 整体替换成 PCOS mask**，因为还会改变混合教师、Anchor 区域、W 和归一化。

### 3.2 审计确认了什么

- 区分原始 `H75`、`ACDD step1000` 权重及其哈希，不直接修改原资产。
- 可用 **1300 张 target 双教师缓存** 和 **source1399 双教师概率缓存**（其中 source 有 GT，可衡量可靠性）。
- 要小心缓存概率中可能存在的 `donor 零和/无效像素`、Arm B FP16 精度损失；**不能对已是 probability 的缓存再次 softmax**。
- `M` 在历史某统计口径下覆盖约 **80.56%**，`G` 约 **3.75%**，`W` 约 **80.71%**。这些口径与 ALHVR 的 “G=2.9227%（source 有效像素）” 不同，不能拼接成一个统一分母。
- 缺少**同一步学生 logits**时，离线缓存不能计算真实的 student target KL 梯度/更新，也不能凭教师离线更准推断训练必然提升。

### 3.3 已有 CPU 离线诊断（不是训练成绩）

历史 2026-10-21 的诊断回执报告：

| 检查 | 结果 | 正确解释 |
|---|---:|---|
| M：CSL 官方代码式，逐类 coverage-matched macro precision 相对原 M | **−0.6314 pp** | 更差；Bootstrap 95% 区间在 0 下方 |
| M：按论文公式式，相同口径 | **−0.2633 pp** | 仍更差；不能说 CSL 优于原 M |
| 原 M 固定门槛的总体 precision | **93.0433%** | **固定阈值 operating point**，不能与上两行 coverage-matched 值直接相减 |
| G 中有益纠错被 PCOS 保留 | **55.86%** | **丢失约 44.14%** 原有益纠错 |
| G 中有害纠错保留 | **35.15%** | 确实过滤部分伤害，但伴随较大有益纠错流失 |
| G 原混合教师真实类平均概率变化 | **−0.6738 pp** | 未体现可靠提升 |
| G 的 NLL 变化 | **−0.02938** | NLL 与平均 GT probability 是不同统计；单独改善不足以放行 |

离线回执还列出其他分组 precision（如原 M 荒地约 47.68%、农田约 77.71%）及匹配 coverage 下的排序统计。**上表只保留已能跨历史记录一致复述的数字；完整算法两版定义、分母和 CSV 行须以原诊断产物确认。**

### 3.4 为什么暂不可行

1. **M 侧**：真正公平的“逐类匹配 coverage”比较下，两种 CSL 变体都未胜出；不能只挑选一个更高的总体 precision 数字来宣称成功。
2. **G 侧**：既能减少坏纠错，也会砍掉很多原本有益的 donor 纠错；更不能直接替换 G，因为 G 与 Anchor、`pT` 和 KL 有耦合。
3. **验证侧**：source1399 是长期复用的开发集合；target1300 没有公开真值，只能做 coverage/权重/invalid 诊断；无学生 logits 意味着无法测量真实训练收益。
4. **实施侧**：没有通过离线可靠性门槛，按预先 GO/NO-GO 流程**不做 GPU 学生训练，不生成新的正式学生 checkpoint，也没有线上提交**。

**结论**：这不是“代码训练失败”，而是**训练前证据否决了方案**。可借鉴的经验是：考察类别条件的 precision–coverage、纠错与损害净收益，而不是单一置信度指标。

## 4. ACDD_ALHVR：教师竞争三次离线迭代

### 4.1 方法关系、公共约束

在 CSL-PCOS 未通过后，研究 DTCT/ALHVR 一类“动态教师竞争”思想：**是否可以在双教师发生冲突时，不再固定使用 75/25，而选择/调节更可靠的教师，从而优化 target soft labels**。

- 参考 DTCT 思想：在两个扰动分支均低于动态置信阈值的像素，比较各自未扰动预测置信度，挑“相对更自信”者作为教师；原方法还涉及锐化、MSE/熵等。**本支线是对 ACDD 的诊断性迁移，不是复现原论文完整训练系统。**
- 教师 `Arm B` 与 `Mask2Former` 是**异构架构**，原生置信度尺度不一定可比；学生本来只是一份 SegFormer-B3 checkpoint。
- 所有 ALHVR 分支保留原冠军与已有缓存，只做 source-GT 可衡量的门控区域离线竞争诊断；没有进行新的正式学生训练、test2 推理或线上提交。
- 为避免误读，本章 A/B/C 分别指**局部软教师候选或门控策略**，**不是不同正式训练的学生 checkpoint**。涉及的类别 IoU 是特定 G/受影响子集的诊断口径，**不是全体 source1399 的模型 mIoU**；若需要严格复核，须查看对应 confusion CSV 的分母定义。

### 4.2 V1：`ACDD_ALHVR_DTCT_V1`——未经校准的最大置信度竞争

**目标**：保留 ACDD 原 Gate，只在 G 中比较教师，对照原 `0.75 Arm B+0.25 M2F` 混合教师（记 A）与 `max-confidence` 竞争教师（记 B）。

| 指标（G 内离线诊断） | A：原混合 | B：max-confidence 竞争 | B − A |
|---|---:|---:|---:|
| 硬正确率 | 31.5282% | **44.3979%** | **+12.8697 pp** |
| NLL（越低越好） | **1.220249** | 1.754919 | **+0.534670，恶化** |
| Brier（越低越好） | **0.789226** | 0.906129 | **+0.116903，恶化** |

- `G` 占 source1399 有效 GT 像素约 **2.9227%**（与第 3 节 M/G 全缓存覆盖口径不强行合并）。
- 历史诊断汇总：B 纠正 A 原错像素约 **6,869,604**，又破坏 A 原对像素约 **1,381,067**；因此硬正确率有明显提高，**但 soft probability 对真实类别的整体质量变差**。
- 受关注的 G 内/受影响类别评价值：荒地 **90.0650→80.6487%**，农田 **87.1307→74.6540%**；注意**这些不是完整 FULL1399 的荒地/农田 IoU**。G 内车辆无相应真值像素时不能报告“车辆提高”。
- 置信度失配实例：某子集 Arm B 置信度约 **79.91%**、实际正确率约 **24.46%**；M2F donor 置信度约 **67.87%**、正确率约 **65.18%**。这些是**诊断子集统计**，不是全数据统一模型准确率。

**判定：NO-GO / BLOCKED；没有启动学生训练。** 原因不是 B 完全不能纠错，而是对异构教师直接使用未校准的 max-confidence 排序会造成概率质量和关注类别风险。

### 4.3 V2：`ACDD_ALHVR_CALIBRATION_V2`——五折概率校准

**目标**：针对 V1 的异构教师置信度不可比，在 source1399 有真值的开发集上进行 **5-fold / out-of-fold 温度校准**，分别检查：

- **Hard competition**：校准后仍选一名硬教师；
- **Soft adaptation**：保留连续分布，低强度调整教师混合（历史候选名 `SOFT_ADAPT_025`），避免硬切换造成不连续伤害。

| 指标（G 内离线诊断） | A：原混合 | 校准后 hard competition | `SOFT_ADAPT_025` |
|---|---:|---:|---:|
| 硬正确率 | 31.5275% | **60.7805%** | **32.4878%** |
| NLL | 1.220249 | **0.946035** | **1.210216** |
| Brier | 0.789227 | **0.530548** | **0.779708** |
| ECE | 0.345360 | **0.075049** | **0.332407** |

另有校准硬竞争下真实类平均概率质量从 **0.377570 → 0.506787** 的改善记录。然而同一诊断也指出其**荒地**与**农田**相关类别评价约由 **90.07%→52.71%**、**87.13%→30.56%**，出现严重损害；软调权方案虽有很小概率质量改善，但 **32.4878%** 的硬正确率没有形成可接受净收益。

**判定：NO-GO，无学生训练。** 不能因为总体正确率 60.78%、ECE 下降就忽略赛题的弱类目标。OOF 减少拟合泄漏，但 **1399 张仍是长期复用的开发集，不等于目标域独立验证**。

### 4.4 V3：`ACDD_ALHVR_SAFE_GATE_V3`——预测类别保护

**目标**：对 V2 中受害严重的类别设置保护，使调整只出现在看似安全的位置；比较：

- `A`：原始混合教师；
- `B`：V2 中较温和的 `SOFT_ADAPT_025`；
- `C`：在 B 上增加预测类别保护/安全门。

| 指标（G 内） | A 原混合 | B 软调权 | C 类别保护 |
|---|---:|---:|---:|
| 硬正确率 | 31.52750% | 32.48785% | **31.52752%** |
| NLL | 1.220249348 | 1.210216221 | **1.220249255** |
| Brier | 0.789226546 | 0.779707947 | **0.789226487** |

保护约 **99.99739%** 的 G；历史回执称**仅 70 个诊断格点未保护、47 个格点仍发生调权**，所以 C 与 A 几乎完全相同；原来 B 的小收益也随之基本消失，细微差值不具稳健意义。历史诊断还提示农田有约 54 个像素的概率指标变差；不同统计网格/粒度下的 `70 / 47 / 54` **不要自行相减或解释成同一个像素全集**。

**判定：NO-GO，无学生训练/推理/线上分数。** V3 的事实不是“保护机制已经解决 V2 的问题”，而是“保护足够强时几乎不再执行有意义的教师修改”。

### 4.5 三代迭代究竟证明了什么

| 观察 | 可支持的结论 | **不能**支持的结论 |
|---|---|---|
| V1 硬预测更准，但 NLL/Brier 恶化 | 原生置信度竞争不稳健 | 新学生一定比 ACDD 好 |
| V2 校准后整体指标改善、稀有类局部大幅下滑 | 教师排序/校准与类别保持存在冲突 | 温度校准足以解决蒸馏质量 |
| V3 强安全门几乎全部拦截 | 保护与有效覆盖之间冲突突出 | V3 已形成可用提分方案 |

共同提醒：**老师准 ≠ 学生会涨分**；进入 GPU 训练前至少应同时检查：G 内 true-positive 纠错、false-positive 损害、soft GT likelihood、关注类别与有效覆盖率。该方向截至此时**没有任何独立的训练后 source1399 mIoU 或线上分数**。

## 5. Mask2Former + Swin-L：E00–E02 错误归因与 B1 区域反馈

### 5.1 与 H75 的关系、原始教师参照

这是**优化 M2F 架构的独立支线**，不是 H75 的 Student 直接继续训练。冠军 H75/ACDD 使用的 donor 基本上仍是已有 `Exp00R` Mask2Former + Swin-L checkpoint，使用 **SIZE768 单尺度**的 Query/概率信息；**E02/B1 没有被替换进冠军 H75 的正式训练链**。

已知历史 M2F 基线：`Exp00R`、模型 checkpoint 为 iter30000，source1399 相关单尺度成绩：

| 单尺度输入 | 本地 source1399 mIoU |
|---|---:|
| 640 | 79.182506% |
| **768** | **79.381034%** |
| 896 | 79.176331% |
| 1024 | 78.962971% |

较早 `Exp01` D4-TTA8 约 **78.627841%**，比 SIZE768 单尺度差约 0.753193 pp（若与 Exp00R 的 79.182506 基线比较则差约 0.554665 pp）。因参照不同，这两个下降数字不是一回事。**SIZE768 更优是对该 checkpoint/协议的经验结果，不能推出所有 M2F 都应使用 768。**

### 5.2 E00：错误归因第一阶段——确认“错在哪里”，不是先改结构

**执行性质**：复核已有预测资产、SHA、缓存和混淆矩阵，不加载新模型、不训练、不增加新推理；最初只具备**相关性诊断**，没有证明“Pixel Decoder/Query Decoder 一定是瓶颈”。

确认的弱类和现象（历史诊断口径）：

| 类别 | SIZE768 本地 IoU（E00 诊断） |
|---|---:|
| Barren / 荒地 | **约 56.10%** |
| Background / 背景 | **约 72.20%** |
| Agricultural / 农田 | **约 77.68%** |
| Vehicle / 车辆 | 约 81.83% |

混淆矩阵有明显的**背景—森林**双向混淆：`Vegetation→Background` 约 **1832 万**像素，`Background→Vegetation` 约 **1685 万**像素；另有“Background 漏分占全部错误约 **44.12%**”“Barren→Background 占真实 Barren 约 **18.35%**”的归因记录。**这些来自 E00 旧诊断汇总，分母/忽略像素与采样尺度需要由 E00 原 CSV 重验，不可把像素总数当成独立图像样本数。**

关键判断：M2F 原生已具多尺度 Deformable Attention，不能看到分割错就武断认为“缺多尺度融合”；需要分清 `Pixel Decoder` 特征问题、`Transformer Decoder` Query/掩码问题、边界/内部问题。

### 5.3 E01：跨尺度＋Query 的进一步定位

**已完成诊断**：同一 1399 张 source 验证图，在 **640/768/896/1024** 四尺度生成总计 **5596 份预测**；另取 **64 张样本**进行 **256 次 Query 诊断**（64×4），并有对应可视化。**未进行结构训练**。

主要发现：

- **高尺度存在“边界更好、内部更差”的权衡**，所以简单加大分辨率未必提高全图 IoU。
- 四尺度中全部预测都错误的有效像素占比约 **7.6573%**。若对每一个像素事后用 GT 从四尺度中挑对的一项，得到**分析性 oracle 像素准确率 92.3427%**；这**不是**可部署的推理准确率，也不是 mIoU 的直接上界。
- 对 SIZE768，背景、荒地、农田的相当多错误在边界区域外；因此“只优化边界”不足以解决主要问题。
- 对荒地，诊断更偏向 **有效激活 Query 的区域覆盖不足**；必须排除那些几何 mask 看似吻合 GT、但类别头判为 no-object 的 Query，不能将其当作有效 Query 覆盖。

**阶段结论**：优先做能向 Query 补充其自身区域视觉证据的**最小 Transformer Decoder 修改**；Pixel Decoder/更复杂多尺度路径作为独立假设，不在同轮一起堆叠。这个结论仍是从相关性诊断作出的研究假设，不等同于已证明 Query 反馈能涨分。

### 5.4 E02/B1 的具体结构改动

B1 = **Region Evidence Feedback（Query 软区域反馈）**。

在 M2F 的 Transformer Decoder 中，每层 Decoder 已产生一个 Query 对应的上一阶段 soft mask。把这个 mask 当作软权重，对 Pixel Decoder 的空间特征做**区域加权池化**，所得区域向量与 Query 拼接后经过共享 MLP，作为残差更新 Query；随后进入既有 `_forward_head`：

```text
soft_weight_q(x,y) = sigmoid(stopgrad(mask_logit_q(x,y))) * valid_fraction(x,y)
region_q = sum_xy[soft_weight_q * pixel_feature(x,y)]
           / (sum_xy soft_weight_q + 1e-6)
query_new = query + alpha[layer] * MLP( concat(query, region_q) )
```

- 在 **9 个 Transformer Decoder 层**对应位置执行，在原层之后、`_forward_head` 之前插入。
- MLP **512→256→256**，各层共享；`alpha` 为每层独立的 9 个可学习标量，**全零初始化**，保证初始预测与原 M2F 一致。
- `stopgrad` 阻断此支路对区域权重 mask 的反向路径（该支路不能单凭此操作证明所有其他路径都不更新）；原 loss、匹配、Query 个数和 Pixel Decoder 保持不变。
- **C0**：同初始权重、同预算继续训练原模型，无新增模块。**C1**：用 `MLP(concat(query,query))`，参数量与 B1 尽可能匹配，但**没有真实区域特征**。**B1**：真正 `concat(query,region)`。三者分别排除“多训练了 2000 步”和“只是多了 MLP/参数”的伪增益。

### 5.5 E02-P0 与正式 P2 对照

**P0** 只完成了：初始 `alpha=0` 与旧模型输出等价、反馈分支有梯度、有限资源 profile 和工程接口通过。**P0 不能证明效果，没有线上包/分数。**

### 5.6 P2C ON/OFF 消融、残差与停止依据

- 首种子 B1 训练完成时 `max |alpha| ≈ 2.7352423×10^-4`；平均 `||feedback residual|| / ||query|| ≈ 3.6233353×10^-5`（**约 0.003623%**），最大约 `6.0550690×10^-5`。说明设计的反馈分支确实存在但对 Query 的实际改变量极小。
- P2C 后续执行了**固定权重 ON/OFF 诊断**：固定 64 张诊断样本、在 1500 和 2000 节点比较是否启用反馈，非重新训练、非 FULL1399。记录到 mIoU 的 ON−OFF 分别约 **+0.000338 / +0.000025 pp**；相应仅约 **772 / 944** 个像素预测变化。不同步骤/统计粒度的这些数字必须依原 P2C 报告确认。
- 这支持“B1 被训练出来但实质影响很弱”的解释，且不能据此归因“完全无梯度”：梯度连接在 P0 已通过。
- 原计划的多 seed P1 验收要求**三种子平均至少 +0.20 pp** 等准入条件；当前只完成首种子，且单种子增益仅几百分之一 pp，不满足证明稳定收益的证据强度。
- 历史后续状态：**P2A 首种子及 P2C ON/OFF 已完成**；并未见 `P2B/A1`、另外两个正式种子或 B1 进入 H75 的完成证据。不要把“计划运行”写成“已完整跑完 P1 三种子”。

### 5.7 分析与结果归属

**事实**：B1 相对两个合法对照均有极小 best 优势，final 对 C1 基本持平；区域反馈残差非常小；未形成稳定荒地/边界优势；本分支没有线上分数。

**推断**：`alpha` 全零初始化与很小的后期学习幅度、反馈向量有效性、no-object/Query 区域分配可能共同导致反馈信号弱，但**具体责任尚未通过独立消融识别**。不能只凭 0.003623% 就宣称是 `alpha` 初始化“造成”失败，也不能在本交接中悄悄提议已经成功的架构升级。

**与原冠军的关系**：这是一条有严格 C0/C1 对照的结构探索，但**没有证据可以把 B1 教师替换进 H75、或预测 H75 线上必定提升**。

## 6. 横向综合分析：四条线反复遇到的同类瓶颈

### 6.1 可区分的四种瓶颈

| 分支 | 主要观察到的限制 | 现有证据强度 | 不能推出的说法 |
|---|---|---|---|
| H75_HPRD | 高精度区域监督覆盖很稀疏，103/1000 步有区域 | 训练日志＋本地评估 | 增加任意区域就一定涨分 |
| CSL-PCOS | 精度-覆盖权衡、G 有益纠错被过滤 | CPU 离线诊断 | 置信度分离一定优于固定门限 |
| ALHVR V1–V3 | 硬正确率、概率质量、弱类保护互相冲突 | G 区 teacher-only 诊断 | 教师 NLL/ECE 变好就等于学生 mIoU 变好 |
| M2F E00–E02 | 荒地 Query 覆盖及内部错误，B1 反馈作用量太小 | 全量诊断＋单种子受控训练 | M2F 当前已证明必须重写 Decoder |

### 6.2 贯穿主线的关键区别

**稀疏但可信 ≠ 能产生足量学习信号**（HPRD）；**更高 hard accuracy ≠ 更好的 soft teacher**（ALHVR）；**有反馈梯度 ≠ 反馈真的显著改变预测**（B1）；**本地 source1399 变好 ≠ 线上领域泛化更好**（历史多轮经验）。

目前没有充分证据支持将这几种失败方向直接堆叠成“更复杂的新方案”；也没有证据表明继续精调同一类教师门控就会自动跨过 H75 冠军。

### 6.3 与已有 H75 机制审计的关系

2026-10-24 的 `H75_EXISTING_MECHANISMS_AUDIT.md` 提醒：冠军 ACDD 代码中已经存在 RareClassCropper 调用、目标域整图 D4/strong_photo、donor gate、非 Gate anchor 以及部分层冻结；`H75` 自身是权重平均而非新增训练。**代码“有一个模块”不能证明运行时具有预期行为**：归档配置若关闭 `domain_aug`，以及 `1024×1024` 原图配 `1024×1024` crop，所谓“裁剪”可退化为整图。此点是后续新实验设计时需要首先避免的重复发明/错误归因，**不属于本文件四条支线已经验证的提分成果**。
