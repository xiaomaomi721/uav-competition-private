# AIC2026 无人机语义分割半决赛：H75 短板诊断与下一步交接

**更新时间：2026-10-25**\
**当前正式基线：H75 + 原始 Bstar**\

## 1. 决策摘要

Zero Bias 在 source1399 上明显优于原始 Bstar，并且 H300、R1099
两个子集方向一致，配对 bootstrap 95% 区间均高于零。但 source1399
是长期复用的开发数据，不是独立盲测；历史记录表明 Bstar
的部分参数来自早期平台数据校准，而 test1
又是半决赛数据的组成部分。因此，source1399
上的收益不能直接外推到半决赛。

当前决定： 1. 保留 H75 + 原始 Bstar 为正式基线和回退方案。 2. Zero Bias
仅作为研究候选，不宣称线上收益。 3. 暂停继续扫描 bias；不启动
GLOBAL_LOCAL、HPRD_V2 或其他新训练。 4. 优先补齐 Bstar
历史来源证据，并核实官方规则。 5. 所有离线分析优先在服务器 `uavmain` CPU
执行，不使用用户本地电脑；GPU 任务需先确认空闲。

Barren index 4 正确。

## 4. H300/R1099 paired bootstrap

### 分组总体 mIoU

### Bootstrap 设置与结果

-   重采样次数：5000；随机种子：`20261025`
-   以图像为单位有放回配对重采样；A/B 使用相同索引。
-   每次重新汇总混淆矩阵后计算 mIoU，不是平均每图 mIoU。

  子集       mIoU 差值        95% Bootstrap CI   重采样差值 ≤ 0
  ------- ------------ ----------------------- ----------------
  H300      +3.2437 pp   \[2.3987, 4.0375\] pp         0 / 5000
  R1099     +3.1001 pp   \[2.2543, 3.9009\] pp         0 / 5000
  ALL       +2.9106 pp   \[2.3266, 3.4653\] pp         0 / 5000

### 图像间收益分布

  子集      正增益图像   零增益   负增益
  ------- ------------ -------- --------
  H300             219        0       81
  R1099            728       18      353
  ALL              947       18      434

全体仍有 434/1399 张图像为负增益。报告称 ALL 的 Top 10% 图像贡献约
57.68% 的正增益，R1099 的增益集中度高于 H300。收益并非每张图都一致。

### 重点类别变化机制

Zero Bias 相对原始 Bstar： - Background：TP 增加约 37.89M、FN 减少约
37.89M，同时 FP 增加约 24.48M。 - Barren：FP 减少约 23.92M，但 TP
减少、FN 增加约 6.22M。 - Agricultural：FP 减少约 17.38M，但 TP 减少、FN
增加约 8.28M。

这说明 Zero Bias 重新分配了类别预测份额：Background
召回改善，Barren/Agricultural 假阳性减少，但后二者漏预测增加。净结果在
source1399 上提高 mIoU。

### 统计解释边界

可以说： - H300 与 R1099 上的 source 增益方向一致； - paired bootstrap
支持该开发集上的增益具有统计稳定性； - 主要收益涉及
Background、Barren、Agricultural 的预测权衡。

不能说： - Zero Bias 在半决赛目标域一定更好； - 置信区间覆盖
test1/test2/test3 的分布变化； - source1399 增益可以直接换算为线上 mIoU
增益。

H300/R1099 均为反复用于模型分析的开发数据，不是独立盲测集。

## 5. 官方规则状态

现有审计记录确认： - 半决赛每日最多提交 2
次；排行榜成绩保留，取半决赛阶段最高分。 -
最终提交结果应仅包含一个模型，不允许多模型集成。 - test1
为初赛测试集，test2 为复赛测试集，test3 与 test1、test2
合并用于半决赛。 - 提交要求涉及单通道
PNG、1024×1024、ZIP；像素标签值应按官方提交文档原文核验。 -
赛后需要复现；无法使用官方数据复现可能导致成绩取消。

**仍待官方确认：** - 固定推理阶段 class logit bias 是否允许； -
其他后处理是否允许； - test1/test2/test3
的无标签图像能否用于自适应或额外处理； - 线上反馈用于校准的具体边界。

获得官方原文或书面答复前，不将固定 bias 视为已获许可，不提交 Zero Bias
候选包。

## 8. 最终判断

**H75 的一个明确短板是：当前外部 Bstar 与 source1399
的类别预测分布存在明显失配。Zero Bias 在 source1399 上的总体增益，经
H300/R1099 分组与 paired bootstrap 后仍然成立。**

但 Bstar 有早期平台校准来源，且 test1
属于半决赛数据组成部分。当前最合理的策略不是立即替换
Bstar，而是完成来源闭环与官方规则核验，再决定是否存在可接受、可复现、合规的候选对照。

**当前正式基线保持不变：H75 + 原始 Bstar。**
