# AIC2026 UAV｜H76 全量 test3 训练主线：基座裁决、算法与执行设计

> **研究/执行方案 V1.0｜2026-10-26**。当前只完成文献核查、用户文件研读和实施设计，**没有登录 teacher-4090，没有解密大包、训练 GPU 或生成任何新权重**。本文件供负责人、Claude Code 与队友实施和批判性复核。严格遵守“不用排行榜试错，不人工标注目标域”。

## 0. 核心决定

**推荐从原始 H75.pt（2026-10-05，`b5eea279…98a28a`）初始化 H76 全量训练，不直接沿着队友 T3-00 checkpoint 继续训练。**

**理由是证据而非排斥队友方案：**

- T3-00 已执行 test3 适配，997 次有效更新，但仅有 **1000 个不同目标 ID 被抽中**，即 **1000/3594=27.82%** 的循环级覆盖；3594 教师缓存≠3594 张目标图像都实际参与训练。
- T3-00 完整复用了旧 ACDD 的 ArmB/Mask2Former 混合教师和 G/M 区门控、KL/Anchor，其 source1399+Bstar mIoU=**77.5872%**；严格可比的原 H75+Bstar=**77.5311488%**，仅 **+0.0561 个百分点**。这个数远不足以证实在 test3-new 具备明显优势，尤其之前的 bias-matched 教师审计对旧混合教师的净纠错和软监督质量不利。
- H75+Bstar→Zero 在 source1399 上 **77.5311→80.4418%（+2.9106pp）**。但 T3-00 的 **Zero Bias 同协议成绩未知**；不能把 T3-00+Bstar 的 77.5872 和 H75+Zero 的 80.4418 混为一谈，更不能说 T3-00 一定逊于 H75 在 test3。
- 从 H75 原件开新分支，能够明确归因“新的训练监督相对 H75”的收益、避免将 T3-00 旧双教师偏移继续放大；T3-00 保留为**独立已存在的训练参考点**，在取得同 bias/proxy 验证证据前不覆盖/继承。

**结论的精确边界：**“H75 是当前**可证据支持的优先研发起点**”，不是“不经试验就能证明全局最优”。如果后续有严格同协议、独立有标签代理域证据证实 T3-00 初始化更有优势，应允许修正裁决，但不做随意网格扫分。

### 今天需要的不是旧方案加长版

不推荐：`T3-00 checkpoint → 把 1000 step 改成 4000 step → 仍用 ArmB+donor 旧 gate`。这只能修复目标覆盖不足，**没有修复教师软标签质量不足**。

主推 **H76-CaSC：Class-Reliable Context & Scale Consistency Adaptation**（项目暂定名：*类别可信的上下文—尺度一致性目标域适应*）。

目标是用 **全部 3594 张官方无标签 test3** 做**真实参数更新**，解决 H75 的目标域未覆盖、类别确认偏差、Barren/Agricultural/Background 混淆、尺度与上下文不一致，而非重做 ACDD 的双教师混合。

## 2. 为什么这条新路线可能比延长 T3-00 更有信息增量

| 维度 | T3-00 既有机制 | H76-CaSC 计划新增机制 | 提分假设与失败风险 |
|---|---|---|---|
| 教师与目标 | Arm B+M2F donor 固定混合，bias 混淆存在历史审计 | **原始 H75 本身作初始冻结教师**，从 raw logits 创建**类别可信伪标签**，不使用混合 donor | 更贴近待改进学生；风险：学生复制自身错误 |
| 伪标签可靠性 | gate 的 M/G、混合概率与 Anchor | **同类门槛 + 增强一致性 + 边界置信**的交集 mask，按类别估计可信覆盖率 | 避免 Barren 过预测；风险：弱类过度筛掉 |
| 目标域学习信号 | 主要是 soft KL 到教师概率 | **完整视图→遮挡学生上下文重建一致性**，使学生学习目标域结构，而非只模仿分类比例 | 可能提升纹理相近区域的上下文判别；风险：遮挡强度不当损害细节 |
| 尺度敏感性 | 单一正常尺寸 student + teacher SIZE640 | **局部—全局同图几何对齐、跨尺度预测一致性**，保留 global context | 针对 UAV 高度/尺度；风险：裁剪丢上下文/小车变形 |
| 目标覆盖 | 1000/3594 ID 抽中 | **先一整轮无放回覆盖3594个 ID，再可选加大新增1794曝光** | 修复未见目标图缺口；风险：增加训练造成遗忘 |
| 稳定性 | source CE 系数0.1，target KL ramp | **source GT 监督主导 + 输出/特征锚定 + 可靠性权重**；首轮不依赖在线 EMA 自举 | 避免确认偏差和灾难性遗忘；风险：约束过强导致不适应 |

## 3. H76-CaSC 算法：可实施的训练设计

### 3.1 模型与冻结范围

- **唯一训练学生**：SegFormer-B3；从原始 H75 SHA `b5eea279…98a28a` strict-load 开新分支，不改既有 H75 和 T3-00 文件。
- **冻结教师**：同一 H75 权重，`eval()`+`no_grad()`；教师只产生训练目标，不参加最终提交推理融合。
- **学生可训练范围首版**：Stage2、Stage3、decode_head；Stage0/1 冻结。符合已跑通的训练范围，训练参数组显式创建新 AdamW，不假装 H75 自带 optimizer/scaler；不加载历史 step1000 作为新训练步数。
- **不加入**：原 ACDD 的 ArmB+donor 混合门控、M/G 软融合、旧 donor anchor、未证实的线上偏置选择。

### 3.2 目标域数据与有效覆盖的硬定义

官方新包本身完整包含 `test3_1...test3_3594` = **500旧test1 + 1300旧test2 + 1794新图**，共 **3594唯一 RGB**。不得追加为 5394。

- 使用 **manifest 驱动的无放回 sampler**，固定 seed 与 ID 序列；一轮完整目标遍历严格抽取 3594 个不同 ID。
- **一次目标有效参与**的含义：该 ID 对应的目标数据进入 forward、生成非空可信训练损失，并且发生一次**成功的 optimizer 更新**；AMP skip 或可信区域空白不算完成，须记录并在队列尾重试（有限重试，不强迫低可信图生成伪真值）。
- 为避免低可信图像永久不达标，可用独立的**不依赖伪标签的跨视图特征/预测一致性损失**作为安全备选；仍需实际非零梯度并记录 `effective_target_id`。每个 ID 至少一次成功更新，优先保证此条件，再考虑目标复采样。
- 第一轮正常遍历的旧/新比例由 1800:1794 自然确定，接近 50:50；**不是 50:50 的理论最优证明**。第二阶段如需提高新增1794曝光，仅作一个事先写定的额外遍历，不做比例网格搜索。
- 有标签 source 同步按 1 source : 1 target 图像参与每次更新，可梯度累积维持显存；source 从 **5597 train** 读取；**1399 val 不用于任何训练损失、教师标定拟合或无标签适配**。

### 3.3 冻结教师与可靠掩码

1. 用 H75 对 3594 目标图像生成**训练专用** logits/probabilities。这里的教师前向计算是无标签训练的必要预处理，**不是提交测试集预测 ZIP，更不会提交平台**。可优先复用经过身份核验的已有 raw logits，否则只补缺失的缓存，不重复计算无关 teacher。
2. **不要先加 Bstar(+3.6 Barren) 做硬伪标签**。保留 raw logits，先在 source train 内部独立的可靠性校准样本上估计各类预测质量（不得用 source1399 拟合阈值），明确 raw/Zero 与固定 bias 的预测差异。
3. 首版可靠掩码：`R(x)= valid_confidence(x) ∧ geom_agreement(x) ∧ stable_region(x)`，其中置信度阈值按类别校准，几何一致性使用 D4 或少量等变视图的一致性，稳定区域对高度不确定的边界做低权处理，不进行一刀切硬侵蚀伤害小 Vehicle。
4. 依据 source train 内部持出样本统计各类伪标签 precision–coverage 关系，**锁定一组**阈值；对 Barren/Agricultural/Background 专门记录有效像素率、跨类混淆，不能仅追求目标域置信度升高。
5. 对极低覆盖图像，不强造伪标签；使用只依赖图像增强一致性的弱损失/跳过高风险硬标签。每类目标损失做有效像素归一化和上限约束，避免某个占地面积大的伪类支配梯度。

### 3.4 三个损失模块（训练首版预先冻结，不进行任意扫描）

设学生 `S_θ`、冻结教师 `T_H75`；source 图像及标签 `(x_s,y_s)`，target `x_t`。

**A. 源域真实标签主监督：**

`L_source = CE(S_θ(A_s(x_s)), A_s(y_s))`，包括标准几何同步变换与温和光度扰动；保留 source GT 作为防遗忘的主要信号。

**B. 可信目标伪标签监督：**

`L_target = Σ_x w(x) CE(S_θ(A_t(x_t))_x, pseudo_H75(x)) / Σ_x w(x)`，对图像与预测严格做相同几何映射；低可靠边界/歧义像素降权，`w` 由冻结规则决定，不按目标域伪标签量反复在线调参。

**C. 遮挡上下文 + 尺度等变一致性：**

- `L_context`：教师在完整目标视图产生可靠伪标签，学生在局部遮挡/patch masking 视图预测原来的类别，训练学生利用大区域上下文，而不是仅复制高置信普通伪标签。遮挡不覆盖整张图，不能对不可靠区域伪装为强监督。
- `L_scale`：同图全局视图与随机尺度视图/局部高分辨率视图的空间对齐预测一致性；必须在有效重叠区域、可比采样栅格上计算，明确 `align_corners`、bilinear 用于 logits、nearest 用于硬标签；不能把“640裁剪插值”误写成新的高分辨率真实信息。

**D. 稳定锚定（非旧 donor anchor）：**

`L_anchor` 采用冻结 H75 在 source 或经识别的可信目标区域的输出/特征一致性，限制灾难性遗忘。锚定权重要小，防止 H76 被强行拉回 H75。

总目标（起始**候选超参数，不是验证结果**）：

```
L = 1.0*L_source + ramp(k)*(0.2*L_target + 0.1*L_context + 0.1*L_scale)
    + 0.03*L_anchor
```

`ramp(k) = min(1, k/800)`，`k` 是**有效更新步**。建议学生 Stage2/3 初始 LR `3e-6`、head `1e-6`、AdamW WD=0.01、warmup/poly，micro-batch=1，梯度累积按现场显存核验调整。所有这些值是**第一版可以用于预注册的小心起点**，必须由 Claude 对照真实 optimizer/梯度尺度做一轮**不超过几十步的工程烟雾测试**；若发现某损失梯度几乎为零或爆炸，先修正实现错误，不以小 val 分数做大量网格搜索。

**工程代价提醒**：完整 D4 教师缓存、双尺度学生前向、遮挡一致性会增加显存、I/O 和计算；4张 4090 不等于必须4卡并行。先锁一张空闲 GPU，若确实需要扩展再通过 DDP 保证有效 batch/随机序列/同步可重复。不能假设旧 trainer 复制就能支持这四项机制。

## 4. 必须认真处理的“训练后评价”问题

### 4.1 为何 77.5872 不是强提分证据

`77.5872 - 77.5311488 = +0.05605pp`，接近微小源域波动；而 T3-00 是源域 Bstar 协议，不能代表新 1794 张无标签目标域。它完全可能在 test3 更好，也可能更差，当前无证据决断。

### 4.2 预先构造**独立有标签代理目标域**（不使用 test3 GT）

目的：让不同训练机制具有可证伪的离线效果，不拿用户提交次数试错。

- 从**5597 张 source train** 出发，依据允许的已知拍摄条件/场景/图像嵌入聚类建立 **scene-disjoint/source-train 内部 proxy**：例如持出约 800–1200 张难域/新场景图像，其他 source train 用来训练；像素标签仅在**评估时**读取；此代理集的 RGB 可作为**无标签 target**供适应方法训练，但真实 GT 绝不进入训练、阈值拟合或模型选择损失。
- 同一独立代理 split 上跑 source-only matched-control 与 H76-CaSC，记录 **IoU/精确率/召回率/类面积偏置/边界质量**，由固定 bootstrap/场景级分组估计差值不确定性。尽可能保留多个场景组，而不按单纯随机像素构建代理域。
- T3-00 权重已接触正式 test3 的一部分，但 source 代理数据来源不同；如要用 T3-00 做 proxy 的模型初始化对照，必须在两个模型的同一代理协议上比较，且清楚披露初始权重训练历史不同。
- **禁止：** 用 source1399 的真值拟合可靠性门槛或训练后再把其分数当“独立验证”；禁止“使用全3594目标图像产生的伪标签”当做 ground truth 测准确率。

### 4.3 固定评估口径和准入门槛

正式评估至少包括：

| 维度 | 固定做法 | 不通过的含义 |
|---|---|---|
| Source1399 稳定性 | H75 与 H76 分别使用**同 checkpoint之外相同评估协议**，**同时报告 Bstar 与 Zero**；其中 H75+Zero 基线 **80.4418%**，不能只和 H75+Bstar 77.5311% 比 | 单靠 Bstar 的 +0.1pp 不能称明显提分 |
| 独立 proxy 域 | 严格同一未参与 source GT 训练的 heldout split；首选目标是 **≥+0.5pp** 且场景级 bootstrap CI 下界为正（研发门槛，而非线上保证） | 低于目标则不是可宣传的强方案 |
| 类别安全 | Barren/Agricultural/Background/Vehicle 单独监控 IoU、precision/recall、预测面积，不接受整体涨0.1pp但关键类严重坍塌 | 停止扩量，检查伪标签确认偏差 |
| 目标3594 覆盖 | 以`successful_optimizer_step + target_id`逐ID计账；3594 ID 实际至少一次有效更新，必要时重试低可信项；统计新1794与旧1800分开 | 不能称“完整test3训练已完成” |
| 训练有效性 | 无 NaN/Inf、AMP skip 实报、最大显存、loss 项梯度比例、checkpoint SHA、原始 H75 SHA 不变 | 工程未达标，禁止将 checkpoint 交付为候选 |

> **诚实边界：** 即便 proxy 域改善 +0.5pp、source1399 守住 80.44%，也不能数学证明 test3 同等提升；我们承诺的是**不浪费提交次数**和提高离线证据质量，不承诺零风险或保底线上提升。

### P2｜配对模型训练：至少有一个严格的 source-only control

**C0（必要对照）**：原 H75 起点、同 source 样本序列和有效 optimizer 更新总数，仅 source supervised CE/保留匹配的常规增强。它衡量“多训练”带来的收益。

**T1（主实验）**：同一个原 H75 起点、同 source 更新样本序列和优化器预算，加上 test3 全量 3594 的可靠伪标签 + 上下文/尺度一致性。只有两组严格一致才能把新特性归因于目标域适应。必要时增加 **T1-ablation**：移除上下文/尺度分支，但这是后续条件性消融，不是第一天并行大规模扫参。

运行建议：GPU1 上 T1；GPU2（若空闲且授权）跑 C0；GPU3 留给共享/后备任务。**本文件没有获得实时 GPU 状态，不能把建议写成 GPU 已分配。** C0 的目标是严格对照而非必须跑满所有算法增强，避免资源无限扩展。

### P3｜完成真正的 full-3594 训练，再作离线 gate

- 第一主阶段 **至少3594 个有效 target ID 被完整覆盖一遍**，不是“跑 1000 steps 就称用过 test3”；记录 unique IDs、每个 ID 对应的有效更新、有效监督像素覆盖率、分 old/new 的反馈。
- 如果在第一完整遍历中训练不稳定，优先修复机制/停止冒险，**不强求损坏的实验继续跑**。第一轮可选保留 1 个中途诊断 checkpoint 以排查灾难性遗忘，但不是只训一部分就对外宣布成功。
- 若通过完整首轮后 proxy 证据及主要类别安全门槛，再作**一轮事先固定的新增 1794 张二次曝光**，不做无限 continuation；以离线 proxy 结果选 checkpoint，并保留 source1399 最终守护指标。
