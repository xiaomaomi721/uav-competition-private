### 4.2 训练时target loss的精确定义

学生对目标图（或一致几何变换后的视图）输出raw logits `z_S`。与教师在相同空间比较：

```
q = softmax(z_T_D4_raw_aligned + b)
p = softmax(z_S_raw + b)
kl_per_pixel = sum_c q_c * (log(q_c + eps) - log(p_c + eps))
```

建议用`log_softmax`及stable KL实现，数值更稳定。计算教师概率时禁止`detach`遗漏；teacher q必须stop-gradient，student p可微。`b`仅作用于概率计算；**不把Bstar写死进学生原始权重和分类头**。模型正式推理仍加一次b。

- **C0（匹配对照）：** `L_target=sum(kl_per_pixel)/num_valid_pixels`（所有合法目标像素等权）。
- **C1（新机制）：** 教师相同、损失相同，唯一变化为每像素可靠性权重：`a = aligned_D4_agreement ∈ [0,1]`、`c = 1-H_norm ∈ [0,1]`；预注册 `w = a^2 * c`。若`argmax(z_T_raw)!=argmax(z_T_raw+b)`，为了保留可能的纠错而非彻底排除，`w *= 0.5`。令`L_target=sum(w*kl_per_pixel)/(sum(w)+eps)`。**C1不可额外改变教师、采样、训练轮数、冻结层、参数平均或最终Bstar**。
- 定义weight数据诊断：`weighted_ESS=(sum w)^2/(sum w^2 + eps)`、`ESS_fraction=ESS/num_valid_pixels`、`mean(w)`、八类按预测类别的有效权重、raw/cal争议区域的有效权重。若ESS极低（例如小于全部合法像素10%），标为`SUPERVISION_COLLAPSE`并停止将C1视为有效候选；不在同一实验里动态调阈值重跑骗过审查。
- C0/C1都必须记录`loss_src`、`loss_anchor`、`loss_target`、`loss_total`、梯度范数、optimizer step、AMP skip、实际见过的源/目标样本数、八类预测占比和最初H75到学生的参数变化，避免只凭训练loss说“更强”。

**说明：** C0与C1比较只能直接估计“相同D4校准教师下可靠性加权的作用”；它不能单独证明“教师升级”的因果效应。如果资源允许，额外做一次小规模`Cweak` matched training（单弱视图教师、其余与C0完全相同、同一Bstar空间），才可以隔离TTA教师的新增效应。优先完成C0/C1；不要因增加Cweak导致首轮所有实验都无法交付。
