## 2. C0 / C1 的唯一差别

```
L_total = CE_src + 0.1 * KL(H75_src || student_src) + λ_t(step) * L_target
λ_t = 0.2 * min(1, step / (0.2*3594))

kl_pix = Σ_c q_c (log q_c - log p_c)     # q = softmax(z_teacher + Bstar), p = softmax(z_student + Bstar)
C0:  L_target = mean(kl_pix)
C1:  w = a² * (1 - H_norm)，翻转像素 ×0.5；L_target = Σ w·kl_pix / Σw
```
