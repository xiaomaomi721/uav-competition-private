# H75-ST++-Lite V2（Class-Aware）完整方案与实验结果复盘

> **实验性质**：基于原始 H75_BSTAR 的单模型自训练改进实验；借鉴 ST++ 的“可靠样本优先训练—困难样本伪监督更新—重新初始化最终学生”两阶段思想，并引入类别感知的目标样本选择。  
> **完成日期**：2026-10-28  
> **实验状态**：`COMPLETE`（后台流程结束，最终本地评估完成）  
> **核心结论**：**本轮没有超过 H75_BSTAR；S2-Treat 相对 S2-Control 仅提高 0.0003 个百分点，困难集实际只更新 1 张图像、4 个背景像素。**

## 1. 实验背景与研究目标

### 1.1 本次实验到底建立在哪个模型上？

**唯一学生初始化基线是原始 H75 checkpoint，而不是 T3-00、ACDD 分支 checkpoint 或 T3-FULL-ST 的模型。**

- 原始学生权重：`/home/jhy/aic2026_h76_20261026/models/H75.pt`
- 原始权重 SHA256：`b5eea2795d8a6d90c803a15b2ca66cf0abcf62322ef1aacd0d4d0ec82098a28a`
- 模型架构：SegFormer-B3，8 类语义分割。
- **H75_BSTAR**：原始 H75 权重 + 最终推理阶段的固定类别 logit bias（Bstar）；Bstar 本身不是另一个模型。
- S1、S2-Control、S2-Treat **各自从同一个 H75.pt 初始化**，S2 不从 S1 继续训练。
- `T3-00` 在本次实际运行中是迁入的 **Arm B / Mask2Former 双教师监督缓存目录**（提供 pB/pD/M/G），不作为学生初始化权重。

### 1.2 研究问题

原始 H75_BSTAR 已有较成熟的双教师监督与门控机制。本轮想验证：

1. 是否能先挑选**相对可靠且不过度排除稀有类别**的 T3 目标域图像，训练出更有用的第一阶段学生 S1？
2. S1 是否能够在未参与第一阶段训练的困难图像 U 上，产生**优于原双教师的局部伪监督**？
3. 以原始 H75 重新初始化的最终学生 S2，使用改进的困难样本伪监督，是否能超过“仅使用原双教师监督”的受控版本 S2-Control，以及原始 H75_BSTAR？

本方案借鉴 ST++（CVPR 2022）的**分阶段自训练**框架，但并非原论文的逐项复现：原 ST++ 使用训练不同 checkpoint 之间的预测稳定性；本实验使用**冻结 H75 的增强一致性**作为候选可靠性指标，并继续沿用现有双教师软监督与门控流程。

### 1.3 数据与评估

| 数据 | 数量 | 用途 |
|---|---:|---|
| Source train（有标签） | 5,597 | S1、S2 的源域监督训练 |
| Source validation | 1,399 | 固定离线验证、教师与伪标签质量审计，不参与训练 |

## 2. 原定方案与实际实施方案的区别

最初讨论过“**每个类别内部取可靠性前 50%**”。但最终 `R_U_GATE.json` 给出的实际选择方法是：

`rare-class quota then best within-class JSD percentile; ties primary stability and ID`

即**稀有类别保底配额 + 类别内 JSD 排序 + 稳定性和 ID 确定性打破并列**，再构造固定总量 R/U。这**不能等同于对所有类别严格各取 50%**。

从 Source256 的选择诊断可读到：

- 稀有类别优先顺序：`[4, 6, 7, 2]`，即 Barren、Agricultural、Vehicle、Road。
- 最小候选区域比例：`0.005`。
- 稀有类别配额公式：`min(ceil(0.25 * eligible_count), ceil(0.10 * R_size))`。
- 该 Source256 检查的配额分别为 Barren 9、Agricultural 10、Vehicle 13、Road 13（R_size=128）。
- 以上是**源域审计中明确记录的规则与数量**，不能直接冒充目标域 3594 张的逐类别入选数量；目标域的详细入选图像数需要 R/U 清单或选择脚本进一步统计。

因此，本文对已完成实验统一称为：**H75-ST++-Lite V2（类别感知配额选择版）**。

## 3. 完整方法流程：我们具体做了什么

### 3.1 Stage 0：已有 H75 多视图可靠性 Pilot

先前已完成的 512 张 Pilot 直接复用，没有重复训练或重跑。

**评分思想**：对冻结 H75 的原始图像预测概率与独立轻度增强视图预测概率计算 JSD。几何增强后将概率恢复到原图网格。按单视图定义：

\[
S_a(x)=1-\frac{1}{|\Omega|}\sum_{p\in\Omega}
\frac{\operatorname{JSD}\bigl(P_0(p),P_a(p)\bigr)}{\ln 2}
\]

其中 \(a\) 分别为颜色、模糊、0.9 倍尺度扰动。评分使用未施加 Bstar 的 H75 输出。这是 **augmentation consistency**，不是 ST++ 原论文的 checkpoint temporal stability。

Pilot 统计：

| 增强视图 | Source 稳定性中位数 | 与 H75 源域像素准确率 Spearman | 高低 128 张组平均准确率差 |
|---|---:|---:|---:|
| 颜色 | 0.999948 | 0.749 | +9.11 pp |
| 模糊 | 0.999262 | 0.695 | +8.46 pp |
| 尺度 0.9 | 0.991358 | 0.700 | +8.89 pp |
| 最大置信度基线 | — | — | **+11.49 pp** |

说明稳定性确有一定区分能力，但**不能证明其优于最大置信度**。尤其全局前 50% 会明显漏掉困难类别：在 T3-256 模糊排序中，高稳定 128 张包含预测荒地的图像 **0 张**，低稳定 128 张则有 **27 张**；农田分别 **12 张/57 张**。这是引入类别感知选择的直接原因。

### 3.2 Stage 1：全量 T3 评分与类别感知 R/U 划分

对完整 T3=3594 张计算/复用冻结 H75 的可靠性结果，并通过类别感知的候选选择策略构建：

- **R（Reliable）=1,797 张**：先用于 S1。
- **U（Unreliable / Difficult）=1,797 张**：第一阶段不用于 S1 目标域训练，待 S1 产生更新候选。

类别感知选样强调荒地、农田、车辆、道路等类别的覆盖，同时仍受固定 R 总量和候选可靠性约束。实际选样与原先“逐类别严格 50%”设想存在差别，见第 2 节。

本轮在 GPU0 全量评分阶段曾发现 `score_full.py` 重复嵌套同一图像循环，造成多余记录。修复处理如下：

- 原始输出为 **5,072 条记录**，包含全部 **3,594 个唯一图像 ID**；重复记录 **1,478 条**。
- 重复记录内容一致；模型 SHA、图像哈希、增强配置、评分结构、有限数值检查全部通过。
- 安全停止了本轮自身的错误推理进程，并保留原始日志与输出。
- 在单独修复目录整理出恰好 **3,594 条、无重复**的规范评分结果。
- 最终 GPU3 续跑**复用全部 3594/3594 有效评分，补算 0 张**，没有重新进行整轮全量推理。

### 3.3 Stage 2：R/U 双教师质量准入（GATE_RU）

训练监督沿用经核查的原始双教师缓存：

- Arm B 教师概率：`pB`。
- Mask2Former 教师概率：`pD`。
- 原有置信/筛选门控：`M`、`G`，以及组合有效区域 `W`。
- 原有 G 中的 Donor 纠错和 non-G Anchor 机制保留。

实际迁移监督缓存的来源目录含 `T3-00` 名称，**名称不表示 T3-00 模型参与学生初始化**。教师缓存中的 pB 在历史生成时已经应用固定 Bstar，最终决定保留该冻结教师监督的既有语义；但**不再把 Bstar 显式加到 S1/S2 学生训练 logits，也不再加到 S1 新伪监督预测上**。最终评估继续使用原固定 Bstar。

准入检查涵盖源域监督正确性、稀有类别支持、G 中 Donor 纠错保留、目标域教师有效覆盖，以及选样与普通置信度选择是否确有区别。报告 `decision = GO`，允许进入 S1；**GO 是训练前质量门槛，不等于最终模型一定提升**。

### 3.4 Stage 3：第一阶段学生 S1

**S1 是中间学生，专门先学习较可靠的目标域数据。**

| 项目 | 实际方案 |
|---|---|
| 初始化 | 原始 H75.pt（严格核验 SHA） |
| 有标签训练 | Source train 5,597 张 |
| 无标签训练 | R 1,797 张 |
| 目标监督 | 冻结 Arm B / Mask2Former 双教师，沿用 M/G/Anchor 逻辑 |
| 目的 | 在较可靠样本上适应 T3，为困难集 U 提供新的候选软监督 |
| 输出 | S1 checkpoint；Source1399 验证预测；对 U 的候选概率 |

学生使用原始 logits 计算训练损失，不额外加 Bstar。S1 不是最终提交模型，也不用于初始化 S2。

### 3.5 Stage 4：S1 更新困难集 U 的伪监督

S1 完成后，对 U 中的图像产生预测概率 `pS`。不是把整个 U 的原双教师伪监督替换为 S1，而是做**局部受控更新**。

实际 `UPDATE_REPORT.json` 中记录的候选区域和准入规则：

| 条件 | 冻结规则 |
|---|---|
| 候选区域 | `M and not G` |
| S1 预测最大置信度 | `>= 0.95` |
| Arm B 置信度 | `<= 0.8` |
| Donor 置信度 | `>= 0.75` |
| 类别关系 1 | S1 与 Donor 类别一致 |
| 类别关系 2 | S1 与 Arm B 类别不同 |
| 更新概率 | `0.5*pB + 0.5*pS` |
| 源域候选像素数门槛 | `>= 1000` |
| 源域纠错/损害净收益门槛 | 记录为 `1.2`（详见原 JSON） |
| Bootstrap | 2,000 次 |

候选区域避开 G，意在避免直接覆盖原本 G 内的 Donor 纠错。未通过条件的区域沿用原监督。该机制在源域检查后得到 `GO_UPDATE`，但目标域的实际更新量极小（详见第 5.3 节）。

### 3.6 Stage 5：第二阶段学生 S2-Control / S2-Treat

**两个 S2 都从原始 H75 重新初始化，而不是从 S1 继续训练**。两者的核心差别仅在困难集 U 的部分软监督是否更新。

| 维度 | S2-Control | S2-Treat |
|---|---|---|
| 初始化权重 | 原始 H75.pt | 原始 H75.pt |
| Source train | 5,597 张 | 5,597 张 |
| T3 目标域 | 全部 3,594 张 | 全部 3,594 张 |
| R 的目标监督 | 原双教师 | 原双教师 |
| U 的目标监督 | 原双教师 | 仅通过准入的位置采用更新概率，其余保留原双教师 |
| 目标 | 验证全量 T3 训练本身的结果 | 隔离困难样本更新是否有额外收益 |

训练过程记录了 Source CE、原目标 KL、Anchor KL、门控覆盖、梯度有限性与学习率。已看到的 S2-Control 日志示例：

- `lambda_anchor = 0.15`；训练日志显示学习率参数组约为 `1e-5` / `5e-7`，并随步数下降。
- step 100～1700 的 `grad_finite=true`、`amp_skip=false`、`stepped=true`；未见这些日志片段显示数值崩溃。
- 多个 batch 的 `gate_pixels=0`，也有非零 batch（如 step 800、1000）；仅凭抽样日志不能断言 G 门控失效，需要全训练聚合统计。
- 日志出现 ADE20K 150 类头到 8 类头的初始化形状提示，但另有原始 H75 SHA 核验和实际严格载入流程；不应仅据此提示判定学生被替换为 ADE20K 权重。

训练结束后统一在 Source1399 上以固定 D4-TTA8+Bstar 评估四组模型。

## 4. R/U 筛选与教师质量审计结果

### 4.1 Source256：可靠组 R 是否真的更可靠？

本轮 `R_U_GATE.json` 的源域诊断将 Source256 划分为 128 张 R、128 张 U：

| 指标 | 类别感知 R | 类别感知 U | 最大置信度 R（参考） |
|---|---:|---:|---:|
| 图像数量 | 128 | 128 | 128 |
| 报告 accuracy | **92.6298%** | 85.7832% | **96.4918%** |
| G 覆盖率 | 2.3949% | 3.5606% | 0.0834% |
| G Donor 纠正像素 | 19,294 | 23,114 | 488 |
| G Donor 损害像素 | 1,487 | 3,414 | 317 |

类别感知 R 相比 U 的 accuracy 高约 **6.8466 pp**，报告给出的图像 bootstrap 差值 95% CI 为 **[4.0748, 9.4831] pp**。

这说明 R/U **有一定监督质量区分能力**，并且保留了相对更多的 G Donor 纠错机会。另一方面，最大置信度 R 组的总体 accuracy 更高，但其源域**农田真实标签像素为 0**，说明简单选择高度可靠图像可能严重牺牲稀有类别覆盖。不能仅比较一个整体 accuracy 就决定最优采样策略。

类别感知 R 中的部分源域稀有类别诊断：

| 类别 | R 的 GT 像素 | R Recall | R Precision | U 的 GT 像素 | U Recall | U Precision |
|---|---:|---:|---:|---:|---:|---:|
| Road (2) | 937,458 | 95.62% | 95.57% | 670,046 | 88.62% | 86.89% |
| Barren (4) | 100,518 | 94.24% | **47.28%** | 133,195 | 83.64% | 33.80% |
| Agricultural (6) | 412,841 | 98.28% | 80.04% | 800,978 | 96.47% | 79.06% |
| Vehicle (7) | 82,733 | 91.86% | 94.74% | 42,853 | 88.60% | 91.36% |

**解读**：R 保留了真实稀有类别，不像单纯置信度选择那样完全排除农田；但荒地的 Precision 仅 47.28%，也说明“确保出现”与“监督足够准确”是两回事。

### 4.2 T3：R/U 的原双教师有效监督并不均衡

| 指标 | R（1,797 张） | U（1,797 张） |
|---|---:|---:|
| M 覆盖率 | 85.7617% | 75.8602% |
| G 覆盖率 | 3.2142% | 4.4275% |
| W 覆盖率 | 85.8421% | 76.1052% |

按有效区域 W 中的双教师类别像素统计：

| 类别 | R 有效监督像素 | U 有效监督像素 | R 占该类 R+U 总量 |
|---|---:|---:|---:|
| Road | 8,111,144 | 3,775,470 | 68.24% |
| Barren | 1,573,529 | 2,938,303 | **34.88%** |
| Agricultural | 10,669,213 | 17,100,058 | **38.42%** |
| Vehicle | 467,952 | 256,512 | 64.59% |

尽管 R 占全部图像的 50%，却只包含 **34.88% 荒地**和 **38.42% 农田**的教师有效监督像素。这是本轮类别感知选择**仍然偏离稀有类别覆盖目标**的直接量化证据，不能因为 `GATE_RU=GO` 就认定问题完全解决。

另外，U 的 G 覆盖率比 R 更高，说明被排除的困难集可能包含较多原双教师的 Donor 处理区域。它可能影响 S1 的学习构成，但**不能仅由覆盖率差异证明其导致了最终退化**。

## 5. 最终实验成绩与增益分析

### 5.1 统一 Source1399 mIoU

最终报告写明评估为 **Source1399 + 固定 D4-TTA8 + 原始 Bstar**。

| 模型 | mIoU | 相对原始 H75_BSTAR | 相对 S2-Control |
|---|---:|---:|---:|
| **原始 H75_BSTAR** | **77.5311%** | — | +2.9529 pp |
| S1 | 74.2301% | **−3.3010 pp** | −0.3481 pp |
| S2-Control | 74.5782% | **−2.9529 pp** | — |
| S2-Treat | 74.5785% | **−2.9526 pp** | **+0.0003 pp** |

**主要结论：**

1. S1 经过 R 可靠集训练后，源域验证 mIoU 比原始 H75 **下降 3.3010 pp**。因此“可靠集优先训练”并未带来源域整体性能提升。
2. S2-Control 在全量 T3 上、使用原双教师监督训练后，比原始 H75 **下降 2.9529 pp**。即使完全不采用 S1 的伪监督更新，这轮新训练也没有超过 H75。
3. S2-Treat 仅比 S2-Control 高 **0.0003 pp**，数值过小，不具有可解释的实质增益；更不能作为“困难样本更新有效”的证据。
4. **不能断言 V2 的 T3 真实 mIoU 比 H75 低 2.95 pp**，因为这里所有数字来自 Source1399，尚无新方案的 T3 标签评估或线上分数。

### 5.2 重点类别 IoU

| 模型 | Barren | Agricultural | Vehicle |
|---|---:|---:|---:|
| **H75_BSTAR** | **46.1451%** | **74.0037%** | **81.7318%** |
| S1 | 31.9428% | 70.5085% | 81.2549% |
| S2-Control | 32.3348% | 70.8582% | 81.0162% |
| S2-Treat | 32.3356% | 70.8586% | 81.0158% |
| **S2-Treat − H75** | **−13.8095 pp** | **−3.1451 pp** | **−0.7160 pp** |

**荒地最明显退化**：从 H75 的 46.15% 降至 S2-Treat 的 32.34%，下降约 13.81 pp。农田下降约 3.15 pp，车辆下降约 0.72 pp。这与我们希望改善困难类别的目标相反。

> 本次对话中提供的 `FINAL_REPORT.md` 只列出了总体 mIoU、Barren、Agricultural、Vehicle 三类 IoU；其余五类完整结果在服务器 `FINAL_REPORT.json`，**当前未提供具体数值**，本文不擅自补写。

### 5.3 为什么 S2-Treat 几乎等于 S2-Control？——实际更新只有 4 像素

`UPDATE_REPORT.json` 的重要统计：

| 指标 | 数值 |
|---|---:|
| 源域验证图像 | 1,399 |
| 源域候选更新像素 | 2,129 |
| 源域纠正 | 2,024 |
| 源域损害 | 91 |
| 源域净准确率变化（候选区域） | +0.907938（原报告的比例值） |
| Bootstrap 95% CI | [0.638642, 1.0] |
| 源域准入决策 | `GO_UPDATE` |
| **T3 实际更新图像** | **1 张** |
| **T3 实际更新像素** | **4 个** |
| T3 更新像素类别 | **全部 Background (0)** |
| 其他 7 类更新像素 | **全部 0** |

注意源域候选像素的类别分布：

- Vegetation (5)：**2,102 / 2,129（98.73%）**，其中纠正 1,997、损害 91。
- Background (0)：22 个。
- Road (2)：5 个。
- Barren、Agricultural、Vehicle：**均为 0**。

由此可以看出：

- 源域报告的优秀候选纠错比主要来自**植被区域**，不是我们最关注的荒地和农田。
- 源域通过 `GO_UPDATE`，但同一规则在 T3 **几乎没有可实际替换的像素**；即使训练了 S2-Treat，和 Control 使用的监督几乎完全相同。
- S2-Treat 相对 Control 的 +0.0003 pp 与这个事实一致，**不足以把这种差值归因于有效伪监督更新**；还应考虑训练数值波动。

这是本轮“困难样本伪监督更新”**未达到预期作用**的最直接证据。

## 6. 失败原因分析：证据、可能机制与尚未验证的解释

### 6.1 已被结果直接证实的问题

**A. 类别感知筛选仍未保证目标域荒地/农田有效监督占比。** 进入 R 的图像占一半，但有效荒地和农田教师像素只占各自总量的约 35% 和 38%。第一阶段学习数据在稀有类别方面仍明显不足。

**B. 全量 T3 训练的 Control 本身退化。** S2-Control 相对 H75 下降 2.9529 pp，意味着性能下降不能简单归罪于 S1 的伪监督更新，因为 Control 根本没有执行这项更新。

**C. 实际 U 更新量几乎为零。** 只有 1 张目标图像、4 个背景像素通过更新规则，因此 Treat 基本没有真正获得新的困难类别监督。

**D. 选样规则与最初直觉并非完全一致。** 实施的是稀有类别配额式类别感知选择，而不是“所有类别分别严格前 50%”。这一差异应纳入实验记录，不能把此次结果等同于验证了用户最初提出的严格 50% 方法。

### 6.2 合理但尚不能证实的机制解释

**假设 1：训练使学生在 Source1399 上出现域适应相关的遗忘或类别偏移。** S1/S2 的源域指标整体下降，尤其荒地大幅退化；但是否是目标域适应换取了 T3 收益，当前没有 T3 真值，不能确定。

**假设 2：原教师有效监督在 R 中的类别/门控构成不利于荒地学习。** R 的 M 更高、G 更低，U 却包含更多荒地和农田监督像素。这可能影响 S1 的类别知识分布，但需要训练批次级别的类别有效损失、采样与 GT 混淆统计，不能仅由像素量直接推断因果。

**假设 3：源域伪监督更新门槛过于严格或跨域不匹配。** `M且非G`、S1 高置信、Arm B 低置信、Donor 高置信、两种类别关系同时成立的条件，在源域尚有 2129 像素，但在目标域仅 4 像素；可能是阈值校准、概率分布、候选区域或类别分布共同作用。**不能直接把阈值降低就当作解决方案**，否则可能丢失当前严格规则带来的纠错精度。

**假设 4：训练超参数/预算未必适配原始 H75 的进一步训练。** 已有日志显示训练过程无明显数值崩溃，但缺少完整的优化器、实际有效损失比例、所有 checkpoint 随步数变化与八类别混淆分析，暂时无法断言是哪一项造成了 2.95 pp 下降。
