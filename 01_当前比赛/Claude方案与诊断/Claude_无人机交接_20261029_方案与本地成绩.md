## 3. 各方案的依据和核对

### H75_BARREN_GATE4096（我自己的方案，建议交）
- **依据**：冠军在 Target 上的荒地出现图数是 879 张，官网是 721 张。多出来的 158 张全部来自小于 4096 像素的 Bstar 改判小块；在 Source 上，这类小块约 90% 是错的（恢复原判后约 68% 是对的）。
- **阈值怎么定的**：扫了 64/256/1024/4096/16384，多检图数分别是 +143/+130/+88/+1/−153，只有 4096 对得上官网。
- **核对**：和冠军相比只改了 768 张图里的 0.0699% 像素，没有一张图改动超过 5%。所有改动都是冠军判成荒地的像素，其中恢复成 Background 0.062%、Agri 0.004%、Water 0.003%。其他类之间没有变化。荒地出现图数 722。
- **预期**：影响大约 0.1pp，方向不能保证。
- **复现要注意**：推理在 argmax 之后要加一步（scipy `ndimage.label`，8 连通）。组委会没有专门确认过这类后处理。脚本 `gate_pack.py` SHA `b180d294d5fb1fb1d9c1c3709a8c68147b3c774033641375617a63af8fa0f7a3`。

### C1_MM / CTRL_MM（重新校准）
- **依据**：本赛段几个失败模型都直接套用了 H75 的 Bstar，结果在 Target 上都向 Background 漂移，漂移越大线上掉得越多：

  | 模型 | Background 面积 | 线上对冠军 |
  |---|---:|---:|
  | 冠军 | 29.66% | 0 |
  | C1 | 30.04% | −0.09 |
  | CTRL | 31.73% | −0.68 |
  | M2F | 35.65% | −3.37 |

  重新拟合 bias，让面积和冠军一致，就把“模型排序能力”和“类别平衡”分开了。
- **方法**：`mm_fit.py`，Background 固定 −0.2，迭代 `b += 0.5·(log A* − log A)`。自检：在 H75 缓存上从 0 开始，能找回 Bstar（各类误差 <0.01）。
- **拟合出的 bias**：
  - C1_MM `[-0.2, 0.0896, 0.1607, 0.5792, 3.5841, 0.3462, 2.4668, -0.2591]`
  - CTRL_MM `[-0.2, 0.2626, 0.8255, 2.1750, 5.0537, 0.9786, 3.2409, -0.1929]`
- **核对**：用冻结打包脚本 `package_semifinal_bias.py`（SHA `206cc80d…`，和冠军同一份）做 FP32 推理。和冠军相比不同像素：C1_MM 1.63%，CTRL_MM 2.76%，说明文件名对应正确。各类面积和冠军相差不超过 0.01pp。
- **注意**：这和队友的 EM/BBSE、PRESENCE_V1 是同一类方法（用 Target 统计重新拟合 bias）。区别只是作用对象（C1/CTRL，而不是 H75）和目标（冠军面积，而不是估计的真实先验）。

## 4. 今天的诊断发现（供后续方案参考）

1. **丢分在跨域**：H75 同域（Source Zero）80.44，接近头部的 Target 成绩 81.33；我们的 Target 成绩是 71.00。
2. **同域丢分拆解**（Source Zero，精确分解，各项相加等于 100−mIoU = 19.56pp）：
   - 经过 Background 的损失占 38%。
   - Bg↔Barren 3.85、Bg↔Agri 2.50、Bg↔Bld 2.21、Bg↔Road 2.14。
   - Bg/Barren/Agri 三类之间互相错判合计 7.18pp。
   - 加 Bstar 后最大的单项是 Bg→Barren 误检 5.08pp。
3. **全局 bias 对不同场景不合适**：Source 上 Bstar 在三类外观场景里分别 −3.57 / −1.63 / −1.43pp。Target 中占比上升最多的绿色场景（26.2%，Source 17.5%），在 Source 上 Agri IoU 只有 48.0（其他场景 77–80），这类场景里 Source 的农田像素只占 2.2%。
4. **教师的问题**：
   - T3_FULL_ST 的教师 96.4% 像素是 Arm B（比 H75 弱）。
   - C1 的教师就是 H75 的 D4 输出，学生部署时也用 D4，学不到新东西。
   - 绿色场景里冠军判成 Background 的像素，教师置信权重均值 0.918，置信度过滤滤不掉。
5. **测试时放大**：历史包 37/38（0.75x / 1.25x 单尺度）线上 −0.66 / −1.13，与 10-29 上午“放大 1.5x”的方案相反。
6. **训练侧稀有类采样没生效**：在 1024 原图上裁 1024，起点固定为 (0,0)（队友的 deep_diag 也已发现）。
7. **Road**：Target 上少检出 377 张图，在 Barren/Agri/Water 的 bias 扫描范围内一直不变（1849 张），调 bias 修不了。
8. **BARREN_2P6 的依据不成立**：它改 0.39% 像素，主要削的是大片荒地，出现图数只降到 +56。“荒地出现图数偏多”是小块造成的，不能拿来支持全局降荒地 bias。
