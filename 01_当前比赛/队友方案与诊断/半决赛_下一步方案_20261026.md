## 一、核心判断：今天的 7pp 反转就是提分地图

**事实**：

| 协议 | source1399（源域） | test3（半决赛，今日） |
|---|---:|---:|
| Bstar | 77.5311% | **74.9987%** |
| Zero | 80.4418% | **67.9796%** |
| Zero − Bstar | **+2.91pp** | **−7.02pp** |

**这 7pp 的反转说明一件事：bias 校准在 test3 上是最大的单点杠杆，而且 Bstar 不是 test3 最优。**

再叠加历史 source1399 的四组消融（`AIC2026_H75_短板诊断_20261025.md`）：

| 消融 | source1399 mIoU | Barren IoU |
|---|---:|---:|
| A 原始 Bstar | 77.5311% | 46.15% |
| C 仅 Barren bias 3.6→0 | 79.4055%（+1.87） | 59.41% |
| D 仅 Agricultural bias 2.1215→0 | 77.8746%（+0.34） | — |

**推导（标为推断，需线上验证）**：
- source1399 上，荒地 bias 3.6 是**最大负贡献**（去掉它 Barren IoU 从 46→59，整体 +1.87pp）→ 源域里 3.6 导致荒地**过预测**。
- test3 上，Zero（全置零）反而 −7pp → 说明在 test3 上这些 bias 是**正贡献**，且可能还不够。
- 唯一自洽解释：**test3 的荒地真实占比远高于 source1399**，Bstar 的荒地 3.6 在 test3 上不是过预测，而是**偏保守**。

→ **第一个可执行提分动作：在 test3 上，荒地 bias 从 3.6 继续往上抬（3.8 / 4.0 / 4.2），线上验证是否继续涨。** 这是零训练、成本最低、有明确方向的候选。

## 二、提分主线 1：test3 专属 bias 重标定（零训练，优先做，杠杆最大）

### 2.1 为什么这是最大杠杆

- 历史（初赛）用「测试时 bias 校准 + TTA」从 66.7 提到 69.28，**其中 bias 贡献约 +1.9pp**，是所有手段里最大的（`提分构成锚点.md`：提大分的全是测试时先验，训练期只 +0.67）。
- 半决赛 test3 = test1(500)+test2(1300)+新增(1794)，**分布已变**，Bstar 是旧分布（test1/初赛）标定的，必然失效一部分。
- 今天的 7pp 反转证明 test3 上 bias 敏感性极高（荒地一维就值 ~2pp 量级）。

### 2.2 系统方法（不需要 test3 真值，零成本）

用 H75 自己的伪标签统计来定方向（复用历史 `复赛Bias重算流程_基于测试集伪标签.md` 的方法论）：

1. 用 **H75+Zero（无偏置 logits）** 对 3594 张 test3 做 argmax，统计 8 类占比 → `P_zero`（模型本体认为 test3 长什么样）
2. 用 **H75+Bstar** 同样统计 → `P_bstar`
3. 对比训练集 5597 张真实标签占比 `P_train`
4. 三组占比的差值关系给出每维修正方向：
   - 某类 `P_bstar < P_train` 且该类是历史弱类（荒地/农田/车辆）→ bias 还压得不够 → **继续抬**
   - 某类 `P_bstar > P_train` → 过预测 → **压**
5. 优先处理**高杠杆维**（荒地 +3.6、农田 +2.1215、背景 −0.2、水体 +0.4、植被 +0.4），每维只生成 1 个候选，不铺开扫描。

### 2.3 具体候选 bias（按优先级，预注册不事后改）

起点 Bstar = `[-0.2, 0.1, 0.0709, 0.4, 3.6, 0.4, 2.1215, -0.5]`
（顺序：背景/建筑/道路/水体/荒地/植被/农田/车辆）

| 优先级 | 候选 | 改动 | 依据 |
|---|---|---|---|
| ★1 | 荒地 3.6→**3.8 / 4.0** | 只动荒地一维 | 今天的 7pp 反转 + source1399 荒地是最大负贡献 → test3 荒地是最大正贡献 |
| ★2 | 农田 2.1215→**2.5 / 2.8** | 只动农田一维 | 农田也是大偏置维，历史锁定 B3 曾到 3.32，说明该维空间大 |
| 3 | 背景 −0.2→**−0.3** | 只动背景一维 | 背景是历史第一杠杆（单调压到 −0.2 才见顶） |
| 4 | 荒地+农田 组合 | 二维同调 | 单维见效后再试组合（历史规律：类间耦合，组合 ≠ 单维相加） |

**纪律**：每次只改 1 个维度，其余锁 Bstar；只挑最高杠杆的 2-3 个候选提交，**不 8 维铺开**（额度不够）。每次提交记录线上分，用线上分决策下一步，**不信本地分**（source1399 方向已被证伪）。

## 三、提分主线 2：test3 无标签域自训练（第二波，唯一搬得动 ~1pp 的训练方向）

### 3.1 原理与合规

把 test3 的 3594 张无标签图用 H75 打**高置信伪标签**（conf≥0.9），混入训练集重训，让模型训练时见过 test3 分布。官方已确认合规（用官方测试图+伪标签，非外部数据；最终单模型）。

历史依据（`战略转向_训练时自适应_伪标签蒸馏.md`、记忆 `uav-no-second-large-lever-as-of-20260927`）：
- **测试域自训练是历史唯一搬得动 ~1pp 的方向**。
- 官方点名「无脑全用效果一般，必须置信度过滤」；历史 Exp22 失败（−0.136）是弱模型(66.x)+无过滤，H75 是 74.9987 的强模型，条件成熟。
- 反面前科：stage65 伪标签螺旋「本地最高线上更低」——必须严格 conf 过滤 + 保留 source CE 防遗忘 + 单机制不堆叠。

### 3.2 执行步骤

1. **先完成主线 1**，锁定 test3 最优 bias（自训练出包要用这个 bias，否则白训）。
2. 用锁定 bias 的 H75 给 3594 张 test3 打 conf≥0.9 伪标签（train ID 0-7 + 255 低置信）。
3. 伪标签图混入训练集（新 ID 7000+），从 H75.pt **严格 load** 继续训练（新建 optimizer，stage2/stage3/decode_head 可训，其余冻结）。
4. 训练后用同一 test3 最优 bias 出包，线上验证。

### 3.3 关键约束（防踩历史坑）

- **单机制**：只做「test3 伪标签 + source CE」，不叠 H76-CaSC 的 context/scale/anchor 多模块。
- **保留 source CE 主监督**防遗忘。
- **conf 过滤 + 连通域过滤**，不强用低置信图。
- **不做伪标签螺旋多轮**（stage65 教训），一轮即止，出包验证。

## 五、诚实边界与风险

1. **不保证提分**：test3 无标签，无法提前证明。荒地抬升是「有方向的赌」，方向来自今天的反转，但幅度未知，必须线上验证。
2. **Bstar 74.9987 是已知可复现的回退**，所有实验都不破坏它（不覆盖 H75.pt、不改 Bstar 向量记录）。
3. **本地分不可信**（source1399 上 Zero>Bstar 但 test3 上 Zero<Bstar），任何「本地涨了」都不等于「线上涨」。
4. **伪标签螺旋有前科**（stage65 本地最高线上更低），主线 2 一轮即止，不迭代多轮。

## 六、明确不做

- 不 8 维铺开扫描 bias（额度不够，且历史证明单维最优≠组合最优，要小步验证）。
- 不启动 H76-CaSC 四模块组合训练（多变量不可归因，且其 source 代理域验证已被今天的反转证伪）。
- 不在 source1399 上继续做任何「验证」（方向已被证伪）。
- 不模型集成（违规红线）。
