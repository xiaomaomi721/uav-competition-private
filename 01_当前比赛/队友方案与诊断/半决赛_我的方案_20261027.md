## 一、三个已用数据坐实的结论（不是我拍脑袋）

### 结论 1：bias 校准这条路到顶了，包括我自己的分域校准方案

我用服务器数据做了完整的推演，**亲手证伪了自己的第一个方案**：

- test3 = test1(500) + test2(1300) + test3_new(1794)，三个子集 raw 预测占比显著不同（Vegetation: 24.28% / 21.97% / 22.15%；Background: 31.56% / 34.92% / 35.34%）。
- 我提出「给每个子集各配一个 bias（先验对齐）」，算出来的 bias 和 **Zero 几乎同向**（cosine 仅 0.38，荒地只 +0.77 而 Bstar 是 +3.6）。
- 而 Zero 今天已线上证伪（掉 3pp）。→ **test3 的偏移不是「先验偏移」，是「表征失效」**（荒地漏检 60%、植被被误判成背景 7pp）。bias 怎么调都补不回来。

**含义：不再在 bias 上花任何精力，包括农田 bias 下调这种小修小补。**

### 结论 2：最大确定收益 = CTRL 续训模型，且因果对齐 test3 最痛点

队友已跑完的 CTRL（source-only 续训 3594 步，从 H75 初始化）在 source1399 上：

| 集合 | H75 基线 | CTRL 续训 | 涨幅 |
|---|---:|---:|---:|
| guard 694 bstar | 77.25% | **79.16%** | **+1.91pp** |
| proxy 705 bstar | 77.55% | **78.89%** | **+1.34pp** |
| **荒地 IoU（guard）** | **46.15%** | **55.39%** | **+9.24pp** |

关键：**荒地正是 test3 上最严重的漏检**（raw 预测只有 0.70%，vs source 真实 1.77%，漏检 60%）。CTRL 续训把荒地学扎实了，这是因果对齐的收益，不是巧合。机制：H75 是参数平均产物（`(9C+R05+R06+R07)/12`），欠收敛，续训让它把难类重新学到位。

**含义：CTRL 是当前确定性最高的一击，优先提交。**

### 结论 3：真正的提分必须解决「无标签目标域的确认偏差」，而这需要「多尺度一致性」而非「绝对置信度」

历史伪标签失败的全部根因，归结为一点：**教师在 test3 上只有 67.98%(Zero)~71%(Bstar)，用它的绝对置信度做监督，就是让错误自我放大。**（stage65 伪标签螺旋：本地最高线上更低）

唯一能对抗确认偏差的，是**多个独立视图的一致性**——如果模型在多个不同变换下给出一致预测，这个预测比单一视图的置信度更可靠。

而历史 E01 已证明：**尺度是真正的分歧来源**（四尺度共同错误仅 7.66%，事后 oracle 可达 92.34%）。所以「多尺度一致性」是比队友 CaSC 的「identity+hflip 两视图」更强的信号，且**恰好对症荒地漏检**——荒地像素在低分辨率下更容易被误判，多尺度一致性能把「0.75× 也判荒地、1.25× 也判荒地」的像素捞回来。

### 第二步（随后，结构性方法）：多尺度一致性引导的单轮自训练

这是**我的方法**，用于补本体表征域差（12.46pp 里 bias 补不动的那部分）：

1. **教师**：H75 冻结，跑多尺度（1.0× / 0.75× / 1.25×）+ D4 旋转，得到逐像素多尺度预测。
2. **可靠性判据（关键区别）**：不是绝对置信度，而是**多尺度一致 + 单尺度高置信**的交集。荒地像素即使在单尺度置信度低（历史阈值 0.64 会滤掉），只要多尺度一致判荒地，就纳入监督。
3. **损失**：一致区域 → 硬伪标签 CE；分歧区域 → 一致性正则（拉向多尺度平均），不做硬伪标签。
4. **硬约束（每个对应一个历史坑）**：单轮（不螺旋，防确认偏差）、2000~4000 步（防遗忘）、单教师 H75（防双教师净纠错为零）、lr 1e-6~5e-6（防扰动已收敛权重）、source CE 主导 0.1（防灾难性遗忘）。

### 第三步（兜底）：CTRL 续训 + 多尺度一致性自训练的组合

若第二步单机制验证有效，再把「CTRL 续训好的荒地表征」作为自训练起点，叠加多尺度一致性监督——两条收益正交，可叠加。
