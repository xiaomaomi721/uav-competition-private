## 一、核心结论（今天一整天的数据收敛）

**唯一被数据反复印证的提分 = H75 欠收敛，source-only 续训 +1.32~1.59pp。**

| 实验 | 结果 |
|---|---|
| CTRL 续训 3594 步（TTA8） | +1.59pp，荒地 46.15→53.60 |
| CONTROL 续训 2000 步（TTA8） | +1.32pp，荒地 46.15→50.53 |
| 最优 checkpoint ckpt_005400（TTA8） | **79.2878%** |

**为什么今天很多方案失败**：荒地是「高置信错误」（conf 0.75 但 precision 0.48），不是「低置信犹豫」。所有依赖"错误≈低置信"假设的方法（伪标签、熵最小化、多尺度）都救不了。bias、多尺度、伪标签、盲类召回全部在此前提下失败。

## 二、正在推进的正确方向：ATDA 迁移（历史已验证配方）

**ATDA = Anchored Target-Domain Adaptation**，历史 test1 上是 +0.33pp 的正收益，是历史上唯一把「自监督 EMA + hard pseudo 用测试集」验证为正的配方。

**配方**（历史已验证）：
```
起点/ref/ema 教师 = 已收敛模型
loss = source_CE + ramp × (0.5×loss_hard + 0.25×loss_cons)
loss_hard = 加权 CE 到参考教师 argmax（w = 置信度）
loss_cons = 加权 KL(学生 || EMA教师)  ← 自监督一致性
```

**迁移改动**：
- 起点/ref/ema = ckpt_005400（已收敛 CTRL，79.29%）——不是欠收敛 H75（这是 blind-recall 失败的根因）
- target = test3 3594
- 参考缓存 = native-256 D4 TTA8 logits

## 六、关键教训（今天踩的坑，避免重犯）

1. **起点必须用已收敛模型**（ckpt_005400），不是欠收敛 H75——blind-recall 用 H75 失败（−1.78pp）就是这个原因。
2. **不要瞎设参数**，用历史已验证配方（2000步、lr 1e-5、head 5e-7、batch 1）。
3. **荒地是高置信错误，不是低置信**，熵最小化/伪标签都救不了。
4. **source-only 续训是确定性 +1.5pp**，但只补欠收敛，不补 test3 域差。
5. **test3 域差的唯一可能解法**：ATDA 自监督（不依赖教师对错，只依赖图像结构），这是历史唯一没在 test3 上试过的正方向。
