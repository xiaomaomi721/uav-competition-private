# H75利用3594张无标签图的下一步方案：BLDA-Soft

日期：2026-10-27。作者：本助手。
状态：论文与作者代码已核对；完成一个CPU数学核验；训练实现、服务器运行和线上验证均未开展。
本文件是可供其他AI和队友独立审阅的方案。资料中的历史命令不视为本轮执行指令。

## 1. 我的决定

下一条建议实施的候选是：**H75 + 保留软标签的类别条件损失调整，简称BLDA-Soft。**

保留SegFormer-B3、源域真实标签、目标软监督、盲类召回和固定Bstar；新增的是：利用源域和3594张目标图中“某类像素对八个类别分别打多少分”的统计，改变学生训练时各类别的竞争压力。推理仍是一份B3权重。

它是基于BLDA在线logit调整思想的项目改造，**不是原论文完整复现，也没有本项目提分结果**。推荐理由是与既有收益机制的契合度、可分离的对照和较小的架构改动，不是已经测出了最高成功概率。DINO训练继续暂停。

目标仍是半决赛72；按用户确认的本轮H75+Bstar 70.998665，差距为1.001335个百分点。这里不承诺BLDA能补齐这段差距。

## 2. 论文到底支持到哪里

主要依据是 [Balanced Learning for Domain Adaptive Semantic Segmentation，ICML 2025](https://proceedings.mlr.press/v267/li25cc.html) 及其 [正文、表4与附录](https://arxiv.org/html/2512.06886v1)。

论文在GTA→Cityscapes、DAFormer基线上给出：

| 配置 | mIoU |
|---|---:|
| 基线 | 68.3 |
| 推理后校正 | 69.2 |
| 仅源域训练期调整 | 68.9 |
| 源域＋目标域训练期调整OLA | 70.2 |
| OLA＋辅助任务CDE | 70.7 |

这支持“训练期按类别条件分布调整”值得研究；不是只靠最后改几个偏置。论文还显示，更均衡的分类表现不一定对应最优mIoU。

**适用边界：**实验是合成驾驶图到真实驾驶图，不能直接外推低空航拍；论文没有验证我们的H75、Bstar和软KL组合。其目标侧统计仍依赖伪标签，没有解决“教师稳定错了，怎么知道真值”的全部问题。

其他路线的论文对照：

| 路线 | 论文支撑 | 这次不作为主线的原因 |
|---|---|---|
| 不确定像素负样本学习 | [U2PL，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/html/Wang_Semi-Supervised_Semantic_Segmentation_Using_Unreliable_Pseudo-Labels_CVPR_2022_paper.html) | 可以使用部分不可靠像素，但排除容易负类未必解决农田/荒地混淆；负类也可能选错。 |
| 源域与目标域语义混合 | [DACS，WACV 2021](https://openaccess.thecvf.com/content/WACV2021/html/Tranheden_DACS_Domain_Adaptation_via_Cross-Domain_Mixed_Sampling_WACV_2021_paper.html) | 有直接跨域研究依据，但本项目ClassMix版本成绩链未闭合，且已有随机CopyPaste负面记录，需要另行核对。 |
| 遮挡上下文一致性 | [MIC，CVPR 2023](https://arxiv.org/abs/2212.01322) | 项目已做过训练，历史坏包不能判方法失败；应查明修复包评分，不能当全新方案重复提出。 |

上述论文支持的是机制；本项目优先级是我的判断。

## 3. 项目证据如何影响设计

### 3.1 沿着有收益的机制继续，而不是把旧结论当定律

- 历史A05→Arm B：70.775011→71.045315，增加0.270304pp；涉及类别感知目标软KL和轻源域锚的整套配方。
- 特定TREAT与source-only CONTROL的+0.595100pp是匹配对照差值，不能再加到Arm B收益上。
- Arm B→ACDD C→H75还有后续收益，不能说项目只有同源自训练有效。
- 本轮H75+Bstar 70.998665，Zero 67.979564，差3.019101pp。它支持保留现有Bstar作为比赛对照，**不证明BLDA还能再获得一份相同收益**。
- ROUND2同时换教师、加test1和延长训练，没有单独隔离哪个变化失败。1.68%像素变化也不能直接判为“几乎没变”：小类的IoU可能由很少像素决定。

这些证据支持研究类别决策与训练信号，但尚不能证明剩余误差主要来自类别偏置。

### 3.2 当前代码已经有哪些东西

已读取本地归档：
uav_semantic_segmentation/无人机/scripts_20260928/round2_iterative/a05_treat_round2.py。

它已有D4、亮度/对比度/饱和度/gamma、噪声和模糊增强；源域使用raw-logit CE；目标侧教师和学生都加同一Bstar再做软KL；水域/荒地/农田有较低置信阈值。不能把“加颜色增强”或“加软标签”重新包装成创新。

这是历史ROUND2代码核对，**不等于H75生成过程或队友当前程序全部相同**。新分支应独立从已知H75权重出发，不能直接运行旧脚本中的路径和教师配置。

### 3.3 这条方法提供的新约束是什么

普通软KL在学生概率等于教师时，其目标梯度为零。增加图片、延长训练，若没有产生新的有效约束，就可能主要继续复制教师。

本方案让源域真标签和目标类别条件统计共同定义训练压力：即使学生暂时复制教师，调整后的损失仍可能要求它提高某类的相对分数。这改变了优化目标，而不只是重复采样。

但这不等于给测试图补上真标签。若教师将农田系统性标成荒地，错误分组仍会污染统计。本方案能处理的假设是“已有语义能力之上的类别训练偏差”；不能保证修复所有语义错误或补回分辨率丢失的小目标。

## 4. 可实施设计

### 4.1 输入与模型身份

- 有标签源域：5597张训练图；1399张验证图不进入训练或GMM统计。
- 无标签目标域：3594张，保留500/1300/1794分组；分组用于日志分析，首轮不分别拟合三套校正。
- 学生与固定教师都从H75初始化，SHA256：
  b5eea2795d8a6d90c803a15b2ca66cf0abcf62322ef1aacd0d4d0ec82098a28a。
- 历史路径：/data/uav/runs/ASTRA_H75_X110_20261005/ckpt/H75.pt。此为交接记录，本轮没有远程复核位置。
- 固定类别顺序：Background、Building、Road、Water、Barren、Vegetation、Agricultural、Vehicle。
- b = [-0.2, 0.1, 0.0709, 0.4, 3.6, 0.4, 2.1215, -0.5]。
- 目标教师概率 q = softmax(raw_teacher_logits + b)，温度1；教师固定，不额外启用EMA或新异构教师。

现有缓存记录为prob(8,512,512)+agree，不能直接当raw logits。softmax丢失了每像素共同logit偏移；log(prob)并不能恢复作者方法使用的原始分数分布。若不能证明缓存身份与定义一致，本候选新生成H75单弱视图native256 raw logits，两个实验共用。3594张FP16裸张量约3.51GiB，不含文件头和清单。

### 4.2 怎样统计

分别维护源域和目标域的8×8条件分布：

- 源域按GT类别c分组，统计学生对每个通道l给出的raw logit。
- 目标域按固定教师q的argmax分组，只从现有有效监督掩码内收集；统计学生经几何逆变换后的raw logit。
- 目标统计的“类别c”是伪标签类别，不声称是目标GT。
- 源域全局正类/负类分数提供共同参照；目标数据提供本轮条件分布。
- 按类抽样仅用于稳定估计条件分布，不把目标面积拉成1/8，也不让各类训练像素数强行相同。

统计用detach后的FP32学生输出；同一次前向产生的分数同时用于损失和统计。当前步使用之前积累的统计做校正，随后更新统计供下一步使用，避免首个像素给自己拟合分布。

首轮实现选择：每个分布5个高斯分量，EM每次3轮、动量0.99；按类保留4096个样本的有界reservoir，每20步更新一次。至少来自5张图、累计500个有效像素才启用对应类别行；不足则该行校正为零。均值按顺序对齐后更新混合分量，方差下限1e-4；CDF逆映射限制在1%—99%区间。

K、EM轮数、动量和500像素起点参考作者公开配置；buffer、跨图条件、更新频率及稳定化细节属于本项目设计值，尚非调优结果。5张图也不等于5个独立场景，需记录文件组与可用的近重复组信息。

源域损失仍在原1024网格上对GT计算；GMM对同一插值后logit空间抽样。目标损失在native256网格上计算。源域与目标域各拟合各的条件分布，这两个网格不代表相同细节质量；尤其车辆需单列统计，不能只看总mIoU。

### 4.3 怎样保留软标签：关键公式

记Delta_c为“若当前像素按类别c解释，各通道分数映射至参照分布所需的位移”。位移用raw logits计算；计算CDF、拟合与位移均不反传。

实际训练校正 a_c = clip(alpha × Delta_c, -0.5, 0.5)，其中0.5是单通道最大logit位移，不是类别概率，也不构成精度保证。

源域：

    Ls = mean_valid CE(zs - a_y, y)

目标域：

    xt = zt + b
    Lt = mean_mask [ - sum_c q_c * log softmax(xt - a_c)[c] ]

总损失：

    L = 0.1 * Ls + ramp(step, 500) * Lt

这里每个候选类别c对应自己的校正向量与softmax分母。**不能只算argmax类别的一行，再声称实现了上述软目标公式。** 实现可逐行累加，不必同时保存所有类别的中间张量。

alpha=0时，Lt是软交叉熵；与既有KL只差固定教师熵，学生梯度相同。日志同时报告原始未校正KL和新目标，避免把常数差异当优化进展。alpha>0时它不是普通KL，不应强行称为一个概率分布之间的KL。

这是对原法硬标签条件损失的软目标扩展；它保留分布信息，但**没有论文的直接消融证明**。源域one-hot目标下退化为相应行的训练期调整。训练使用减号；把它写成推理后加号会改变方法意义。

### 4.4 Bstar怎样处理

源域、目标域的GMM都拟合raw logits；目标概率和目标学生损失中各加一次相同b；最终推理保留原Bstar。不再做第二次CDF推理后校正。

这能避免机械地重复添加Bstar，**不能保证BLDA与Bstar的作用互不重叠**。因此首轮固定Bstar、不重扫偏置；如果需要联合调校，作为后续独立问题讨论。不能看到Zero改善就宣布成功，最终仍以实际部署的Bstar配置线上成绩判断。

### 4.5 首轮固定训练规格

以下均为待执行配方，不是已验证最优超参数：

| 项目 | 决定 |
|---|---|
| 更新预算 | 3594次，每次1张source＋1张target |
| 数据顺序 | target按固定随机顺序每张一次；source从5597中固定打乱，取相同3594次；两臂完全相同 |
| 可训练层 | B3 stage2、stage3及decode head，其他冻结 |
| 学习率 | stage 1e-5；head 5e-7；AdamW，weight decay 0.01 |
| LR日程 | 沿历史小步续训方式：初始LR×[1-(step-1)/10000]；两臂一致 |
| 数据增强 | 复用上文已核对的D4和strong_photo，不加新裁剪、遮挡或ClassMix |
| 伪标签掩码 | confidence≥0.98；或预测为Water/Barren/Agricultural且confidence≥0.50 |
| 目标系数 | 前500步升至1.0；source系数0.1 |
| 校正强度alpha | 前500步为0，只积累统计；501—1000步线性升至0.1，此后0.1 |
| 辅助CDE | 不加入 |
| 保存 | 1000、2000、3594步；3594为预先指定终点，早期点用于诊断 |
| 随机种子 | 20261027；统计抽样使用独立随机数发生器，不扰动数据增强顺序 |
| 推理 | 既有D4八视图→对齐平均raw logits→一次Bstar→原输出映射 |

3594步仅保证首轮target覆盖一次，不代表3594张都获得可靠监督，也不代表已充分收敛。不能用这轮短续训否定论文40K训练的整体有效性。其目的在于检验当前冠军上是否出现值得继续投入的增量。

## 6. 不等待目标GT，具体看什么

### 开训前与前500步

1. 校验H75、3594个ID、分组、类别顺序、raw缓存和Bstar身份；不能接错队友Zero概率缓存。
2. alpha=0时，同批数据的新旧目标梯度应在数值容差内一致；源域ignore255、全空目标mask、D4对齐分别核对。
3. 输出按“阶段组×预测类”的有效像素覆盖、有效图像数、条件分布样本数、缺失类别行。统计失败的类别不强行拟合。
4. 实测50步时间与显存，再估算两臂预算。不能把旧B3脚本20分钟直接当新方法工期。

### 训练中与终点

必须产出：

- 每类校正位移、达到限幅的比例、对logit梯度的影响；观察是否主要由荒地/农田或背景支配。
- 每类普通KL、调整后损失、有效监督覆盖，按500/1300/1794分开。
- source1399逐类IoU、precision、recall；已知部分存在训练重叠，另列已排查未发现重叠的605子集。两者都不是目标域验证集。
- 目标预测转移矩阵、按类归一化变化率，以及变化发生在哪些图/小目标/边界。改变多少像素不等于改对多少。
- C0、C1与H75的固定Bstar推理结果；Zero只作诊断，不凭它选择比赛候选。

明确的工程停止条件：NaN/Inf、缓存身份不明、标签错位、alpha=0不等价、GMM缺样本却产生校正、断点恢复改变统计状态。修复后再运行。

源域明显退化、目标某类消失、校正长期大量撞限幅，均是需要暂停检查的风险信号；不能根据某个单独代理数值宣判目标涨跌。可固定96张分组覆盖图作诊断，人工观察只找伪影，不为测试图补GT或拟合人工标签。

### 线上判断

- 本轮可确认冠军门槛是70.998665，不是旧test2的71.329400。
- C1与匹配C0的线上差值才用于估计本次处理的增量；只评C1时明确因果证据有限。
- 未超过基线，不以“分布更均衡”“source涨了”宣布成功。
- 一次训练失败只否定这套具体迁移配方，不能反过来宣布所有目标数据利用均无效。

## 7. 作者代码审核发现：实现时不能跳过

作者仓库：[Woof6/BLDA](https://github.com/Woof6/BLDA)，固定核对提交 eff6331f55c19a3523c2a322014d878ca085eb07。

1. [损失实现](https://github.com/Woof6/BLDA/blob/eff6331f55c19a3523c2a322014d878ca085eb07/mmseg/models/losses/cross_entropy_loss.py#L762) 内部写死19类，需参数化为8。
2. 混合样本用weight==1判断source、0<weight<1判断target。我们应显式传domain标识，不能把权重1的目标像素误分到source。
3. 官方GMM为普通Python对象和tensor属性，并非完整注册的模型buffer；项目checkpoint需显式保存分布、reservoir、计数、随机状态，验证恢复一致性。
4. 作者配置中tau=0.99表示统计动量，t=0.1才是校正尺度。二者不要混淆。
5. [README指定配置](https://github.com/Woof6/BLDA/blob/eff6331f55c19a3523c2a322014d878ca085eb07/configs/daformer/gta2cs_uda_warm_fdthings_rcs_croppl_a999_daformer_mitb5_s0_blda.py) 的t2=0，关闭了辅助损失；实际代码辅助回归用绝对值，而正文公式使用平方误差。因此不能宣称运行该入口就完整复现表4最后一行。
6. 作者完整环境含DACS、EMA、特征距离与驾驶图上下边缘忽略设置；不能无差别复制到航拍。我们的C0/C1不引入这些额外改动。
7. 统计detach和训练减号已在代码核对。逆CDF与GMM浮点稳定性仍需真实实现测试，本轮数学小测试不能替代。
