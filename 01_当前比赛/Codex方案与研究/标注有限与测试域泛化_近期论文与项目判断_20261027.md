# 标注有限、3594张测试图与泛化：近期论文及项目判断

日期：2026-10-27。目的：回答“训练只有五千多张，而测试三千多张，是否有近期论文研究这种情况，以及对我们的方案意味着什么”。

**同日优先级补充：** 用户指出DINOv3已有不理想结果后，重新核对PMT2000步评估，明确继续暂停DINO训练。文中的DINO辅助方式是文献候选，不是当前比赛主线；用法不同和论文有收益，都不足以推翻本项目尚无增益证据的事实。详细裁决见《3594张无标签测试图_利用方法与实施边界_20261027.md》开头补充。

本次工作：核对已有项目审计记录；检索2025—2026相关论文，并阅读下列主要论文的方法/实验部分或官方摘要。没有连接服务器、占用GPU、启动训练、修改既有模型或提交结果。论文实验不是本项目实测，以下建议也不是已执行实验。

## 1. 先把问题说准确

依据本项目既有审计记录：

| 数据 | 数量 | 当前含义 |
|---|---:|---|
| 有标签源域总量 | 6996 | 并非总共只有5597张标注 |
| 常用训练划分 | 5597 | 实际用于这条训练配方的源域样本 |
| 常用验证划分 | 1399 | 有GT，长期用于开发；不能等同于线上测试域 |
| 半决赛测试包 | 3594 | test1 500 + test2 1300 + 新增1794；不要再把前两轮重复加进去 |

用户在本轮已纠正：测试集是三千多张，不是一千多张。

**5597:3594这个比例本身不能说明模型训练不足。** 固定模型不会因为要预测的图片更多，就把已学能力分摊掉。同分布下增加测试图片主要影响评价统计的稳定程度；若新增图片集中来自不同场景或拍摄条件，分数变化才可能反映覆盖不足、域偏移、类别构成变化等问题。

“没见过”要分清三种情况：

1. 没见过具体照片，但见过相似场景和目标外观：这是正常泛化。
2. 没见过该照片里的拍摄角度、尺度、区域外观或类别组合：这才是需要研究的覆盖缺口。
3. 看过照片并参与伪标签训练，但没见过其真实标签：这已经属于无标签目标域学习，不能说模型完全没见过。

H75相关训练历史已使用过部分前期目标图像；不同后续分支是否使用了完整3594张，需要按其数据清单和有效监督记录判断，不能一概而论。

5597张航拍切片也不必然代表5597个独立场景。相邻/重叠区域可能重复，少数类的有效场景数量可能远低于总图数。相反，像素多也不代表每个像素都是独立训练样本。我们需要衡量的是“每类、每种尺度、每种场景究竟得到多少不同的有效监督”。目前不能仅凭总张数证明数据不足是主要瓶颈。

## 2. 我们对应哪类研究

| 研究设定 | 是否适合当前问题 |
|---|---|
| 半监督语义分割：少量标注+更多无标注图 | 方法有用，但不少论文默认标注/无标注来自相近分布 |
| 无监督域适应UDA：有标签源域+无标签目标域 | 在既有目标图像使用许可范围内，与我们更直接匹配 |
| 域泛化DG：训练时没有目标域图像 | 对未来新批次有意义，但我们已经拿到本轮目标图，不能只按这个设定考虑 |
| 少样本分割/Few-shot | 通常指每类极少支持标注等特定协议；不能因为“只有五千张”就直接套用 |
| 半监督域适应SSDA | 通常额外要求少量目标域真标签；当前没有，不能把相应结果当可直接复用 |

**需要纠正过去过强的判断：同源自训练不等于“绝对没有新信息、必然突破不了教师”。** 无标签图像提供目标域的结构、变化和样本分布；一致性约束、增强和优化可以改善决策。另一方面，无标签图像也不会自动告诉我们农田与荒地的正确语义归属。正确结论是“仍可能获益，但容易受伪标签偏差和有效覆盖限制”，不是已经证明存在不可突破的信息上限。

## 3. 六篇值得参考的近期论文

以下引用仅来自作者论文、官方会议论文库或作者公开稿；不是按会议新旧简单排序。

### A. UniMatch V2：无标签数据怎样提供超出简单复制的训练信号

- 论文：[UniMatch V2: Pushing the Limit of Semi-Supervised Semantic Segmentation](https://arxiv.org/abs/2410.10777)。2024首发，所读修订版为2025-01-09；不是2026新论文。
- 已阅读：方法、互补特征Dropout、骨干比较和扩大训练预算的对照。
- 核心：弱视图教师指导强视图学生，并用互补的特征通道扰动扩展一致性学习；结合DINOv2预训练表征。文中还比较了单纯增加训练预算与改变学习方式。
- 对项目的启发：ROUND2多训不涨，不能推出目标图像无价值；也可能原来的教师、扰动和监督选择没有形成新的有效学习任务。可借鉴“让模型在不同有效视图下仍能识别”，不应只统计多看了多少张。
- 边界：论文主要半监督协议不能保证跨域航拍收益；强增强必须保持标签含义，小车辆不能被裁掉或破坏。我们做过某些增强不等于完整复现该方法，反过来也不能因方法有名就重新堆全部增强。

### B. Rein++：数据有限时，大模型该怎样适配

- 论文：[Rein++: Efficient Generalization and Adaptation for Semantic Segmentation with Vision Foundation Models](https://arxiv.org/abs/2508.01667)。2025-08-03作者公开稿；本次不把它冒称为某个已核实的正式会议论文。
- 已阅读：Rein-G/Rein-A设计及冻结、全量微调、参数高效适配的对照。
- 核心：Rein-G用少量可训练token调整基础模型特征；Rein-A进一步处理无标签目标域。其“不到1%”指骨干适配参数口径，不等于整个分割系统所有训练参数都少于1%。
- 对项目的启发：样本有限时，应同时考虑预训练知识、可训练自由度、解码器和训练方式，不能只按模型总参数判断能否使用。B4/B5那次失败不能否定所有大模型方案。
- 边界：冻结骨干也可能不够适配，少量参数也会过拟合。我们PMT约5370万可训练参数，主要在解码器，不能把“冻结了主干”描述为“只训练了很小的头”。Rein++也不是当前PMT代码已经实现的功能。

### C. BLDA：与我们历史成功机制直接相关

- 正式论文：[Balanced Learning for Domain Adaptive Semantic Segmentation，ICML 2025](https://proceedings.mlr.press/v267/li25cc.html)。[方法全文](https://arxiv.org/html/2512.06886v1)。注意arXiv上传日期晚于会议，不据此改写会议年份。
- 已阅读：类别偏差定义、logits条件分布、在线校正与累计分布辅助学习。
- 核心：分析不同类别的logits分布，在自训练中修正类别偏置，使被压制的类别获得更合理的学习机会。
- 对项目的启发：Bstar和盲类召回已经显示类别决策/监督分配值得重视。值得研究“能否在训练过程中减少这类偏置”，而非默认所有类都从新增图片中均等获益。
- 重要限制：目标域条件分布仍通过伪标签估计，源域GT提供统计锚点。这不是无需假设的目标错误检测器，也不是读一下预测面积就能知道真实先验。不能把BLDA校正与原Bstar直接相加；两者可能重复补偿。迁移需固定对照并区分训练收益与推理校正收益。

### D. Dual-Foundation UDA：DINOv3可以用于辅助训练，而不必立刻替换部署模型

- 论文：[Dual-Foundation Models for Unsupervised Domain Adaptation](https://arxiv.org/abs/2605.03365)。2026-05-05预印本；未核实正式录用信息。
- 已阅读：源/目标自训练、SAM掩码生成、DINOv3原型构建、实验及消融。
- 核心：SAM提供区域结构；DINOv3从源域真标签对应的特征构建固定类别原型，辅助学生特征学习。作者在道路场景UDA基准报告收益。
- 对项目的启发：现有DINOv3权重不一定只能服务于独立PMT分割模型，也可以在训练时提供补充表征，最后仍由B3学生预测。这是与“先把PMT练到超过H75”不同的使用方式。
- 重要限制：原型仍来自源域；SAM本身不提供比赛八类语义。固定原型被作者称为domain-agnostic，不等于已证明对我们的斜视航拍域不变。农田/荒地可能含多种外观，单类均值会掩盖差异；区域传播还可能整片放大错误。论文也不能证明我们的H75与DINO冲突时一定该相信DINO。
- 目前只把它列为有直接机制依据的候选，不把道路基准增益搬成比赛提分承诺。训练辅助模型的许可与单模型推理是两件事，仍以团队已确认的规则范围为准。

### E. HESS：2026年仍在研究“高置信度不等于伪标签正确”

- 正式论文：[From Softmax to Dirichlet: Evidential Learning for Semi-supervised Semantic Segmentation，CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/html/Mai_From_Softmax_to_Dirichlet_Evidential_Learning_for_Semi-supervised_Semantic_Segmentation_CVPR_2026_paper.html)。
- 本次核验范围：官方摘要和论文首页/检索可见内容；未完成代码审查或全面复现评估。
- 核心：显式建模证据和不确定性，改善伪标签筛选，而非只用最大softmax概率。
- 对项目的启发：加过Bstar的概率变化不自动等于更可信；扩大目标图像数量时，要同时记录哪些类别和区域被纳入训练、哪些长期被过滤。
- 边界：它需要相应建模/训练，不能给已有H75概率改个名称就获得可靠不确定性；跨域下仍需检查可靠性与覆盖的取舍。

### F. ExPLoRA：数量最接近，但也提供了一个重要的“不涨分”对照

- 正式论文：[ExPLoRA: Parameter-Efficient Extended Pre-Training to Adapt Vision Transformers under Domain Shifts，ICML 2025](https://proceedings.mlr.press/v267/khanna25a.html)。[作者全文](https://arxiv.org/html/2406.10973v3)，[会议论文PDF](https://raw.githubusercontent.com/mlresearch/v267/main/assets/khanna25a/khanna25a.pdf)。
- 已阅读：方法、SpaceNet实验、数据/计算讨论；核对会议PDF表6结果。
- 核心：在新领域图像上继续自监督预训练，主要用LoRA并解冻少量块，之后做有监督下游适配。它说明无标签图像可通过表征学习利用，不只有语义伪标签一条路。
- 非常贴近的例子：文中SpaceNet-v1建筑分割使用5000张训练、1940张测试。表6里DINOv2+LoRA和ExPLoRA+LoRA均为76.69 mIoU；线性探针为76.21到76.34。**同样比例的数据可以研究和训练，但更多预训练并不必然提高分割分数。**
- 对项目的判断：保留为研究方向，不因为“遥感+小数据”就给它最高比赛优先级。空间尺度、任务、数据总量及训练预算不同，论文不能证明在3594张目标图上短训就能获益。不能将其分类准确率增益当作分割mIoU增益。

## 4. 这些论文要求我们修正哪些判断

1. **不能把平台期直接归因于“测试图片太多”。** 新增目标数据可能是更全面的评估，也可能是可利用的无标签信息，关键在分布与监督质量。
2. **不能用5597张一票否决大型预训练模型。** 应比较相同预算下的预训练、冻结/适配策略、解码器和目标域学习；也不能反过来认定更大的DINO必胜。
3. **不能将同源自训练视为理论上无效。** 现有实测已说明部分同源目标域学习有效；失败的一轮说明那个配方未获益，不是证明整个方向已到上限。
4. **不能把“所有图都进过训练”当作有效覆盖。** 若新场景的关键类别全部被低置信阈值过滤，新增图片可能几乎没有给这些类别提供梯度；相反，无条件放开过滤又会增加错误监督。
5. **我们当前PMT仍是源域监督训练。** 它引入了通用预训练特征，但并没有完成上述目标域适配。2000步源域结果既不是完整路线已成功，也不是所有DINO辅助方式已失败。

## 5. 对项目下一步研究优先级的判断

这次检索后，优先应回答的具体问题是：**新增1794张中哪些场景/类别缺乏源域支持，现有训练又有没有真正学到这些区域？** 它比“总张数够不够”更能区分后续应做什么。

建议形成一张可核查的覆盖表，而不是直接再开一个复杂训练：

| 诊断对象 | 输出 | 能说明什么 / 不能说明什么 |
|---|---|---|
| 源域真实标注 | 每类含类图数、独立场景近似数、连通区域和尺寸分布 | 找到稀少/重复监督；不能据此知道目标GT |
| 旧1800与新增1794 | 图像及区域特征最近邻、距离分布、代表性样例 | 找到与训练差异大的候选区域；距离大不等于预测必错 |
| 当前教师/训练掩码 | 按图组、按伪标签类统计有效像素、实际损失权重、采样次数 | 区分“数据没被使用”和“用了但质量/效果未知” |
| DINO与H75表征 | 源域按场景分组的原型/小头诊断及目标分歧分布 | 初步筛选补充表征；源域成功不证明目标纠错正确 |

实施这些诊断时应尽量复用已有cache/统计，不为同一问题重复跑全部图像。若新增诊断需要GPU，应先报告当前卡使用情况，再启动；本轮未执行。

根据结果选择方向：

- **若问题集中为已知类别被压制、伪标签覆盖不足：** BLDA类的类别平衡与可靠覆盖值得优先研究。它与既往有效机制最接近，但须防止和Bstar重复补偿。
- **若关键目标区域在H75表示中混淆、在独立DINO表示中具有可迁移的区分线索：** 优先研究训练阶段DINO辅助，不要求立刻用PMT替换成熟部署模型。该判断目前尚未由目标真值验证。
- **若主要是增强下不稳定、学习视图不足：** 参考UniMatch V2，改变一致性学习任务而非只加步数。必须考虑小目标和场景语义的保持。
- **若目标域表征本身严重不适配：** 再考虑Rein类适配或ExPLoRA类继续预训练；需要另外估算成本，不能沿用B3二十分钟一轮的耗时。

这不是四条路线一起堆叠，也不是已经确定其中某条能到72。现有资料支持“类别偏置与有效目标监督值得优先研究”，不足以证明某个机制是剩余误差的唯一根因。
