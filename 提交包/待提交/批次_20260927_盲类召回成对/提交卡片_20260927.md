## 预注册决策树（拿到分后判定）

```text
Delta_target    = online(TREAT) - online(CONTROL)
Delta_treat_A05 = online(TREAT) - 70.775011
Delta_ctrl_A05  = online(CONTROL) - 70.775011
```

| 情形 | 判定 |
|---|---|
| 两 delta（target 与 treat_A05）都 ≥ +0.20 | 盲类召回是强新杠杆 |
| TREAT>CONTROL 但 TREAT≤A05 | 正因果无部署收益，关闭本 recipe，保留 A05 |
| TREAT≤CONTROL, CONTROL>A05 | 不支持 target 蒸馏；CONTROL 或是 source-continuation 候选 |
| 两者都 ≤A05 | 保留 A05，关闭 |
| 同分 | target effect=0，关闭 |
