# B4 Capacity Scaling 实验报告

**日期**: 2026-09-27
**状态**: B4 base训练已完成
**GPU**: GPU3 (RTX 4090)

---

## 1. 实验目的

在当前训练数据规模（5597 real-GT + pseudo）下，重新验证 MiT-B4 backbone 是否比 MiT-B3 带来独立的泛化增益。

背景：
- B3 是当前线上最优 backbone（A05_WEIGHT = 70.775011）
- 历史上 B4/B5 未带来满意线上收益，但当时训练数据约5597，现已增加到6296
- 旧 B4/B5 结论不能直接外推到当前数据规模

---

## 2. 实验方案

### 核心原则：最小变化探针
只改 backbone（B3→B4），其余全部继承 B3 最优 recipe。

### 继承自 B3 的配置
| 项目 | 值 |
|---|---|
| 损失 | CrossEntropy, ignore_index=255 |
| 优化器 | AdamW, LR=6e-5, weight_decay=0.01 |
| Scheduler | polynomial decay, power=1.0 |
| 总步数 | 56000 (40 epochs × 1400 steps) |
| Batch | physical=2/GPU, accum=2, effective=4 |
| 分辨率 | 1024 crop |
| Augmentation | HFlip/VFlip/Rot90各0.5 + color jitter(0.5) + rare_crop |
| CWFA | enabled, prob=0.3, epsilon=4.0, start_step=28001 |
| AMP | 开启 |
| seed | 42 |

### B4 特有变化
| 项目 | 值 |
|---|---|
| Backbone | MiT-B4 |
| Pretrained | segformer-b4-ade512（独立加载，不从B3继承） |
| 参数量 | B3约64M → B4约90M |

### 明确不加的
- LLRD (layer-wise LR decay)
- 新 DropPath/stochastic depth
- 改 weight decay
- Prototype / consistency / ETKD
- 改 augmentation 或 loss

## 4. 关键观察

1. **无明显过拟合**：从step 42000到56000稳定在0.813-0.815，终点仅比best低0.0006
2. **Barren仍最弱**（0.623），但相比B3历史值（约0.516）有明显提升
3. **Vehicle显著改善**（0.821 vs B3约0.78）
4. **Vegetation/Water最强**（>0.89）
5. 训练曲线平滑上升，只有一次短暂回落（step 23800）后快速恢复

---

## 5. 当前限制

- **无 matched B3 control**：B3 control（同数据同recipe只换backbone）只跑了60步就停止，未完成完整56000步训练
- 因此无法严格量化 B4 相对 B3 的独立 capacity gain
- B4 base 的线上 test2 成绩尚未验证
