## 2. A05_WEIGHT方案

### 公式
```
theta_A05 = parent + 0.5 * (D1 - parent)
```
- parent = f_s2p100_s3p125.pt (theta278)
- D1 = checkpoint_step2000.pt
- 纯CPU操作，一阶近似：权重空间中点 ≈ logit空间中点
