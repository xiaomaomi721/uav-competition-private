6. PER-IMAGE EXECUTION ORDER
Views: rot0, rot0+mirror, rot90, rot90+mirror, rot180, rot180+mirror, rot270, rot270+mirror.
Read/normalize image on CPU -> input to GPU2.
For EACH view: GPU rotation/flip -> GPU model forward (253) -> GPU inverse flip/rotation (254-257) -> GPU bilinear resize to 1024x1024 (258-260) -> float().cpu().numpy() (261).
After all 8 views are CPU NumPy arrays: combine via np.stack / mean or softmax+mean (72-81, 263-268), argmax and confusion on CPU, append prediction arrays to dataset-wide lists.
Then standard mean logits are computed again in NumPy, converted to fp16 and saved once per image (270-272).
Therefore the path is NOT GPU forward -> inverse -> GPU mean -> one CPU transfer -> disk. There is a GPU-to-CPU transfer per view, and mean aggregation is on CPU.
