# 论文核心机制与公式

日期：2026-10-29。

## 1. Model Soups (ICML 2022)

**公式**：
```
θ_soup = Σ_i w_i θ_i / Σ_i w_i     （逐张量加权平均，w_i 可为均匀或按验证集调）
```
**前提（关键）**：
1. 各 θ_i 必须来自**同一预训练起点**的微调（同一 basin 假设）；
2. 不同超参/数据顺序的微调会产生**不同 basin**，此时平均会变差；
3. 作者报告中，增益主要来自**超参多样性**（不同 lr、不同增强、不同 epoch）。

**本项目的情况（VERIFIED）**：
- 所有候选共享 A05 祖先 → 满足前提 1
- 但**超参多样性极低**：都是同一配方（ACDD）的微调，rel_L2 仅 0.4–0.9%
- 本次实测：CTRL→TREAT 插值单调下降（80.48→79.60），**无内部峰值**
- 历史 soup 全部低于最佳单点

**判读**：本项目的 soup 失败**不是违反 Model Soups 前提**，而是**成员多样性不足**。论文的增益前提（多样性）不满足。

## 2. DAFormer (CVPR 2022)

**公式（核心三项）**：
```
L = L_ce(source, GT) + λ_s * L_ce(target, pseudo) + λ_fd * L_fd(f_student, f_imagenet)
RCS: 图像按 1/freq(class) 采样，使稀有类图被更频繁使用
```
**前提**：需要目标域伪标签；需要 ImageNet 预训练特征可访问。

**本项目（VERIFIED）**：
- RCS：`RareClassCropper(crop_size=1024, ...)` 在 1024 输入下可裁范围为 0 → **退化为整图，从未生效**
- FD：无实现

## 3. DACS (ICCV 2021)

**公式**：对一个 batch 的两张图按类别 mask 拼接
```
x_mix = M ⊙ x_a + (1−M) ⊙ x_b,   M = ∪_{c∈C_sub} mask_c(x_a)
```
**前提**：两张图来自不同域，且混合后伪标签自洽。

**本项目**：无实现。CopyPaste（实例级）是不同机制，线上 −0.311。

## 4. MIC (CVPR 2023)

**公式**：
```
L_mic = CE( S(mask(x_t)),  argmax T(x_t) )   仅在未遮挡区计算
mask: 随机块遮挡（如 64–128px 块，覆盖率 ~70%）
```
**前提**：教师 T 在完整图上产生伪标签；靶域需有足够上下文结构。

**本项目（VERIFIED）**：有真实实现（`a05_micmask_20260927`），训练到 8000 步，修复包工程 PASS，**从未评分**。

## 5. HRDA (ECCV 2022)

**公式（概念）**：
```
从原图裁出小 patch（真实高分辨率细节）→ 缩放到网络输入尺寸
从原图下采样整图（上下文）→ 同一网络
两个尺度的预测用 learned scale attention 融合
```
**前提（决定性）**：**必须存在比网络输入更高的真实分辨率**。

**本项目**：原图就是 1024×1024，网络输入也是 1024。
**→ HRDA 的核心前提在本赛题不成立。**
本次的"512 裁剪 → 上采样 1024"是**伪高分辨率**（512 个真实像素插值成 1024），与 HRDA 本质不同，**其失败不构成对 HRDA 的否定**。

## 6. BBSE / Saerens EM

**公式**：
```
Saerens:  p_t(y) 迭代更新，π^(k+1)_c = π^(k)_c * mean_x[ p^(k)(c|x) ] / p_s(c)
BBSE:     解 C^T π_t = μ_t，C[i,j]=P(pred=i | gt=j) 在源域拟合
```
**前提**：**label shift**（p(x|y) 不变，仅 p(y) 变）。

**本项目（VERIFIED）**：`em_bbse.py` 完整实现，7 种模拟偏移下 BBSE 平均比固定 Bstar 高 +1.3778pp，但 `G-B5_magnitude` 门槛失败。

**关键判断**：本项目 Target 同时存在**更暗更糊**（p(x|y) 也变），所以纯 label-shift 方法只能补一部分。
