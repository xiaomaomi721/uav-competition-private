## 3. 结论

### `FUSION_NO_GO`（针对这对模型）

1. **单调下降，无内部峰值。** 五个点在 80.48 → 79.60 之间近乎线性下降，**不存在"中间的汤比两端都好"的现象**。
2. **没有互补性。** 分歧像素只有 0.38%，且在这些分歧里，两者"一对一错"的互补量（1.489M）虽然占分歧的 94%，但**插值后的模型并没有同时继承两者的正确处**——因为两者在权重空间只差 0.4-0.5%，插值出来的点在功能上就是"中间态"，不是"并集"。
3. **Barren 是唯一有明显梯度的类**（56.96 → 53.17），说明这两个模型的主要差异正是**荒地预测的激进度**，而不是"互补的知识"。

### 结构层面的根本原因

本项目所有候选模型都在同一个**极近的权重邻域**（rel_L2 < 1%）。在这个尺度上：
- 线性插值得到的是"线段上的中间点"
- 不存在"两个不同盆地之间的互补性"
- **因此 model soup / 权重插值在本项目的模型池里天然没有上限空间**

这与此前所有 soup 实验（soup_3way 78.76 < 单点 79.29、soup_4mem 79.19 < 79.29）的结论**完全一致**，现在有了结构解释。

## 4. 对"70.3 与 70.13 是否值得融合"的回答

**即使找到 70.13 的模型，本结论仍然适用**，理由：
- 复赛阶段所有候选（A05 / D1 / theta278 / Arm A / Arm B / C / H75 / BlindRecall pair）都已验证为**同一 A05 祖先 + 仅深层 0.4-0.9% 扰动**
- 在这个邻域内插值必然是"中间态"，不会产生超越两端的协同

**除非 70.13 的模型来自完全不同的训练起点**（例如不同的预训练权重或不同的数据），否则融合不值得投入。

**要确认这一点，需要 70.13 的模型身份——目前 MISSING。**
