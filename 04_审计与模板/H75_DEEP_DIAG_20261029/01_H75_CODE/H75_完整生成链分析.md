```

   （A05 = 0.5*theta278 + 0.5*D1 权重平均）

                              ▼
                    ACDD_V1_ANCHOR = C (71.158317)
                    双教师：Arm B + Mask2Former donor
                    门控 G、软融合 0.75*pB + 0.25*pD、非门控 Anchor
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
             R05             R06             R07      （同配方独立轨迹）
```

## 4. 推理链（VERIFIED，逐项实测）

由 `package_semifinal_bias.py` 源码直接读出：

```
1024×1024 RGB
  → /255 → ImageNet mean/std 标准化
  → D4 八视图：for r in 0..3, for hf in (False,True)：
        正向：先 rot90(r)，再水平 flip
  → 每视图 model(...).logits（native 256×256）
  → 逆变换：先 undo flip，再 rot90(-r)
  → 8 视图 FP32 累加 / 8（不做上采样，全程 native）
  → + Bstar[-0.2, 0.1, 0.0709, 0.4, 3.6, 0.4, 2.1215, -0.5] 恰好一次
  → F.interpolate(bilinear, 1024, align_corners=False)
  → argmax → +1 → uint8 → PIL mode "L"
  → ZIP 根目录平铺
```

**关键确认**：
1. **不使用 autocast**（只有 `torch.inference_mode()`）——这是纯 FP32 路径。任务书中"包括 autocast"的描述与源码不符。
2. **Bstar 在 native 上施加一次**，之后才上采样。因此不能"上采样后再加 bias"。
3. 视图顺序为 `(0,F),(0,T),(1,F),(1,T),(2,F),(2,T),(3,F),(3,T)`，与 `divmod(v,2)` 等价。
