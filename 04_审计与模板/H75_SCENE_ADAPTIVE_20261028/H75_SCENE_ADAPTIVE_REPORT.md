## 5. 假设判定

### 「固定 Bstar 对不同场景并非同样适合」→ **成立（SUPPORTED）**

三条独立证据：
1. **Source1399 场景分析**：Bstar 效应跨场景相差 **2.97pp**；农田 IoU 在 urban 场景 −26.5pp、在 agricultural 场景 −0.9pp
2. **EM/BBSE 模拟**：固定 Bstar 在 5 种分布偏移下退化 2~3pp
3. **Target 子集梯度**：翻转率 5.27% → 5.78% 单调，置信度单调下降

### 「能据此实现一个对 test3 有效的逐场景校正」→ **不成立**

决定性反证：
> **源域上 Bstar 每一类、每一场景都是负贡献（−2.53 ~ −5.50pp），但 test3 线上 Bstar 是 +3.02pp 的正贡献**（Champion 70.998665 vs Zero 67.979564）。

也就是说：**源域告诉我们要"减少/取消"农田与荒地偏置，而 test3 的线上实测告诉我们这些偏置恰恰是对的、且不够。** 任何从 Source1399 推导出的逐场景校正，方向都会**反过来**伤害 test3。

而唯一的替代信息来源——Target 无标签统计——**没有 GT 可验证**，且队友的全局 BBSE 已在自身 `G-B5_magnitude` 门槛上失败。把一个已经失败的方法从"全局"细化成"逐场景"，会引入 3 倍以上的参数，过拟合风险更高，且仍无验证信号。

## 6. 为什么不做"轻量受约束"的最小版本

我认真考虑过三个可行方向，均被否决：

| 候选 | 否决理由 |
|---|---|
| **按 GT 场景类型分配不同 bias** | 场景类型只能从 GT 得知；test3 无 GT，需从预测反推场景 → 自引用，会自我强化 |
| **逐图先验匹配（每图一个 bias）** | 相当于把队友失败的全局 BBSE 扩展到 3594 倍参数，无任何验证信号 |
| **仅调整农田/荒地 bias**（伤害最集中的两维） | 方向由源域决定 = 与 test3 实测相反；且 test3 上荒地/农田正是 Bstar 帮上忙的地方 |

**结论：在当前信息条件下（无 target GT、源域方向已知反转），任何逐场景校正都无法证明其收益，且大概率有害。继续投入 GPU 是浪费。**

## 9. 风险与诚实边界

1. "场景"是**按 GT 类别组成构造的代理**，不是官方场景标签，也不是地理场景；urban/agricultural 的划分边界可被质疑，但主结论（跨场景幅度差 2.97pp）对该边界不敏感——五个组全部为负且跨度大。
2. Source1399 与训练集存在空间重叠，其绝对数值不代表泛化；本报告只用它比较**同一划分下的相对差异**。
3. Target 侧全部是预测统计，**没有任何一行可以当作准确率**。
4. 我**没有**验证"逐场景校正一定无效"——我只验证了"在现有信息条件下无法证明其有效，且已知方向反转"。这两者不同，不应混淆。
