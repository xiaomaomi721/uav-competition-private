### R3. SEMEDA 的 L1 在 **256×256** 上计算 —— 它是粗结构损失，不是边界损失

`src/semeda.py` 逐行：

```python
probabilities = F.softmax(logits.float(), dim=1)
pred_soft = F.interpolate(probabilities, size=(256,256), mode="bilinear")   # ← 这里是 256²
L = CE + 0.5 * L1( encoder.embedding(pred_soft), encoder.embedding(GT_soft) )
# embedding() = conv2(relu(conv1(soft_mask)))   第二层 pre-ReLU，32 通道
```

**1024×1024 图上做 256×256 的嵌入匹配 = 64 倍下采样。**
该损失能"看见"的最细结构是原图 4 px。

**⇒ 把它叫"边界 loss"是错的。它约束的是区域级、低空间频率的结构/类别布局。**
用户 §四 的警告成立，而且这里给出了比形态审计更直接的证据。
**⇒ 也意味着：stage2（中深层、大感受野）正是这类粗结构特征的载体 —— 这为 stage2-only 提供了机制上的合理性。**

## 第二部分：逐条回答那六个问题

### Q1. P1 应该从 θ237 还是 θ209 启动？—— **我判定 θ209，但理由不是"因果干净"**

先纠正我自己的一个误判：`θ237 + λδ` 在 λ=0 时**就是冠军本身**，所以 GPT 的设计并没有丢掉 +0.1483。
候选族在两种 init 下形式相同：

```
两种 init 给出的候选族都是    θ209 + u_old + λδ
（u_old = 0.2189·(Exp47−soupC)|stage2）
⇒ 差别只在于「梯度在哪一点被求值」，不在于代数可组合性。
```

**判定依据只有一条：位移量。**

```
θ237 的 stage2 已经处于「SEMEDA 解」的 2.24% 相对位移处。
从 θ237 续训 SEMEDA loss，损失已经被部分满足 ⇒ 梯度更小 ⇒ δ 更弱。
而我们当前的核心困难就是「效应太小」（最强单步 +0.1483，其余 +0.03 量级）。
```

**⇒ 从 θ209 出发，同样的算力能产出**更大的 δ**，这才是我们缺的。**
**⇒ 而且 θ237 是冻结的、已入账的；任何候选仍可按 `θ237 + λδ` 评估。零成本。**

**同时给出 GPT 那一侧成立的条件**：如果 8k 门发现 δ 的 RMS 已经 ≥ 2×R_old 且 test1 掉，
说明从 θ209 出发的轨迹「路过」θ237 邻域时已是最优点，此时再切回 θ237 续训是合理的第二步。

**⇒ 综合建议：训练 base 用 θ209；评估时两条合成路径都测：**
```
路径 A（重优化）： θ209 + Σα_g d_g^s55b + λδ
路径 B（增量）  ： θ237 + λδ
```
**两者共用同一个 δ，不额外花 GPU。**

### Q2. stage2-only 是否合理？—— **机制上成立，但有一个必须加的对照**

支持：
- R3 证明 SEMEDA 的 L1 在 256² 上算 —— 约束的是低空间频率的粗结构。
  stage2 是 18 个 block、30.18M 参数（63.9%）、感受野最大的编码器级之一，**是粗结构的天然载体**。
- donor gate 的平台证据：同一 donor 只有 stage2 方向给正（+0.1483），
  E −0.0470 / Dp −0.0215 / H +0.0058 / Hbn +0.0176。
- 冻结非 stage2 层**不会切断梯度**（冻结参数照常反向传梯度），梯度路径
  `loss → softmax → logits → decoder → stage2` 完整。

风险（GPT 提到的那条，我认为成立）：
- stage2 独自承担全部输出改变，可能被推向"替冻结层背锅"的位置。
- **加一个几乎零成本的对照**：同时导出**全模型可训练**的同配方短跑（同 LR、同步数、同数据），
  只用于比较 `RMS(δ_full)|stage2` 与 `RMS(δ_stage2)|stage2` 以及两者的 test1 斜率。
  这不需要额外提交位，只需要一次额外的前向（8 分钟 GPU）。

### Q3. LR —— **不该先定 LR，该先定位移预算**

GPT 说 1e-5。我不接受"因为 GPT 说"，也不接受"照抄 Exp47 的 6e-5"。理由是：

**Exp47 的 6e-5 是「从 ADE 预训练 cold start 训 56k 步」的 LR。
我们现在是「从一个已收敛的解出发做有界扰动」，两者不是同一个 regime。**

用 R4 的绝对量级做标定：

```
stage2 的参数 RMS = 0.07280
已知有用的位移：  R_old = 0.001631 （相对 2.24%）
我们想探测的区间： ≈ [0, 3] × R_old  =  [0, 0.0049] （相对 6.7%）
```

**⇒ 建议把目标写成功率门，而不是 LR：**

```
lr = 1e-5, cosine 衰减到 0, 8k 步（不是 56k）
checkpoint: 1k / 2k / 4k / 8k
【位移门】在 2k 处必须满足：
     0.25 ≤ RMS(θ_2k − θ_init)|stage2 / R_old ≤ 1.5
  若 > 1.5：LR 过高，立即停，按比例下调重跑（不消耗提交位）
  若 < 0.25：LR 过低，上调
在 8k 处应落在 [0.5, 3.0] × R_old
```

**理由**：AdamW 的累积位移对"梯度方向是否相干"极度敏感
（相干时 Δ≈lr·N/2 = 0.04，随机游走时 Δ≈lr·√N = 0.0009，差 45 倍）。
**任何纸面 LR 估计都不可靠；唯一可靠的是实测位移并据此调整。**
有了这道门，1e-5 只是起点值，不影响正确性。

**⇒ 额外一条硬性要求（针对 GPT 的 §六）**：冻结不能只靠 `requires_grad=False`。
必须把冻结模块置 `eval()` 并确认训练循环不会写回 `running_mean/running_var`；
`num_batches_tracked` 也应逐位不变。**这条 GPT 提得对，我完全同意，且成本为零。**

那等于把「是否换架构」交给硬币，而不是交给证据。**

**我的替代判据（不依赖绝对分数，依赖斜率）：**

```
STOP / 换架构 的条件改为二选一：
  (a) 任一机制在其 8k checkpoint 的最佳 λ 候选上拿不到 +0.15pp（= 曲线一开始就平）
  (b) 32k 处的斜率 < 8k→32k 区间的一半（= 已经饱和）
只要有一条机制在 8k 就给出 > +0.15pp，且 32k 仍在上升 —— 就继续投，不换架构。
```

**理由**：0.71 的算术是「8 个类各 +0.74 IoU 点」。
历史告诉我们单机制能搬动 0.2–1.3pp，所以**问题从来不是"能不能搬动"，而是"能不能叠起来"**。
决定"叠不叠得起来"的是**方向是否正交**，这与绝对分数阈值无关，必须用 §十四 的重叠度检查来判。

**顺带给出我认为合理的架构切换条件（比 0.7065 更可操作）：**
```
若两条真正独立的新训练方向（例如 v_SEMEDA 与 v_noDecay）都已各自
在 test1 上独立贡献 ≥ +0.10pp，而它们的 stage2 子空间高度重合
（||U_S^T U_N||_F / min(r_S,r_N) > 0.7），说明 B3 的 stage2 只能提供一种能力。
此时才转 B5 —— 因为问题不是"capacity 不够"，是"能力轴只有一根"。
```

## 第四部分：我自己 v2 方案的自我反驳

R2 出来后，我必须下调自己上一版的两条：

- **v2 的 M1（残差定向训练）—— 降级。**
  它训练的是**源域残差**。R2 显示源域拟合与 test1 反相关（r = −0.371）。
  「让模型在源域残差上更用力」在这个背景下先验不利。**除非** 论证是
  "我们要的是误差去相关，不是源域拟合" —— 那就必须先测误差 Jaccard，
  且这是在赌一个未经验证的中间指标。**从 P1 降为观察项，不占训练预算。**

- **v2 的 M2（全模型 SEMEDA 现代配方）—— 被 P1 吸收并改进。**
  P1 的 stage2-only 更省、更可解释、且有位移门控制。

- **v2 唯一保留并强化的**：pseudo-label 之前必须做先验校正（见 §三.C）。
  这条在 v2 里已提出，现在有了 R2 的支撑，**保留为第二枪的前置条件**。
