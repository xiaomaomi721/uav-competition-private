## 第一部分：弱点诊断（全部为本机 CPU 实测，未跑 GPU）

### 1.3 弱点 B：模型高置信度地判错（校准崩溃）

| 置信区间 | 像素数 | 占比 | **准确率** | 误差份额 |
|---|---:|---:|---:|---:|

| 0.50–0.70 | 87.9M | 6.1% | **0.5368** | 27.43% |

| 0.80–0.90 | 76.5M | 5.3% | 0.7031 | 15.30% |
| 0.90–0.95 | 67.2M | 4.7% | 0.7741 | 10.23% |
| 0.95–0.99 | 135.2M | 9.4% | 0.8522 | 13.46% |
| **0.99–1.00** | **1013.9M** | **70.2%** | **0.9768** | 15.82% |

```
84.2% 的像素落在 conf>0.9；这 84.2% 贡献了 39.5% 的误差
误差 margin (logit[pred] − logit[TRUE]):  40.3% < 1.0 ；58.1% < 2.0
```

**读法**：真正的"逐像素歧义"会让模型落在 0.5–0.7 档。而这里
**58.9% 的背景错误里有相当一部分是 p>0.9 的决定性错误信念**。
⇒ **更像系统性偏差，不像不可约噪声。** 这是本方案选择"强攻"而非"收口"的唯一理由。

### 1.4 弱点 C：b\* 用 8 个自由参数去补模型的系统性缺陷

```
冠军 ZERO（无 bias）  val mIoU 0.7996
冠军 BSTAR           val mIoU 0.7816      净损失 −0.0180

逐类损失： Barren −0.0920 ｜ Background −0.0273 ｜ Agricultural −0.0245
           Vegetation −0.0035 ｜ Road −0.0016 ｜ Building −0.0014 ｜ Vehicle +0.0071
```

b* 的向量：`[−0.2, 0.1, 0.0709, 0.4, 3.6, 0.4, 2.1215, −0.5]`
—— **Barren +3.6、Agricultural +2.1215** 是量级极大的单类偏移。

**它是在 soupC（0.696865）时代标定的，此后再没在冠军上重标过。
而每一次 merge 都是在 b\* 固定的条件下评分的。**
⇒ **所有 merge 的 Δ 都混杂了"b\* 与新 θ 的失配"这个未受控项。**

## 第二部分：病理结论

```
冠军的 0.7026 = 一个用平台标量 oracle、在参数空间里挪了 250 次的结果。

它的 59% 误差是"背景整片漏成农田/植被/建筑"，而且是高置信度、大连通域的错。
现有三件工具都够不到这块：
   参数合并  → 所有成员犯同样的错（83–91% 重叠）
   b*(8维)   → 只能整体挪一个类的先验，而错误是区域级、逐图不同的
   继续 α    → 分布根本不跟随，边际 +0.017
```

**一句话：冠军的强来自"事后适配"，而剩下的缺口全部在"模型本身对灰色团的系统性误判"上 ——
必须换一种把监督信号送进模型的方式。**

## 第三部分：补偿方案

### 方法 M1（主攻）· 残差定向成员 —— "boosted member"

**靶向弱点 E（共享误差）**

```
1. 冠军 θ* 在官方训练集上跑单视图前向 → 残差图 R = 1[pred ≠ GT]
   同时记录每像素置信度 c 与 margin m
   （6996 张 × 1 次前向 ≈ 25 min GPU2）
2. 权重图： w = 1 + λ · R · 1[ c ≥ τ ]
   τ 预注册 0.90（只加权"高置信度的错"；低置信度的错不动，那些是歧义）
   λ 预注册 2.0（权重比 3:1）
3. 从 ADE 预训练 B3 全新 init，用 s58 配方训 56000 步，损失 = 加权 CE
4. 产出 θ_res；方向 d_res = θ_res − soupC
```

**为什么这不是项目里已经失败的 weighted-CE（历史 −0.049）**：
那次用的是**类频率**权重（与模型无关）；这里是**模型特定、像素级、经置信度门控的残差权重**。
这是梯度提升的思想搬到分割上：拟合当前模型的残差。

**可直接测的中间指标（不用提交）**：
```
J(θ_res, θ*) = 两者在 val 上错误集的 Jaccard
现状 83–91%  →  若 θ_res 降到 < 70%，说明方向确实去相关了，值得并入
若仍 ≥ 85%，说明残差权重没起作用，本臂关闭
```
**这一条让 M1 在花提交位之前就能被证伪。**

### 方法 M2（主攻）· 结构正则成员 —— SEMEDA 的现代用法

**靶向弱点 A（区域级灰色团误判）**

```
配方 = s58 配方 + SEMEDA loss
       (embedding_weight 0.5, feature_size 256, gt_noise_sigma 0.1,
        edge_encoder = /home/jhy/models/semeda_edge_s01.pt, 冻结)
       CWFA 打开（历史 Exp47 是关的 —— 这正是本次要测的）
```

**依据（四条，互相独立）**：
1. 历史上唯一一个 >1pp 的训练期方法（test1 +1.056pp）
2. 它的增益**只在 test1 出现**（local val −0.096pp）⇒ 它作用在**跨域不变的结构**上
3. 它的误差行为是"减少正类误入背景、新增背景误报正类"（取证报告 §5）——
   **正好作用在"背景 vs 前景"这个界面上**，与本诊断的弱点 A 完全重合
4. donor gate 里它的 **stage2 方向 +0.1483**，是次高值（+0.0414）的 **3.6 倍**；
   而它**从未被做过分层处理**（三个 composite 的剖面都是从 s55b 搬来的）

**风险**：方法叠进同一模型历史上有互毁（CWFA+no-decay −0.54）。
SEMEDA 是 loss 不是增广，可能更好叠，但**未经验证**。
⇒ **M2 的第一次训练就是在这个风险上下注；用 gate 控制。**

### 方法 M3（方法学修正，必做，成本极低）· 标定与权重解耦

**靶向弱点 C 与 D**

```
现状：θ 搜索时 b 固定；b 是在旧 θ 上定的 ⇒ 测到的是 (θ, b) 的混杂物
改为：
  (a) 每个新候选，在 b 的一个小邻域内评估 2–3 个变体，取最好
      （纯 CPU：冠军的 test1 logits 重算一次后，改 b 是零成本的）
  (b) b 必须有约束起点：用有原则的先验修正给出
      （从模型自身的 test1 预测分布 + val 混淆矩阵，做 EM/BBSE 式 test-prior 估计），
      只允许在起点附近小范围偏离
      ⇒ 防止 8 个自由参数继续过拟合 500 张 oracle
```

**依据**：D 证明**分布由 b 控制**（layer-wise 挪不动分布），
C 证明**当前 b 在源域净损 1.8 分**。
两者相加 ⇒ b 是当前最大的未受控变量。

### 方法 M4（顺序修正）· 测试域自训练 —— 必须排在 M3 之后

**这是本项目历史上最被验证过的方向**（s55b 用弱 teacher 的伪标签贡献了 +0.1776）。
但**必须排在 M3 之后**，理由：

```
若教师的 test1 输出带着先验偏差（冠军的 Agricultural 比独立估计高 ~2.5pp、
Background 低 ~4.6pp），那么硬 argmax 伪标签会把这套偏差**刻进新模型的权重**。
s55b/KD_Run1 都是在 b 失配的状态下做的伪标签 ⇒ 这是它们可能被低估的原因。
```

**三个相对历史版本的升级**：
```
(a) 伪标签生成前，先做 M3 的无偏先验校正
(b) 用软标签（KD，官方模板）而不是硬 argmax
(c) 用全部 6996 官方训练图（不再留 1399 做那个已被多次证伪的 val）
```

### 顺带必做（零风险，纯收益）

- **不再保留 1399 张 val 作决策用。** 历史证据：val 0.8182 → online 66.61；
  affine val +0.37 → test1 −0.029；SEMEDA val −0.096 → test1 +1.056。
  它只做诊断，不做选择。训练用全部 6996。
- **每个新候选都记录 test1 预测类分布**（纯本地，零成本），作为"是否只是在挪先验"的监视器。

## 第四部分：预注册与停止条件

| 项 | 冻结值 |
|---|---|
| init/base | `published_pretrained` nvidia/segformer-b3-ade512 |
| 数据 | 官方 6996（全部）；M4 额外加 test1 官方 500 伪标签 |
| loss/recipe | 逐字复制 s58（CWFA + regionC）；M2 仅加 SEMEDA 项 |
| 优化器 | AdamW 6e-5 / wd 0.01 / polynomial / batch 2×accum2 / amp / seed 42 |
| 步数 | 56000 |
| checkpoint gate | **不用 local val 选点**；取 last 与 best 都导出，后续用可观测中间指标筛 |
| merge 方式 | soupC 中心 + 分层 α；每个新成员 ≤6 个包 |
| 提交预算 | ≤40 位（M1 6 + M2 6 + M3 8 + M4 6 + 余量 14） |

**硬停止条件**
```
M1: 若 J(θ_res, θ*) ≥ 85%  → 关闭，不消耗提交位
M2: 若训练后 val 上"背景漏出"的像素数没有下降 ≥10% → 关闭
M3: 只扫一轮，不迭代
M4: 只在 M3 完成后启动
全局: 若 M1+M2 合计增益 < +0.10pp → 判定参数/训练两侧均已饱和，
      停止进攻，转入"保住可复现的 0.7026"
```

## 第五部分：诚实预期

```
M1 残差定向        +0.05 ~ +0.25pp   p≈40%
M2 结构正则成员    +0.10 ~ +0.30pp   p≈50%
M3 标定解耦        +0.00 ~ +0.15pp   p≈45%
M4 修正版自训练    +0.10 ~ +0.30pp   p≈45%

乐观可加 +0.25 ~ +1.00pp
```

**P(达到 0.710) ≈ 15–25%（较 v1 下调）。**

下调理由：弱点 A 的 59% 误差里，按项目自己的诊断（"灰色团视觉不可分，RGB 距离 3~15"、
"标注含糊 + 先验错配"）**存在不可约成分**。本方案把赌注压在
"高置信度 + 大连通域"这两个特征上，判定它是**可约的系统性偏差**而非噪声。
**这个判断若错，全部四臂的上限都会显著降低。**

**什么会证伪这个判断（早期信号）**
```
M2 训练后，val 上 Background 的 FN 像素（现状 87.4M）若下降 < 10%
   ⇒ 灰色团误判不是可训练偏差，方案应转向"收口 + 保可复现"
M1 的 J(θ_res, θ*) ≥ 85%
   ⇒ 残差不可定向，共享误差是结构性的
```
