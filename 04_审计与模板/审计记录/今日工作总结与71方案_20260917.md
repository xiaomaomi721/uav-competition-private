## 1.2 关键认知：最好的模型不是任何单体模型

**今天的核心发现**：

```
θ = θ_C + Σ_g α_g · d_g

θ_C = (s58 + s64) / 2        等权 soup 中心
d   = s55b − θ_C             参数空间中的方向
α_g                          每个网络分组的独立系数
g ∈ {stage0, stage1, stage2, stage3, head}
```

**为什么有效**：5 个 soup 成员来自 **5 条不同的训练配方**：

| 成员 | 配方 |
|---|---|
| s58 | CWFA + regionC |
| s64 | CWFA + weight_decay 0.0005 |
| s55b | CWFA + pseudo500 |
| s62 | resume55b + pseudo500 |
| Stage23B | CWFA + CE formal |

**它们的参数差异 = 参数空间里可用的方向。**

# 第二部分：0.71 方案

## 2.1 缺口分析

```
0.701091 → 0.710000    差 +0.8909pp
```

**今天参数搜索的边际收益在快速衰减**：

```
+0.3769 → +0.1776 → +0.1088 → +0.0752 → +0.0172 → 饱和
```

**外推：参数搜索的天花板约 0.7015–0.7030。**

**⇒ 0.71 必须来自训练，不可能来自继续搜参数。**

## 2.2 训练路线的承重假设

**今天证明的第一原理**：

> **增益来自"参数空间中的新方向"，而方向来自"不同的训练配方"。**

**推论（待验证）**：

> 引入一条**从未用过的配方**训出的新成员，会为参数空间增加一个新方向；若该方向与现有方向互补，则合并后分数上升。

**支持证据**：
- s62（配方：resume55b+pseudo500）贡献 +0.1453pp，尽管它自己 R 最弱
- 5 个成员 = 5 条配方，**没有两条配方相同**

**反证 / 风险**：
- **误差重叠分析**显示现有模型**错误高度共享**（83–91%）→ 新配方可能也落在同一个瓶颈里
- 官方 Swin-L M2F 在同赛道只有 0.6723，**低于我们 B3** → 容量不是自动解

## 2.4 训练目标的建议（关键）

**传统目标**：`max_θ S(θ)` —— 训一个自己分高的模型。

**今天的数据说这个目标可能不对**：

```
s62 自己 ZERO 0.680973（中游）、R 0.5637（最弱）
但混入 10% 给 +0.1453pp
```

**建议目标**：

```
max_θ  S( (1−α)·θ_champ + α·θ )
```

**即：训练时就以"混入冠军后的增益"为监控指标，而不是它自己的 mIoU。**

**实现**：每 N 步取 checkpoint，做一次快速 merge + TTA8，记录 `(α, 增量)` 曲线。**这直接复用今天已经跑通的流水线。**
