## 一、最重要的结论：盘不是被你的文件撑满的

```
/dev/sda4   3.5T   3.3T used   5.8G avail   100%   /
```

- `du -x /` **只能统计到 254G**，而 `df` 报 `used = 3.23T`。
- 差额来自 `du` 的 **6472 条 `Permission denied`**：`/home` 下 `cmq / daiqun / huao / hwh /
  junyao / liudun / ljh / u42411035 / ubuntu / wenliangjian / zjt` 等 **13 个他人目录无法读取**。
- `/home/jhy` 实际占用 **209G**。

→ **你自己的全部文件加起来才 209G，约占整盘的 6%。剩下约 3TB 在其他用户目录里。**
→ 清你的目录能让"你自己"腾出空间，但**不会改变机器整体爆满的根因**，也无法让队友免于受影响。
→ 这件事需要让队友/管理员一起看，不是单靠清 `/home/jhy` 能解决的。

另外确认：`/ssd` 1.8T/3.5T（55%），`/hdd` 完全空闲（7.3T 用了 28K）——**有空余盘可用**。
`/var/lib/docker` 对你是 Permission denied，且不属于你的空间。
