### 与 M2F56 Stage 1 的关系

`ms_scan.py` 与我的 `pack_multiscale_v1.py` **定义同构**：真实输入尺度 → `forward_views`
(D4) → FP32 均值 → 1024 坐标系融合 → ZERO → argmax。

**唯一差异（滤波实现）**：
- `ms_scan.py`：`normalize_to_tensor` → `F.interpolate(antialias=True)` → `normalize` 之后的张量
- 我的版本：PIL `Image.resize(BILINEAR)` RGB → `normalize_to_tensor`

归一化是仿射变换、插值是线性算子，**两者数学上近似等价**，差别只在滤波核。
这个差异不足以预期结论反转。

**因此 M2F56 多尺度属于"已被证伪方向的重跑"，不是新信息。** 有价值的例外只有一个：
M2F 是**不同架构**，其 resolution 敏感性可能与 SegFormer 不同 —— 但期望值应显著调低。

## 四、官方 Mask2Former 与我们的实现差异

读 `py/b3_m2f_head/head.py`（241 行）逐项对比：

| 官方组件 | 我们的实现 | 差异性质 |
|---|---|---|
| Masked attention | `build_attention_mask`：sigmoid<0.5 阻断 + nan_guard | ✅ 有，且与官方思路一致 |
| Query refinement | 6 层 `QueryDecoderLayer`，self-attn + masked cross-attn + FFN | ✅ 有 |
| class + mask 双头 | `class_embed` (C+1) + `mask_embed` → `einsum("qbd,bdhw->bqhw")` | ✅ 有 |
| no-object 通道 | C+1，`semantic_scores` 归一到前 C 个 | ✅ 有 |
| 逐层 deep supervision | `forward()` 返回 `aux_outputs = outputs[:-1]` | ✅ **已有** |
| **多尺度 pixel decoder** | `SimplePixelDecoder`：**纯 FPN**（lateral 1x1 + 平滑 3x3 + 双线性上采样），`levels=[p2,p3,p4]`，无 deformable attention | ⚠️ **这是最大简化项** |
| **Point sampling** | 未见独立实现（`ignore` 排除在 matching/point sampling/BCE/Dice 之外） | ⚠️ **需查训练脚本确认是否为 uncertainty-driven** |

**结论**：文档里"decoder deep supervision 可能缺失"的说法**不成立**，它已经实现了。
真正确认的缺口排序：
1. **多尺度 pixel decoder**（MSDeformAttn，官方替换 FPN 的核心）
2. **uncertainty point sampling**（需进一步确认训练侧实现）

**但必须指出**：历史上「改解码器」已经吃过一次亏 —— 台账 4.1：B3 + 注意力融合头 = 65.979，
**−0.760**。所以补 pixel decoder 属于结构性改动，风险不低，应排在 TTA/8D/长训之后。
