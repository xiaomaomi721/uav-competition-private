**损失实现的两个不变式（都已满足）**

```
INVARIANT 1: 缓存 q 已是 softmax(ens/T) → 训练用 log_q = log(q.clamp_min(1e-12))
             ，不得二次 softmax。
             现跑验证：ref 2.55744219 vs actual 2.55744195，diff 2.4e-07；
             且 softmax(cache) 与 cache 差 0.685（证明二次 softmax 会显著改变目标）

INVARIANT 2: CE 与 KD 必须除以同一个 accum
             total = ce + λ·kd ;  scaler.scale(total / accum).backward()
             —— 注释原文即记录"只除一个会静默把 λ 缩放 accum 倍"
```

⇒ **「KD 未除以 accum、每个 update 累计 2 次 KD」是修 bug 之前的状态，已被 INVARIANT 2 修掉。**
当前代码中 CE 与 KD **对称**，不存在偏高的 target exposure。

## 二、`kd_every` 的结论：**2**（时间线证明）

### 2.1 GPT 引用的证据是真实的，但属于被取代的那一次

```
_kd_restart.sh   14:43:50   KD_EVERY=1 bash _kd_launch.sh   ← 旧
_kd_launch.sh    15:06:32   KD_EVERY=${KD_EVERY:-2}        ← 之后被改成默认 2
_kd_train.py     15:08:48   最终版（两处 INVARIANT 注释）
KD_META.json     15:08:54   ★ 训练启动，文件内记录 kd_every = 2
```

`_kd_restart.sh` 的用途是"停掉旧 trainer、用**修正后的损失**重启"，
并会 `rm -rf "$R/$RUN"` 清掉旧产物。**它写于 14:43，早于 `_kd_launch.sh` 的 15:06 修改**，
即它调用的仍是当时还是默认 2 的 launch——而 launch 后来被改为显式默认 2。
**真正的最终一次启动由 15:08:54 的 KD_META 记录，其值 = 2。**

### 2.2 时间戳算术（决定性）

```
15:08:54  +  3200 步 × 1.85 s/step = 5920 s = 98.7 分钟  =  16:47:36
实际 checkpoint_step3200.pt 落盘时间                      =  16:47:59
                                                            差 23 秒 ✓

若这四个 checkpoint 来自 14:43 启动的那次：
14:43:50  +  98.7 分钟  =  16:22:32   →  比实际早 26 分钟 ✗
```

**四个平台 checkpoint 只能来自 15:08:54 启动的那次，即 `kd_every = 2`。**

### 2.3 一条纪律（这次的教训）

`_kd_restart.sh` 这种**残留的旧启动脚本**会误导身份认定。
判定"实际配方"必须以 **①KD_META 时间戳与 checkpoint 时间戳的算术一致性** +
**②launch 脚本的最终修改时间** 为准，**不能只看任一份脚本里的字面参数**。

## 四、梯度比 `0.4071` 的确切定义

`_kd_train.py:376-405` 的实现：对 CE 与 KD **各做一次独立 backward**，
每次前后 `model.zero_grad(set_to_none=True)`，用**各一次 `next(iter(loader))` 的单批**。

| 性质 | 值 |
|---|---|
| 范围 | **单批、单次 forward，pre-accumulation** |
| 时机 | 训练**开始前**一次性诊断 |
| 是否含 accum 聚合 | **否** |
| 是否含 `clip_grad_norm_(1.0)` | **否**（裁剪在 optimizer step 前，诊断里没有） |

**因此只能说：设计前比值 λ·‖g_KD‖/‖g_CE‖ ≈ 0.4071（单批，pre-clip）。**

由于 INVARIANT 2 中 CE 与 KD **同除 accum**，该比值在聚合后**设计上保持不变**；
但 `clip_grad_norm_(1.0)` 是按**聚合后总梯度**统一缩放的，对两项同比缩放，比值仍近似保持。
**真正的"完整 update 有效 KD 强度"历史上从未测量 → 记为 UNKNOWN，不得用 0.4071 顶替。**

**实操**：本方案的 smoke 里**补测一次完整 update 的比值**（一个 optimizer step 内分别累计
CE 与 KD 梯度再取范数比），作为干净实现的绑定证据。这是**一次初始化尺度绑定，不是 λ sweep**。

## 五、算术：三个假设必须分开

已知：KD 的 fixed-C 平台分，相对 s62+C 的**总 final 增量** = `0.692202 − 0.686610 = +0.5592pp`。
KD6400 的**绝对 R_C** = `1.1600pp`。三教师集成的 **R_C** = `1.2400pp`。

| 假设 | 算式 | 结果 | 与记录 0.693096 |
|---|---|---:|---|
| **A. 历史总 final 增量 100% 迁移** | `0.691330 + 0.005592` | **0.696922** | 破 +0.3826pp |
| **B. KD6400 绝对 R_C 直接搬** | `0.683042 + 0.011600` | **0.694642** | 破 +0.1546pp |
| **C. 恢复到三教师集成 R_C** | `0.683042 + 0.012400` | **0.695442** | 破 +0.2346pp |

**A 最乐观，B 最保守；三者都破记录。** v1 里那句 `0.683042 + 0.5592pp = 0.6966` **作废**
（把"绝对 R_C"和"总增量"两种量纲混在了一起）。

### 5.4 `0.695637` 的正确定性 —— 融合函数**已核实同一**

`_kd_precompute_teachers.py` 头部原文：
> "TTA8: the same 4-rotation x {plain, mirror} D4 protocol used by the **30.zip raw
> ensemble**, so the target **reproduces the combination logic that scored 0.683237**"

逐项核对：

| 环节 | KD teacher cache | 30/43 号集成 |
|---|---|---|
| 每教师 D4 顺序 | `[(k, hf) for k in range(4) for hf in (False,True)]` | 同 |
| 教师内融合 | `views.mean(dim=0, fp32)` on **raw logits** | 同 |
| 教师间融合 | raw logits **等权平均** | 同 |
| softmax 位置 | 仅在构造 KD target 时 `softmax(ens/T)` | 不 softmax |
| C 施加空间 | ZERO（无） | **raw logit 空间**加 CHAMPION |

⇒ **同一个组合函数。** 因此 `0.683237 / 0.695637` 就是该 teacher 函数的线上分，
**可直接与 KD target 比较**。

**但仍不是"上界"**：它是**同教师组三模型输出融合的线上参考点**，
证明 `Z≈0.6832` 与 `R_C≈1.24pp` 在多模型函数里可以共存；
**不证明单个 B3 一定能同时表示这两者**，也不是 student 的数学上界。

### 6.5 Gate

历史边际：KD 3200→6400 的 fixed-C 只再涨 `0.692202 − 0.691925 = **+0.0277pp**`。

| gate | 条件 | 性质 | 动作 |
|---|---|---|---|
| **G1** | `best final ≥ 0.693096` | 破记录 | 续 6400 |
| **G2** | `best final ≥ 0.692819` | **严格由历史边际推出**（0.693096 − 0.0277） | 续 6400 |
| **G3** | `Z ≥ 0.6825` 且 `R_C ≥ 1.00` | **mechanism-positive discretionary**（非边际保证） | **允许一次**续 6400 |
| **G4** | 其余 | — | **停，路线降级，不换配方连试** |

**G3 如实说明**：其最低 final = 0.6825 + 1.00 = **0.6925**，
即便机械复制历史 +0.0277pp 也只有 **0.692777 < 0.693096**。
它是"机制看起来对、值得再赌一档"的**探索性** gate，**不是**由历史边际推出的。

## 七、本路线**未被证明**的东西

1. **无可加性证据**。「平均抬 Z + KD 抬 R_C → 串联」是**待测假设**。
2. **KD 续训不抬 Z**：KD Run1 的 Z 轨迹 0.6815 / 0.6778 / 0.6806 / 0.6782
   （init 0.680973），**均值低于 init 0.15pp**。soupB 的 0.683042 能保多少是未知。
3. **教师集与 soupB 成员重叠 2/4**。
4. **本地完全看不见**：KD 使本地 0.810394 → 0.809968（−0.043pp），平台 fixed-C **+0.53pp**。
   ⇒ **全程不得用本地 mIoU 做任何中途判断。**
