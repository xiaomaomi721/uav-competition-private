**剩余 0.74pp 不在参数算术里，也不在标定里，而在"把测试域信息注入参数空间"。
而项目历史上唯一一次 >1pp 的单方法效应（SEMEDA +1.056）恰好就是这一类。
所以方案的重心是：先把 SEMEDA 效应归因清楚，再用它 + 冠军教师自训练，制造 2–3 条全新方向并入参数空间。**

## 1. 方案依据的硬事实（均已核实）

### 1.1 规则边界（官方答疑 2026-09-15，权威）

> **禁令只作用于推理/提交阶段，不作用于训练阶段。**
> 推理/提交只能输出**单个模型权重**，禁止多模型集成推理提交；
> **训练阶段可以任意使用多模型、蒸馏、伪标签等技术。**

官方明确列为 ✅ 合规的模板：
- **流程A**：模型A训练 → 给测试集生成伪标签 → 用伪标签训练模型B → **最终只提交 B**
- **分段策略**：前段真实标注训练，后段加入测试集伪标签继续训练同一模型
- **双 Teacher KD**：Teacher A（仅训练集）+ Teacher B（训练集+test1 高置信伪标签），
  Student 用 test1 原图 + 双 teacher 软概率蒸馏，**只提交 Student**

伪标签仅限官方图片（test1 的 500 张属于官方图片 ✅）。
官方工程经验原话：**"直接无脑使用全部测试集伪标签效果一般；必须增加置信度筛选策略。"**

**⇒ 输出侧仍必须是单权重；训练侧几乎无限制。这决定了方案形态：所有新方向最后必须并进一个 checkpoint。**

### 1.2 当前冠军的确切构造

```
θ* = soupC + Σ_g α_g · (s55b − soupC)|_g  +  β · (Exp47 − soupC)|_stage2
soupC = (s58 + s64)/2
α = {stage0: 0.5, stage1: 0.5, stage2: 0.2, stage3: −0.1, head: 0.0}
β = 0.2188631149   （由 RMS 匹配到 s55b 方向 α=0.2 的扰动幅度，不是扫出来的）
g ∈ {segformer.stages.0..3, decode_head}
```

### 1.3 参数合并的实测形状（全部 test1 平台分）

```
0.693096  起点

0.698641  + s55b 全局 α=0.20                       +0.1776

0.702574  + β·SEMEDA|stage2                        +0.1483   ← 本战役第二大单步
```

**两条读法：**

- **递减**：+0.3769 → +0.1776 → +0.1088 → +0.0752 → +0.0172，前四个都来自同一类操作（同一个 s55b 方向上的 α 微调），确实在饱和。
- **但 +0.1483 是"换了一条来源完全不同的方向"之后的跳变。** 它打断了递减。
  ⇒ **饱和的是"同一条方向的继续微调"，不是"引入新方向"。**

### 1.4 同一个方向，值不值得"分层处理"差别很大（最重要的一条）

```
s55b 方向：全局单一 α=0.20   → 0.698641   (+0.1776)
s55b 方向：分层 α 剖面       → 0.701091   (+0.3130)   ← 净增 +0.1354pp
```

**⇒ 一条方向被"认真对待"（逐层给独立系数）与"粗暴对待"（全局同一个 α），
在本项目实测差 +0.135pp。**

### 1.5 SEMEDA 这条方向**从未被认真对待过**

donor gate 对 SEMEDA 只做了两件事：

1. **6 个单组探针**（H / Hbn / Dp / Dm / M / E），尺度由 RMS 匹配约定确定（β 非搜索得来）
2. **3 个 composite**，但其剖面形状（P1champ / P3half / P2unif）是**从 s55b 的最优剖面搬过来的**

实测结果：

```
S_semeda_M   (stage2 单组)  0.702574   +0.1483   ★ 最高
C_semeda_P1champ (全幅)     0.702236   +0.1145
C_semeda_P3half  (半幅)     0.702065   +0.0974
C_semeda_P2unif  (均匀)     0.701856   +0.0765
S_semeda_E   (stage0∪1)     0.700621   −0.0470
S_semeda_Hbn (head+BN)      0.701267   +0.0176
S_semeda_H   (head)         0.701149   +0.0058
S_semeda_Dm  (stage3−)      0.701039   −0.0052
S_semeda_Dp  (stage3+)      0.700876   −0.0215
```

**关键推断（不是事实，是被数据强烈提示的假设）：**
**单组 M 打败了全部三个 composite** ⇒ s55b 搬过来的三个剖面形状**对 SEMEDA 是错的**。
SEMEDA 方向的最优剖面**从未被搜索过**。

### 1.6 SEMEDA 的历史效应是"只在测试域出现"的

```
Exp47 (CE + SEMEDA λ0.5)   本地 val 0.809569    test1 单视图 67.796
Exp18 (CE / rare_crop)     本地 val 0.810525    test1 单视图 66.739544
```

**本地 val 说它略差，test1 说它好 +1.06pp。**

> "source-val 上 SEMEDA 不优于 CWFA; online 上 Exp47 标准 +1.056 但**此增益无法在 source-val 复现**

**一个只改变损失函数的干预，产生了 1.15pp 的 val↔test1 背离。**
这是本项目全部历史记录里最大的一次背离，也是唯一一次"训练期方法拿到 >1pp"。

## 2. 对 0.74pp 缺口的结构判断

已知：**任何单一操作的历史最大单步 = +0.377，第二大 = +0.148。**
要拿 0.74pp，只能靠**多次"新方向级"的跳变**，不能靠同一条方向的微调外推。

新方向从哪来？历史证据指向两条：

- **来自不同训练配方**（s62 自己 R_C 最弱 0.5637，做方向却给 +0.1453 —— 成员自身质量不预测方向价值）
- **来自测试域信息**（law 1.7；SEMEDA 的 val↔test 背离就是最纯的例证）

⇒ **方案 = 制造 2–3 条新方向，其中至少一条携带测试域信息。**

## 3. 方案

### Arm 0 · 归因诊断（**先做，约 1 小时 GPU，8 个包**）

目的：**在花 5 小时训练之前，先确定"stage2 那个 +0.1483 到底是什么"**，并给 SEMEDA 方向做它从未得到过的分层处理。

#### 0a. stage2 归因探针（3 个包）

同一个 β 约定（RMS 匹配到 s55b α=0.2），只换 donor：

| 探针 | donor | 含义 |
|---|---|---|
| A | `stage47` (CE+SEMEDA) | **已知 = +0.1483**（对照锚点） |
| B | `stage18` (CE / rare_crop, 纯基线) | 测试"是否只是把 stage2 拉回朴素 CE 解" |
| C | `stage23` (CE+CWFA, 我们自己的血缘) | 测试"是否是血缘相近的弱正则版本" |
| D | `models/segformer-b3-ade512`（**从未训过 UAV 的原始 ADE 权重**） | **距离控制**：是否任何"远距离 stage2"都有效 |

**判读（预先写死）：**
- 若 **只有 A 正、B/C/D 全负** ⇒ 效应是 SEMEDA 特异的 ⇒ **Arm 2 值得做**
- 若 **B/C/D 也显著正** ⇒ 效应是"stage2 被拉离当前解"的通用效应，与 SEMEDA 无关
  ⇒ **不做 5h SEMEDA 训练**，改为沿"把 stage2 往 ADE 方向拉多少"这条轴做有界扫描
- 若 **D 正得最多** ⇒ 冠军的 stage2 过拟合了，方案重心改为"stage2 正则化"

**这一项是本次提案里信息量/成本比最高的动作。** 4 个 checkpoint 全部已在服务器上。

#### 0b. SEMEDA 方向的第一次分层处理（≤5 个包）

把 s55b 上验证过的分层协议**第一次用在 SEMEDA 方向上**：

```
SEMEDA 方向 d_S = Exp47 − soupC   （全 key）
θ = soupC + Σ_g α_g · d_S|_g + （其余保持冠军的 s55b 分层结构）

候选剖面（预注册，不再扩）：
  S1  (0.5, 0.5, 0.2, −0.1, 0.0)   冠军 s55b 剖面搬到 SEMEDA
  S2  (0.8, 0.8, 0.2, −0.1, 0.0)   s62 上获胜的形状
  S3  (0.0, 0.0, 0.2,  0.0, 0.0)   等价于已知的 S_semeda_M（β 归一后）
  S4  (0.5, 0.5, 0.5, −0.1, 0.0)   加大 stage2 权重
  S5  (0.5, 0.5, 0.2, −0.1, 0.1)   同时补 head
```

**硬停止条件：只做这一轮，无论结果如何都不开第二轮。**

**Arm 0 合计：8 个包，约 1 小时 GPU（每个包 TTA8 约 8 分钟）。**
**若 Arm 0 出现 > +0.20pp 的单包 → 立即暂停后续，先把这个点做出来。**

### Arm 1 · 冠军教师自训练成员（**主攻，5 小时 GPU**）

这是唯一一个**直接把测试域分布注入参数**的动作，也是官方明确背书的流程A。

```
Teacher   = θ*  （当前冠军 0.702574 的真实单权重 checkpoint）
Pseudo    = θ* 对 test1 官方 500 张的 TTA8 预测（复用已验证推理路径，约 200s）
筛选      = 置信度过滤（官方强调的关键步骤）——
            低置信像素写 ignore(255)，保留率预注册在 70–90% 区间
            阈值由"test1 置信度分布 vs 训练集 val 置信度分布"确定，不看平台分
训练集    = 官方 5597 张 + test1 500 张(伪标签)   ← 管线已存在（pseudo_train_6796/）
配方      = s58 的配方，逐字复制，只改训练列表
            （CWFA + regionC，ADE 预训练 B3，1024，56000 步，seed 42，AdamW 6e-5/wd0.01）
            ⇒ 唯一新变量 = 伪标签
```

**为什么这次可能比历史上的 pseudo500 强：**
- teacher 从 ~0.68 变成 0.7026（test1 上强 2.2pp）
- 官方配套的置信度筛选这次会做
- 历史证据：s55b（用弱 teacher 的伪标签）贡献了 +0.1776 的方向增益

**产物并入：**
```
d_ps = θ_ps − soupC
候选并入方式（预注册，≤6 个包）：
  (i)  分层剖面 (0.5,0.5,0.2,−0.1,0) 叠加在冠军上
  (ii) 分层剖面 (0.8,0.8,0.2,−0.1,0)
  (iii) 分层剖面 (0.8,0.8,0.2, 0.0,0)
  (iv) 作为第 3 个 soup 中心成员：(s58+s64+θ_ps)/3
  (v)  (iv) 与 (i) 组合
  (vi)  θ_ps 与冠军直接等权平均（最保守）
```

**仅在 Arm 0a 判读为"SEMEDA 特异"时执行。**

```
配方 = s58 配方 + SEMEDA loss (embedding_weight 0.5, feature_size 256, gt_noise_sigma 0.1)
```

### Arm 3 · 测试域 BN 统计量（**低成本试探，约 15 分钟 GPU，≤3 个包**）

## 5. 我的诚实预期

**必须说清楚：这不是一个"做完就到 0.71"的方案。**

算术：

```
Arm 0（β/剖面/归因）          期望 +0.02 ~ +0.15pp   概率 40%
Arm 1（冠军教师自训练方向）    期望 +0.15 ~ +0.35pp   概率 60%
Arm 2（SEMEDA 现代配方）       期望 +0.10 ~ +0.30pp   概率 45%
Arm 3（BN 测试域）             期望  0.00 ~ +0.08pp   概率 30%
Arm 4（seed 保底）             期望 +0.05 ~ +0.15pp   概率 50%
```

乐观可加 ≈ +0.5 ~ +0.9pp。**P(达到 0.710) 我估计 20–30%。**

**什么会改变这个判断：**
- 若 Arm 0a 显示 stage2 效应是**通用的**（B/C/D 也正）⇒ 说明冠军的 stage2 存在系统性可压榨空间，
  且可扫描幅度 ⇒ 单臂就可能给 0.3pp 以上，概率上调
- 若 Arm 1 的新方向像**最早的 soupC 那样**给 +0.3pp 以上（而不是后期成员的 +0.1）⇒ 0.71 在两臂内可达
- 若 Arm 0/1 全部 < +0.05pp ⇒ 说明参数空间已真正饱和，**应当停止并在 0.703 附近收口**，
  把剩余时间投向"保住可复现的 0.7026"（官方复现失败 = 取消成绩，风险大于不涨分）
