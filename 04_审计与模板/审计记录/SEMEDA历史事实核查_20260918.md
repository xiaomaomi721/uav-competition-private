## 三、`+1.056pp` 到底是哪两个数字

**出处**：`raw_master_experiment_ledger.csv:49` 记录 `"+1.056(相对Exp18)"`，
且审计表明确标注 `"delta_computed": false`（当时**没有**重算）。

**两个数字（均为 test1 平台分，单视图、无 TTA、无校准）：**

```
Exp47  CE+semeda / semeda(λ.5, fs256, noise.1)   67.796
Exp18  CE / rare_crop  (B3 基线)                 66.739544
                                                 ─────────
                                     67.796 − 66.739544 = +1.056456  ≈ +1.056pp
```

- 来源文档：`文档归档/04_实验决策与成绩/线上成绩记录表.md:55`（Exp18 = 66.739544，标注"B3 基线"）、`:508`（Exp47 = 67.796）、`:514`、`:606`。
- 两者**配置同族**：同为 SegFormer-B3 / 1024 / 56000 步 / seed 42 / lr 6e-5 / wd 0.01 / rare_crop。Exp47 的配置基类就是 `stage18`。差异 = loss（+SEMEDA）。
- **不是** TTA8 或校准口径的数字（那是 69.0776 vs 68.03 等另一组）。

### 3.1 必须一并记录的三个限制（来自项目自己的取证报告）

1. **NOT_STRICT_SINGLE_FACTOR** —— `SEMEDA_VS_CWFA_FORENSIC_REPORT.md` 原文：
   Exp23(B3+CWFA) vs Exp47(B3+SEMEDA) 的差异是 **SEMEDA 替换 CWFA**，不是"在 CWFA 之上加 SEMEDA"。
   项目当时没有 Exp23 的 no-CWFA 同 seed 对照，此限制已被如实记录。
2. **本地 val 不支持这个增益，甚至相反**：
   ```
   Exp23 (B3+CWFA)   local val 0.8110
   Exp47 (B3+SEMEDA) local val 0.8096      → Δ local = −0.0014
   ```
   同一份取证报告 §11 原文：
   > "source-val 上 SEMEDA 不优于 CWFA; online 上 Exp47 标准 +1.056 (67.796 vs 66.739)
   >  但**此增益无法在 source-val 复现** → 指向 test 域特性(域差异)，非 source-val 可测能力。"
3. **校准后差距缩小**：Exp47 的校准增益只有 +1.28（项目内最低档），最终校准版 69.0776，
   仍低于当时锁定冠军 0.6928129。`线上成绩记录表.md:514` 原文称其为
   "**标准版高 ≠ 校准空间大**"的例证（同 Exp41 边界：67.05 → 校准 68.81）。

**⇒ `+1.056pp` 是一个只在 test1 上出现、local val 上不出现、且校准后不复现的数字。**
它成立，但它的性质与"模型本体变强"不同。

## 四、stage2 具体是什么

`_make_donor_gate2.py` 的分组函数：

```python
def group_of(key):
    if key.startswith("segformer.stages."): return f"stage{key.split('.')[2]}"
    if key.startswith("segformer."):        return "stage0"
    return "head"
```

在 donor checkpoint 上实测的键结构（本次只读 keys，未做前向）：

| group | 前缀 | 子模块 | 张量数 | 参数量 | 占比 |
|---|---|---|---:|---:|---:|
| stage0 | `segformer.stages.0.*` | patch_embeddings / blocks ×3 / layer_norm | 72 | 0.954 M | 2.0% |
| stage1 | `segformer.stages.1.*` | patch_embeddings / blocks ×4 / layer_norm | 94 | 1.938 M | 4.1% |
| **stage2** | **`segformer.stages.2.*`** | **patch_embeddings / blocks ×18 / layer_norm** | **402** | **30.184 M** | **63.9%** |
| stage3 | `segformer.stages.3.*` | patch_embeddings / blocks ×3 / layer_norm | 60 | 10.996 M | 23.3% |
| head | `decode_head.*` | linear_projections ×4 / linear_fuse / batch_norm / classifier | 13 | 3.156 M | 6.7% |
| | | | | **47.23 M** | 100% |

**stage2 = SegFormer-B3 encoder 的第三级（depth 18 的那一级），是五个分组里最大的一个，
单独占全模型 63.9% 的参数。**

## 五、`S_semeda_M` 这个包的确切定义（技术细节）

`_make_donor_gate2.py` 的方向与尺度定义（逐行核实）：

```
soupC = (s58 + s64) / 2                        # 等权参数 soup，冠军的"中心"
d_ref = s55b - soupC | stage2                  # 已知良好方向
target = 0.2 * RMS(s55b - soupC | stage2)      # ALPHA_REF[stage2] = 0.2
beta   = target / RMS(donor - soupC | stage2)  # 相对 RMS 匹配
out    = champ + beta * (donor - soupC | stage2)     # 只改 stage2 的键，其余逐位保持 champ
```

所以 **`S_semeda_M` = 冠军 + β·(Exp47 − soupC) 限制在 stage2**，其中：

| 量 | 值 |
|---|---|
| β（S_semeda_M） | **+0.2188631149** |
| β（X_maxent_M） | +0.1804102547 |
| β（W_paramwise_M） | +0.2023878 |
| 注入方向 | **`Exp47 − soupC`**（不是 `Exp47 − champ`） |
| 注入尺度 | 使 stage2 扰动的 RMS **等于 s55b 方向在 α=0.2 时的 RMS** |
| 其余分组 | stage0/1/3/head 与 BN buffers **逐位保持冠军**，`num_batches_tracked` 从不参与 |

## 六、冠军侧：现代 recipe 是什么

冠军 `layerwise3_20260917/N9_e050_dm010.pt` 的构造（据 `今日工作总结与71方案_20260917.md` §1.2）：

```
θ = θ_C + Σ_g α_g · d_g
θ_C = (s58 + s64) / 2                 等权 soup 中心
d   = s55b − θ_C                      参数空间方向
α_g                                   分组系数 g ∈ {stage0, stage1, stage2, stage3, head}
α = {0.5, 0.5, 0.2, −0.1, 0.0}
```

五个 soup 成员的配方：

| 成员 | 配方 |
|---|---|
| s58 | CWFA + regionC |
| s64 | CWFA + weight_decay 0.0005 |
| s55b | CWFA + pseudo500 |
| s62 | resume55b + pseudo500 |
| Stage23B | CWFA + CE formal |

**五个成员全部是 CWFA 家族 —— SEMEDA 从未进入过任何 soup 或合并路径。**
这也解释了为什么这次 donor gate 是第一次把 SEMEDA 的参数方向注入现代冠军。

**两边的起点完全不同：**

| | Exp47（donor） | 现代冠军 |
|---|---|---|
| init | ADE20k 预训练 B3 | 由 s55b/s58/s64 等自训模型合并而来 |
| CWFA | 关 | 开（所有成员） |
| pseudo-label | 无 | 有（s55b/s62） |
| 训练期方法 | 单一 SEMEDA loss | CWFA + regionC + wd + pseudo + 合并 |
