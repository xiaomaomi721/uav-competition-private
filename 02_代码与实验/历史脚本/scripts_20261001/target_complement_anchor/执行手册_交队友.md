日期：2026-10-01。目标：只生成 **1 个**正式候选，不自动提交，不为凑满每日两槽制造第二包。

## 0. 科学问题与冻结结论

当前冠军 Arm B：

```text
test2 = 71.045315
A05 init + A05 teacher
source_coeff=0.1, target_coeff=1.0
blind-class soft KL, 2000 attempted loops
```

已知纯 target Arm A 为 70.957249，说明无锚会损失；但 source-only CONTROL 相对 A05 损失约 0.503pp，说明 source CE 有域税。

2026-10-01 线上结果（用户报告）：RAS-KD TREAT 71.042244（较 Arm B −0.003071pp），BLACK_CORE_DROP 71.029651（较 Arm B −0.015664pp）。两者没有刷新冠军，且都混入共同 `xlogy` 变化；今日另行提交既有 RAS CONTROL 只用于闭合该因果链，不改变 TCA 配方。

TCA v4 只改一件事：

```text
删除 source CE；
原 selected mask 上保持完整 soft KL；
完整 256×256 teacher 网格的 mask complement 上加入一次性梯度校准的弱 soft KL。
```

`selected | complement` 必须覆盖完整网格，TCA v4 不排除 black core。teacher KL 固定使用 zero-safe `torch.xlogy(q,q)-q*logp_student`。

不加入 RAS D4 权重、BLACK_CORE_DROP、EMA、SWA、test1、hard pseudo、新 bias 或额外训练步数。

## 5. 阶段 A：一次性冻结 mu

输出目录必须不存在：

```text
/data/uav/runs/tca_20261002_calibration
```

命令：

```bash
CUDA_DEVICE_ORDER=PCI_BUS_ID CUDA_VISIBLE_DEVICES=1 \
/data/uav/venv/bin/python /data/uav/code/tca_20261002/calibrate_tca_mu.py \
  --root /data/uav \
  --output-dir /data/uav/runs/tca_20261002_calibration \
  --physical-gpu 1 \
  --expected-gpu-uuid GPU-9f3707b0-4a7d-0ba5-6c3b-463906c93bd7 \
  --samples 96 \
  --target-grad-ratio 0.10 \
  --mu-min 0.02 \
  --mu-max 0.15 \
  2>&1 | tee /data/uav/runs/tca_20261002_calibration.log
```

必须产生：

```text
CALIBRATION_RECEIPT.json
COMPLETE.json
```

检查：

- `parameter_updates_performed=false`；
- `black_region_training_exclusion=false`；
- `full_teacher_grid_partition=true`；
- A05 SHA 正确；
- teacher cache 1300/1300 shape/dtype/finite 通过；
- 96 个样本 main/rest gradient 均 finite 且 >0；
- `mu` 在 `[0.02,0.15]`；
- 若 `clamped=true`，如实保留，不改值、不追加第二个候选。
