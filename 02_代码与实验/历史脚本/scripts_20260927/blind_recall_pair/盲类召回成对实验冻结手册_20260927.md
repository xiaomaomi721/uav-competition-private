## 0. 一页摘要

```text
科学问题：
  启用"盲类召回 + 软 KL 蒸馏"的测试域自训练，是否优于纯 source 续训？

TREAT:
  A05 教师(自己) → 1300 test2 软伪标签
  先验校正 = +Bstar 后 softmax（教师带线上判决过的 8 维 bias）
  盲类召回 mask:
      非盲类像素  conf >= 0.98
      盲类像素    (Water/Barren/Agricultural) conf >= 0.50   ← 关键：不删盲类
  软 KL 蒸馏（非 D1 的 hard argmax）
  混 5597 source 回训，2000 attempted loops，target coeff = 0.5*min(1,loop/500)

CONTROL:
  同配方、同步数、同 seed、同 replay，唯一差异 target coeff = 0
  （target branch 仍完整执行并记录，损失贡献精确为 0）

主因果比较:
  online(TREAT) - online(CONTROL)          ← 测试域监督的净价值
  online(TREAT) - 70.775011                ← 相对冠军的部署价值
```

**为什么这个设计不是假大空**：D1（+0.149）是项目里唯一在 test2 上被验证过的测试域机制，但它的 conf≥0.98 hard mask 恰好删掉了教师"不自信地错"的盲类像素（Barren 教师只认出 0.29% vs 训练集 2.51%）。`最优方案薄弱点与丢分结构_20260908.md` 已实锤丢分是区域级 Background/Vegetation→Agricultural/Water/Barren 整片翻转。v3 rescue 配方（`独立反驳与方案v3_20260918.md` §五）给出盲类单独降阈值、高召回打标的正确姿势。本方案把"盲类召回"+"软标签"+"先验校正"三件事一次做对，并与纯 source 续训做干净因果对照。

## 2. 冻结的科学问题与预注册强度

### 2.1 主问题

```text
在完全相同的 A05 source continuation、target 输入计算和随机流下，
启用"盲类召回软 KL 测试域蒸馏"是否比其权重为 0 更好？
```

### 2.2 为什么必须有 CONTROL

只比 TREAT vs 静态 A05 会混入：2000 步 source continuation、fresh optimizer/weight decay、随机增强、target 蒸馏。只有 `TREAT - CONTROL` 能估计 target 蒸馏的增量价值。

### 2.3 预注册强度

```text
Delta_target    = online(TREAT) - online(CONTROL)
Delta_treat_A05 = online(TREAT) - 70.775011
Delta_ctrl_A05  = online(CONTROL) - 70.775011
```

- `<+0.05pp`：无实质 target 增益。
- `+0.05 ~ +0.199pp`：小的残余增益。
- `≥+0.20pp`：强信号（本项目追求的"提大分"门槛）。
- 只有 `Delta_target` 与 `Delta_treat_A05` 都 `≥+0.20pp`，才称盲类召回为强新杠杆。

## 5. 每 loop 准确训练语义

```text
source:
  1024 crop, rare crop p=.5, priority=(7,4,6), max_offset_fraction=.25, batch=1
  source_logits → bilinear 到 GT size → CE(ignore=255)

target (两臂都执行):
  D4 view ∈ 0..7 → strong_photo 增强
  student: model(aug) → inverse D4 → +Bstar  (z)
  teacher: 读 A05 cache → +Bstar → softmax (pa)
  conf, ya = pa.max(1)
  blind = ya ∈ {3,4,6}
  mask  = (conf>=0.98) | (blind & conf>=0.50)
  kl    = Σ_c pa*(log pa - log_softmax(z)_c)  逐像素
  lt    = kl[mask].mean()  (mask 空则 0)
  coeff = 0 (control) / 0.5*min(1,loop/500) (treat)
  loss  = lsrc + coeff * lt
```

AMP 与 step：attempted 2000；overflow 记 skip，skip 不 update 但仍消耗本 loop 的 replay record；不补 loop。

## 9. 成对线上提交（不可拆分）

预注册顺序：先 CONTROL 后 TREAT，同一平台窗口，用户人工提交。不能先交 CONTROL 看分再决定 TREAT。

固定决策树：

```text
A. TREAT > CONTROL 且 TREAT > A05   → 盲类召回有独立部署价值（强杠杆若两 delta ≥ +0.20）
B. TREAT > CONTROL 但 TREAT ≤ A05   → 正因果但无部署收益，关闭本 recipe，保留 A05
C. TREAT ≤ CONTROL, CONTROL > A05   → 不支持 target 蒸馏；CONTROL 或是 source-continuation 候选
D. 两者都 ≤ A05                     → 保留 A05，关闭
E. 同分                             → target effect=0，关闭
```

无论哪种，不自动加第三臂 / seed / lambda / confidence / duration sweep。
