## 3. C1/C2 定义与插入位置

### 数据流

```
source batch ──> student(stage0/1 可训, stage2/3/head 冻结) ──> logits ──> CE
target 图 ──> 32×32 patch 随机遮挡 40%（1024 坐标） ──> 归一化空间置 0
   ├─ C1: student.stage1 特征(128ch,128×128) → Conv2d(128,192,1)+PixelShuffle(8) → 1024×1024×3
   │       L = Σ|recon - rgb_clean|*mask / (3*Σmask)         仅遮挡区
   └─ C2: student.stage1 特征 vs 冻结H75 在**未遮挡**原图上的 stage1 特征
           L = Σ(1-cosine)·token_mask / Σ token_mask         仅遮挡 token
```

- **可训练范围**：`segformer.stages.0.*`、`segformer.stages.1.*`；C1 另加训练期 RGB 头（1,024,899 参数）。stage2/stage3/decode_head **参数与 buffer 全部冻结并审计**。
- **未使用任何目标伪标签/argmax/教师 logits/Bstar**；C2 的参考仅为冻结 H75 的 stage1 特征。
- **遮挡映射**：32×32 patch 网格 → 1024 像素坐标（kron 32×32）；stage1 为 128×128，128/32=4，故每个 patch 网格单元 → 4×4 token，用 `nearest` 上采样，语义为"该 patch 被遮挡即其 4×4 token 全部被遮挡"（保守）。
- **泄漏检查**：重建头只接 stage1 特征，输入图像在遮挡区被置 0；未遮挡像素不参与 aux loss。已通过 §4 的第 2 项测试。

### lambda 选取（固定 pilot，不做事后网格）

| 臂 | ‖grad_aux‖/‖grad_src‖ @λ=1 | 选定 λ（目标比 0.25） |
|---|---:|---:|
| C1 RGB-L1 | 0.5432 | **0.460226** |
| C2 feature-cosine | 4.7088 | **0.053092** |

两臂 `mean_grad_src` 完全相同（**0.2395**），证明配对一致。**这验证了任务书的警告：不能把 RGB-L1 的 λ 直接套给 feature-cosine，量纲差 8.7 倍。**

## 7. 最终决策：`NO-GO`

### 判据对照（任务书 §E4）

| 判据 | 实际 | 是否触发 |
|---|---|---|
| 实现错误 / 冻结层变化 / 生产推理变化 | 无（frozen_diff=0，复现 0 像素） | 否 |
| 过大梯度冲突 | λ 已按 0.25 比值标定 | 否 |
| 显著 source GT 能力退化 | 三臂 −0.08~−0.11pp，且 C0 同样退化 → 是**续训本身**的问题，非 aux 造成 | 部分 |
| 预测单类异常膨胀 | 未观察到类别坍缩 | 否 |
| **C1/C2 在 source 安全与目标稳定性上均不优于 C0** | C1 +0.0066、C2 +0.0205，**噪声量级** | **是 → NO-GO** |

### 最强反证

1. **两种 aux loss 的机制增益都在 0.01~0.02pp 量级**，远小于方法噪声，且三臂均低于未训练 H75。
2. **C0 本身在 300 步后就掉 −0.105pp**，说明在这个训练范围（仅 stage0/1）与预算下，任何"续训"都是净负面；aux loss 最多只是**部分抵消**这个损害，不是独立增益。
3. **C2 的教师是 H75 自身冻结特征**——它最优解就是"复制 H75 已有表征"，因此不可能带来新知识，这与任务书 §B 的预设一致，本轮实测证实。

### 可能过拟合位置

- 300 步太短，还不足以让 stage0/1 充分吸收 target 分布；但任务书明确要求先做短程匹配对照，**不得因此擅自扩大成全量训练**。
- source1399 与训练图空间重叠，其小幅波动不能代表泛化。

### 建议保留/放弃

**建议放弃 RGB-MIM 与 feature-consistency 两条路线在此设定下的必要性。** 若未来仍要验证，唯一有意义的改动是**扩大可训练范围到 stage2/3**（但那样失去"保护原冠军"的初衷），或**换用非自蒸馏的外部教师**（目前无可用资产）。
