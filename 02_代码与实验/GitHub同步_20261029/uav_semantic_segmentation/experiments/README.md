# 正式实验台账维护规则

`experiment_registry.csv` 是 Stage 03 之后正式实验的统一索引。维护时遵守：

- 一次只改变一个核心变量，确保能够与正式基线归因比较。
- 每次正式实验必须记录本地指标；有线上提交时必须补充线上指标与来源。
- 必须记录 checkpoint SHA256，并区分“声明值”和“本机已重新验证”。
- 必须记录实际训练代码 commit；历史实验若未留存只能写 `not_recorded`，不得猜测。
- 不把 checkpoint、完整训练日志、预测 PNG 或提交 ZIP 提交 Git。
- 不删除旧实验、不修改历史实验 ID；补全同一实验时更新原行，避免重复。
- Stage 05 的每项实验均以 `formal_b0_ce_512_seed42` 为正式对照组。
