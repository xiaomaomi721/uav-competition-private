### FDA数值审计补充

10/28 FDA方案曾设低频幅度混合 `A_mix=A_src+λMβ(A_donor−A_src)`，phase保留Source。合成数组/代码复查发现：颜色变化用 `abs(mean(signed ΔRGB))` 而非 `mean(abs(ΔRGB))`；1024中心低频掩码存在38处共轭对不匹配，逆FFT虚部最大约0.00105。**INCONCLUSIVE不能写成FDA方法已被正式训练证伪**。

## F. 对后续报告的统一写法

- 仅使用具体实验相应协议、有效训练步数、数据划分、checkpoint身份、Source GT/Target无GT及真正的官方回报。
- 对“无线上分”的实验写`unknown`或“未报告”，不写0、不从Source推断Target。
- M2F E02 C1 与 H75可靠性蒸馏C1是不同实验；ST++-Lite V2实际新监督仅4个像素，不能写成已实质覆盖困难集。
- CUDA/资源、截止期、磁盘及服务状态均有时效性；本文仅保留历史事实，不代表任何后台任务的执行授权。
- 比赛材料最终必须对应**真实线上最高分的模型+推理配置+预测ZIP**；GitHub文档整理不等于已完成可复现Docker。
