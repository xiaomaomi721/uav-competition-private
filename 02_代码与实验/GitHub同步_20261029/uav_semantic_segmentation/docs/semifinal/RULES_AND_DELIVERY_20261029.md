## 数据、标签、评价

- 官方6996张有GT，团队固定Source train5597 / val1399；半决赛Target3594（旧500 +1300 +新1794），全部1024×1024，Target真实逐像素GT不公开。
- 八个计分类：Background(1), Building(2), Road(3), Water(4), Barren(5), Vegetation(6), Agricultural(7), Vehicle(8)，Ignore(0)不计分。项目内部映射官方1..8→0..7、Ignore→255。
- mIoU：累计混淆矩阵求八类TP/(TP+FP+FN)的平均，不是逐图IoU均值或pixel accuracy。Source和Target指标完全区分。

**这些数是每图存在性频数，不是像素级先验，也不是任何模型的Target类别IoU。** 执行方在Source6996按“≥1像素”统计得到与官网9类完全一致。

## 模型/数据合规与团队问答范围

- 官网规定最终提交**单模型**，不得多模型推理ensemble；允许使用公开学术预训练权重、赛事官方数据。禁止额外非官方训练数据、商业闭源模型API替代、泄露数据及任何测试GT作弊。
- 团队问答记录老师“可以”的主题包括：训练期多教师→单模型推理、同构checkpoint离线参数平均形成单权重、官方无标签test数据用于域适应/伪标签或软蒸馏、单checkpoint D4及重叠裁剪TTA、固定8维logit bias。
- **2026-10-29额外确认**：用户向老师明确询问是否可使用官网公开的Target“出现图数”聚合统计来估计分布并优化最终固定类别bias/类别先验参数，得到“可以”。完整提问与答复截图应在队内归档；不能把答复扩大为“允许使用不可公开的Target逐像素GT”。
- 历史“soup直接提交是否属于禁止范围？”为否定式问句；仅有“可以”文字存在歧义。多个问题合并询问时也不能推定全部解释得到独立授权。
