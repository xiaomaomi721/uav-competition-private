# 数据集说明

## 1. 数据集用途

本数据集用于“2026AIC·无人机低空航拍图像语义分割”赛题。模型需要为每个测试图像像素预测类别 ID，并生成与测试图片同名的单通道 PNG 标签图。比赛主要评价指标为 mIoU。

## 2. 官方数据目录结构

以下使用 <DATASET_ROOT> 表示每位成员本机上的官方数据根目录，不在文档中记录真实绝对路径。

    <DATASET_ROOT>/
    ├── Label.txt
    ├── images/                 # 初赛测试图像，500 张
    ├── train/
    │   ├── images/            # 训练图像，6996 张
    │   └── masks/             # 训练标签，6996 张
    └── Examples/
        ├── Label.txt
        ├── images/            # 示例图像，11 张
        └── masks/             # 示例标签，11 张

Examples 用于理解数据格式，不作为独立训练版本或提交示例。

## 3. 数据数量

| 数据部分 | 数量 |
|---|---:|
| 训练图像 | 6996 |
| 训练标签 | 6996 |
| 初赛测试图像 | 500 |

训练图像文件名为 0000.png 至 6995.png，标签与图像同名；测试图像文件名为 test1_1.png 至 test1_500.png。

## 4. 图像与标签格式

| 项目 | 格式 |
|---|---|
| 训练与测试图像 | 1024×1024，RGB，uint8，PNG |
| 训练标签 | 1024×1024，单通道 L 模式，uint8，PNG |
| 标签实际像素值 | 0–8 |
| Palette 标签 | 未发现 |
| 255 像素值 | 原始标签中未出现 |

标签检查必须使用不改变原始像素值的方式读取。不得将标签转为 RGB 后插值，也不得归一化标签 ID。

## 5. 官方类别 ID

类别表来自数据包内 Label.txt，名称与 ID 已确认。

| 官方 ID | 类别名称 |
|---:|---|
| 0 | Ignore |
| 1 | Background |
| 2 | Building |
| 3 | Road |
| 4 | Water |
| 5 | Barren |
| 6 | Vegetation |
| 7 | Agricultural |
| 8 | Vehicle |

## 6. Ignore 类别

官方 ID 0 的名称为 Ignore，表示训练或评价时不应作为普通语义类别学习的像素。数据包确认了 Ignore 的 ID，但没有提供官方 evaluator 配置；开始训练前仍需从正式规则核对 mIoU 是否排除 ID 0、Background 是否计入指标。

## 7. 当前数据完整性结论

- 6996 张训练图像与 6996 张标签完全一一对应。
- 所有训练和测试图像均为 1024×1024、RGB、uint8、PNG。
- 所有标签均为 1024×1024、单通道 L、uint8、PNG。
- 未发现空文件、损坏文件、尺寸异常、异常通道或图像标签尺寸不一致。
- 未发现标签 ID 超出 0–8，也未发现 255。
- 16 张标签只包含一个类别，属于场景分布警告，不需要自动修复。
- 当前数据集不需要人工清洗或自动修复；发现的问题应通过训练策略和验证设计处理。

## 8. 主要类别分布

下表占比按排除官方 Ignore 像素后的有效像素计算。

| 类别 | 有效像素占比 | 出现图片频率 |
|---|---:|---:|
| Background | 28.011% | 96.87% |
| Building | 18.277% | 65.64% |
| Road | 8.921% | 62.42% |
| Water | 6.291% | 36.26% |
| Barren | 1.835% | 15.69% |
| Vegetation | 28.780% | 87.11% |
| Agricultural | 7.103% | 17.04% |
| Vehicle | 0.783% | 26.39% |

非 Ignore 类别的最大与最小像素量约相差 36.745 倍，存在明显像素级长尾。

## 9. Vehicle 与 Barren 长尾问题

Vehicle 约出现在 26.39% 的训练图像中，但仅占有效像素约 0.783%，说明它并非只在极少图片中出现，而是在出现时通常面积很小。该类对网络输出步长、裁剪策略、上采样边界和小目标采样较敏感。

Barren 仅占有效像素约 1.835%，并且只出现在约 15.69% 的图片中，同时具有像素级与图片级稀缺问题。后续需要关注验证集覆盖、批次采样和逐类 IoU，不能只看总体损失或总体像素准确率。

## 10. 训练侧建议标签映射

建议在数据加载阶段动态映射为 8 个可学习类别：

映射规则：官方 0 → 训练 255，作为 ignore_index；官方 1–8 → 训练 0–7。

| 官方标签 | 训练标签 | 训练含义 |
|---:|---:|---|
| 0 | 255 | Ignore，设置 ignore_index=255 |
| 1 | 0 | Background |
| 2 | 1 | Building |
| 3 | 2 | Road |
| 4 | 3 | Water |
| 5 | 4 | Barren |
| 6 | 5 | Vegetation |
| 7 | 6 | Agricultural |
| 8 | 7 | Vehicle |

此方案对应训练 num_classes=8、ignore_index=255。映射只能在内存中或派生缓存中完成，不得覆盖官方标签；测试提交前必须把训练 ID 0–7 映射回官方 ID 1–8，并严格遵循正式提交规则。

## 11. 当前数据风险

- 类别不平衡：Vehicle 与 Barren 明显弱于主导类别。
- 小目标分割：Vehicle 面积小，可能被下采样和随机裁剪丢失。
- 跨场景泛化：样本覆盖城市住宅、工业、农田、水域、停车场等场景，随机切分可能低估域差异。
- 划分泄漏：连续航拍帧、相近场景和重复候选可能同时进入训练与验证集。
- Ignore 评测口径：正式 evaluator 对 ID 0 和 Background 的处理仍需规则确认。

## 12. 数据使用注意事项

- 每位成员自行获取授权数据，不通过 GitHub 传播。
- 官方数据和压缩包不得进入仓库。
- 原始图像、标签和目录结构保持只读。
- 不自动清洗、修复、插值或重编码标签。
- 后续所有实验必须使用统一的固定数据划分和指标实现。
- 训练侧映射、增强和裁剪必须保证标签使用最近邻或离散索引操作。
- 提交文件必须恢复官方类别 ID，保持测试图片同名、单通道 PNG。

## 13. 运行只读检查脚本

在项目根目录安装依赖并执行：

    python -m pip install -r requirements-audit.txt
    python scripts/inspect_dataset.py --dataset-root "<DATASET_ROOT>" --output-dir reports --sample-count 20 --seed 42

可选参数包括 --workers、--compute-hash。只有需要完整 SHA256 时才使用 --compute-hash。输出目录不得位于 <DATASET_ROOT> 内部。
